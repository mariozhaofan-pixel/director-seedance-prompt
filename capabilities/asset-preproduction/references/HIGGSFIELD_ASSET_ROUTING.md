# Higgsfield Asset Routing

## 使用说明

仅在需要核对 Higgsfield 当前入口或模型路由时读取本文件。产品能力会更新；精确上限、格式、分辨率、价格和功能入口必须以调用当天的官方页面为准。

## 证据

官方产品说明用于确认产品定位和界面工作流。下表“控制重点”里的经验做法与官方说明或当前实测冲突时，以官方说明和实测为准，经验降为候选方案。

## 当前任务路由

| 任务 | 首选入口 | 控制重点 |
| --- | --- | --- |
| 快速构建虚构演员 | Soul Cast | 通过界面设置类型、时代、身份、体型、细节和服装 |
| 写实角色照片/身份板 | Soul 2.0 | 身份、皮肤、身材、服装和中性角色覆盖 |
| 跨生成持久真人身份 | Soul ID | 使用平台身份训练/持久身份能力，不用文字冒充 |
| 电影感场景与电影帧 | Soul Cinema | 场景材质、光线、纵深、构图和电影质感 |
| 道具、包装、准确文字 | Nano Banana Pro / GPT Image 等当前入口 | 多视图结构、产品材质、文字准确性 |
| 已有图局部修改 | Nano Banana Pro 经验优先 | 一个变量、局部变化、其余保持 |
| 纹理修整 | Seedream 当前可用版本 | 皮肤、织物和表面；点改能力需实测 |
| 反向机位/新视角 | GPT Image、Nano Banana 或 Cinema Studio 当前工具 | 先写新机位的物件排列和世界拓扑 |

资产方法本身（双锚点、状态拆分、中性角色板、场景地标与方向、局部修改、压力测试）只在[静态资产预制](../ASSET_PREPRODUCTION.md)维护。

## 不升级为硬规则的项目选择

- Nano Banana Pro 永远是所有修改的第一模型。
- Seedream 永远不能承担点改。
- 每张图都必须使用三分法构图。
- 每个项目都必须固定生成十次才能验收。
- 一个模型版本的参考数量、分辨率或价格长期不变。
