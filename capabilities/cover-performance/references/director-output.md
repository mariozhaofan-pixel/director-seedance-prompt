# 导演统一演唱格式

纯演唱与剧情内演唱默认都采用导演五栏，不用旧四段式；演唱的五栏映射只在本文件维护。用户明确要求旧格式或其他格式时覆盖；纯格式切换不触发工作区、云服务或版本确认。

每段标题使用`第01段｜30秒｜场景功能`的结构，时长写本段真实计划值。五个标题各自独占一行，严格依次为：

```text
【角色/场景/素材锁定】
【基础风格】
【运镜与时间轴】
【声音设计】
【画面限制】
```

1. 素材锁定：每个角色/场景一条主行，结合真实名称、身份造型和控制维度。角色音色、歌曲参考或最终音轨各自单独成行并写明职责。仅列本次生成用附件，不把本地备用伴奏写成已绑定。无真实上传句柄时使用实际文件名，不虚构句柄或绑定。
2. 基础风格：沿既定光影与摄影基线，写画幅、摄影/镜头、景深、动机光方向、空气层次、材质和色彩；不重复人物外貌、歌词或管理说明。
3. 运镜与时间轴：Seedance 2.5段在CUT 1前写“前提、核心关系、导演意图、演员指令、对白规则”五行紧凑总控（按[06](../../../knowledge/06_TIMELINE_EDITING_SOUND.md)），2.0不强制。对白规则包括本段唱词白名单；导演意图直接写观众体验、情绪与注意力变化，不写素材来源或工作流程，不凭歌曲发明剧情反转。随后用CUT表示真实切镜，连续乐句在同一CUT内用BEAT；动作窗和发声边界分别表达。每句写完整唱词、开始/持续/结束、口型与气口、眼神/姿态的进入及余态，覆盖实际留白；逐CUT落实主体与camera路径、焦点、视线、画外延续和可见OUT，口型优先。没有模型版本时可用该结构写通用稿，不虚构平台支持。
4. 声音设计：先写本次真实声音组织（清唱/伴奏/弹唱）及歌曲参考、音色身份的分工，再写“参考音频的完整歌词如下：”并列本生成段完整可用歌词；纯器乐段明确无人声。唱词与时间轴逐字一致，保留重复句。只禁未请求的额外配乐，不禁已选伴奏或乐器。未听辨的ASR歌词状态放正文外，不改名为确认稿。参考加速后按处理后的文件节奏演唱，不再要求原速；原调可保持。声线样本不进入成片对白。
5. 画面限制：沿本轮身份、结构、文字等要求，发音自然、口型优先，加字幕/水印等清洁约束；不用固定抿嘴或冻脸换取稳定。

预算核算、上传文件清单、素材状态、来源、候选时码声明与后期操作放在正文外；源时间、整片与段内时间的映射留在台账，正文只放该段实际可执行时序。参考音频与视频时长分开，文件不能因画面有收尾而补长。通用稿不假定特定模型上限；指定模型后由导演入口适配其当前真实规格。没有可靠时码时给有序节点草稿，严格逐句要求未满足不标为已校准。

单段正文完整给出，文件可作补充；用户只要文件时按其要求。需要补齐声音生成或平台能力时只说明真实缺口，不把参考人声当作角色已重唱完成。
