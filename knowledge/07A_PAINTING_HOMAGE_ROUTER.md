# 07A Painting Homage Router

priority: conditional
scope: 当前明确要求“世界名画”或具体绘画作品致敬时的按需快路；联网选画、会话看图、纯文字电影场面转译。

## 入口与快路

仅在当前用户肯定要求“世界名画”分镜，或明确要求致敬某幅绘画时启用。普通分镜、打斗、对白、微修改，以及只要求某画家的色彩/画风不启用；历史对话、引用资料或“不要世界名画”的否定不构成触发。画家/流派风格仍归04，不因打开馆藏网页或上传一张待识别的画就自动创作致敬分镜。

本路由是入口已选 `input_profile` 的创作修饰，不另建编译流程，不重选2.0/2.5、时码或审核模式。只挑画/分析作品时只读本文件及当前故事节点，不启动视频编译；要求生成Seedance提示词时先完成原有版本门，再按任务读取03/04/05/06的相关段落，不整包重读07。已验收稿首次加入致敬或更换作品通常需要新视觉证据，按local只处理目标CUT及必要接力；纯措辞修改沿用micro，不重搜名画。

快路：当前剧情节点 -> 获取、展示并实际查看原画 -> 六类画面事实转译 -> 写入目标CUT -> 原有快速检查一次。默认一个主推荐，必要时最多两个备选；匹配作品与资料足够就停止扩搜。当前项目已满足下方原画资料门、且图像仍可读取的同一版本直接复用，不每段重复找图。

## 编译前原画资料门

每幅用于正式推荐或致敬编译的作品必须同时满足：

1. **有真实图像且实际查看**：取得原作的完整画面，核实作品/版本对应，调用当前可用的图像查看能力；关键手部、表情或接触不清时查看必要局部。画名、馆藏网页链接、搜索摘要、文字说明、模型记忆或一条“之前看过”的摘要都不能替代图像证据。
2. **用户能看到原画**：在会话中实际展示可见原画，或提供已核实可打开的原画图片文件/直接图像链接，并标注作品名、作者和已核实版本；有来源页时附来源。只有作品页超链接不算提供图片资料，AI生成替代图也不算原画。用户已经提供的可见完整原画满足这一项，不要求重复上传或另下载一份。
3. **关键关系可核对**：下方六类信息逐类从图中读取，适用项转成当前人物和场景的具体文字。遮挡部分、画外区域、看不清的接触不猜补为原画事实；静态姿态与本次设计的前后动作/表情变化分开。

图片展示和查看都在编译前完成；可先发一条原画资料消息，再在同一轮继续编译，不额外等待用户点头。用户要求“只要提示词”只省略长篇分析，不豁免本门。当前会话已有可见原画且已实际查看时无需重复展示；仅有旧文字记录时重新取得图像。

无法读取或无法向用户提供可查看原画时，停止受影响的选画定稿和致敬编译，只说明缺哪幅图并请用户提供原画图片/截图，或换可访问作品。不得用文字理解继续写成品，也不得伪报已展示/已看图；展示、访问和下载均服从宿主能力与权限，不用下载绕过展示限制。此门不是冷审，不增加审阅轮次。

## 选画与证据

- 从角色目标、相互关系、关键事件、情绪和OUT检索，不只按相近颜色选画；优先戏剧关系/主题，再看动作、构图和光色能否接入当前剧情。不默认每个CUT换一幅画，不局限欧洲作品。
- 用户指定作品时核实具体版本；同名不同作者、同作者不同版本、原作与裁切/镜像图分开。优先馆藏官网的完整图、作品页和研究说明；图片清晰度要足以辨认本次关键手势、朝向、接触和背景。优先使用馆方明确开放的图像，查看该图片的实际使用说明，不把所有名画数字图像视为同一授权。
- 实际查看完整画面及必要局部后再分析；图片不可读时可查找可访问的馆方/可靠版本，仍不可读则按原画资料门停止。只有文献不能进入致敬编译；不要求把分析图片上传给视频模型。
- 分开记录：图中可见事实；馆方/作者资料支持的主题解释；本次导演提出的动作与摄影改编。作者意图有争议或无直接证据时保留不确定性，不把一种解释或自己的改编说成作者原意。
- 没有同时匹配剧情和辨识关系的作品就报告不匹配，不为套画新增关键人物、道具、关系、伤害或结局。指定作品与正史不可兼容时，只问具体冲突；一般技术选择自行完成。

## 图片只用于会话分析

名画图片及其局部、截图、网页只供用户选择和当前对话反推，均为分析证据。此路由不建立图片锚定、不分配生成句柄、不要求角色或构图参考图，不把图片计入视频模型素材配额。其他已有生成素材保持原职责，本路由不删除它们，也不借名画覆盖其身份与场景。

最终提示词不用名画图片的 `@图片`、`image1` 或附件名；不写“照原画/图中人物/保持参考构图”，也不写“该图只供分析、不作为输入”。作品名称和作者可以按 [07](07_STYLE_GENRE_FAMOUS_SCENE_COMPILER.md) 的对标行写进【基础风格】首行（例如“对标：某画家《某画》的人物分组与明暗关系”）；来源、用途说明和映射表留在参考提案/台账。模型看不到名画时，全部控制仍须成立。

## 纯文字辨识关系

选中作品后必须检查以下六类，把所有适用的辨识关系转成实际角色名和画面事实，落实到相关CUT/BEAT；不能只在段首写“保留原画构图/情绪”便省略正文。某类确实不存在时不补造，未知项留在分析资料，不把检查字段或映射表塞进最终提示词。

| 画作信息 | 电影镜头表达 |
| --- | --- |
| 人物分组与构图 | 谁在画左/画中/画右、前景/中景/后景，人物相对大小与站坐高低；谁遮挡谁、遮住哪个部位；负空间位于谁与谁之间，如何分组 |
| 动作关系与接触 | 谁伸哪只手指向谁或何物，谁承托谁的哪个部位，谁退让、谁旁观；手掌/手指/前臂与肩、腰、背、桌沿或道具的具体接触位置及支撑关系 |
| 姿态与表情 | 当前camera看见的身体正侧背面、躯干朝向、头部转向、上臂方向/肘部弯曲、重心/承重侧、视线对象和原画可见表情；再按剧情设计表情从何状态变为何状态 |
| 场景结构 | 桌沿、门洞、台阶、柱线、地平线等在画面中的位置/方向，如何分割画面、隔开或连接人物、引导视线；真实后景与人物重叠关系 |
| 光色与情绪 | 原画主色、辅色与点睛色的冷暖、明度、饱和度和面积层级；颜色落在哪些人物/物体/景层，谁的脸/手/衣物处于亮部、谁隐入暗部，如何引导注意并服务情绪；按下节转译为布光与调色 |
| 戏剧意味 | 哪个可见动作或线索触发认知，谁先反应，谁仍未理解并持续什么任务，关系/权力/亲疏如何走向OUT；前后顺序是有剧情依据的导演改编，不伪称静态原画证明了时间顺序 |

保留原作可辨认的人物动作关系、核心构图与有依据的主题情绪，不降格成只有配色相似的“电影感”。身份、台词、时代、场景与OUT仍服从当前故事；服装、道具、色块若承担原作辨识或象征功能，不随意删换。不可兼容时换画或处理冲突，不静默把致敬变成反讽。几何数值仅在消歧必要时使用，不能凭图片伪造精确焦段、距离或肢体角度。

## 原画配色转译为电影光影

此路由默认继承所选原画可见的配色关系，不只继承构图或一个主色。实际看图后提取主色、辅色、点睛色（若有）的相对面积、位置、明度、饱和度及冷暖关系，连同人物与背景的明暗分组一起保留。以原画实际色块层级为准，不强套04的60/30/10、固定10%强调色或通用青橙调色；同色人物可用明度、质感和轮廓分开，无需另造对比色。

把配色拆成三个相容的控制层：

- **物体固有色**：落在当前故事已有的服装、道具、墙面、地面与后景材质上，保留主要色块的承载者；已锁定身份/服装/场景不擅自改色。普通色块可借其他兼容的现有表面承接，承担关键辨识或象征功能的色彩与正史不兼容时，只询问该冲突或换画。
- **照明与阴影**：用场景合理的光源、方向、软硬、强弱、衰减和负补光，转译原画的受光人物、暗部群组、暖亮冷暗或其他实际冷暖关系。物体是红色不等于给全场打红光；不为凑配色新增无动机的灯具、天气、烟雾或彩色光束。
- **整体调色**：写明主辅色关系、饱和度层级、黑位、高光过渡与肤色表现，使布光和材质形成同一基调，而非整幅套单色滤镜。仅凭原画不声称测得精确HEX、色温、光比或LUT；必要参数是本次导演选定的实现方案。真人路线保留真实皮肤和材质，不自动变成油画纹理。

每条独立致敬段的【基础风格】写入本段完整的配色与光影基线，保留原有摄影机/镜头信息；【运镜与时间轴】将当前色块、受光面与暗部落实到具体人物、表面和前中后景，写清其如何组织视线与情绪。辨识瞬间同时兑现配色层级和人物关系；camera或人物移动后，按真实光源位置、遮挡及视角变化重算色块投影、受光与注意力，不把原画的画左暖/画右冷定死在所有机位。基线不逐CUT重复，只有当下位置与有意义的变化写进CUT。

## 写进运镜与时间轴

以剧情产生画面，不让人物无动机摆出姿势：

```text
IN：当前camera、实际画框、主体位置/可见面/任务
-> PATH：camera与演员各自路径、身体动作、表情触发和焦点交接
-> 辨识瞬间：核心姿态、接触、分组与构图同时可读
-> OUT：当前剧情的结果与下一镜接力
```

- 至少一个关键画面完整兑现本次选定的辨识关系，不能把所有主体拆成不相干特写。辨识瞬间可在IN、途中或OUT；不强制整段静止、不固定停留秒数，也不新增CUT来逐项展示。
- 原画画左/画右属于原画视点下的二维投影。辨识瞬间明确复现选定的分组、相对大小、接触和负空间；此前/此后camera移动或换角度时重新计算前中后景、可见面、遮挡、画面滑移/缩放与真实背景视差，不能让全段所有机位共用原画左右。每个相关CUT写明本镜IN、演员与camera各自PATH、可读变化及OUT。
- 六类信息可以在同一动作窗口同时成立，不机械拆成六镜或六个时段。固定光色基线仍放基础风格；关键人物此刻落入亮暗区、色块焦点和关系变化须在对应CUT具体落位。表情变化要有接收线索和可见结果，不能只写“震惊、悲伤、像原画”。
- 摄影机在关键动作成立前到达可读画框：按03/04重算人物投影、朝向、遮挡、真实后景与可达路径，05负责动作/表情及听者反应，06负责连续时序、容量、对白与接力。必要的手势不能裁出画幅，强虚化或装饰性绕拍不能毁掉关键人物关系。
- 绘画的复合透视不是可直接行走的三维房间。先匹配关键画面的投影，再构造与当前正史兼容的摄影距离、景别和前后动作；隐藏部分只作导演方案，不伪称由原图确认。camera变化可以改变前后构图，不能无交代移动墙体或改变人物相互关系。
- 静止画面不证明此前/此后的动作。让人物因当前剧情而起身、伸手、回头、承托或分离；动作路线、力量、接触、表情、台词相位和OUT用完整文字写清，不由画名或图片补全。
- 真人影视仍采用真实皮肤、布料、光源与空间；借用画作明暗和色块不等于加油画纹理、画布边框或二维纸片运动。只有用户明确需要这些外观时才进入风格选择。
- 静态身份与场景基线归原有文字锁定，摄影/光色基线归基础风格；逐CUT只写当前位置、可见内容与变化，不重复整份作品分析。2.5导演意图由当前剧本的戏剧功能推导，不写作者生平或“复刻原画”的制作目标。

## 两种交付内容

原画资料只给用户看：可见原画或已核实可打开的原画图片文件/直接图像链接、作品名/作者/具体版本、来源，以及简短匹配理由。需用户选画时每个正式候选都附图；仅有页面链接的作品只能列为待取图线索，不能冒充资料齐全的候选。

用户只要选画/方案时，到附图提案为止；用户要求直接编译且原画资料门已通过、无实质冲突时继续，不增加强制选画确认轮。用户明确要自己选才等待选择。

原画资料/提案置于可复制候选之外，优先在编译前的会话消息中展示。每条最终候选仍是一行段标题加原有五节，名画关系全部转成可独立执行的文字；图片、来源和提案不占生成字符预算，不送提示词验证器或冷审。用户只要提示词时省略长分析，已提供并看过的原画不再重复附送；不可把这项输出精简解释为跳过原画资料门。来源不得塞进生成正文。

## 一次检查

并入当前已选预检，不新增审核轮次：原画确已查看且用户已获得可见图/可打开图像文件；六类适用信息逐项有图像依据或已分清导演改编，并落入相关CUT；选定辨识关系在某一可读画面同时成立，运镜前后投影自洽；原画主辅色、冷暖与明暗层级已在基础风格明确，并由CUT中的实际人物/表面/光影兑现，不被通用配色或整体滤镜覆盖；人物/道具/OUT与正史兼容；去掉资料/提案后，提示词仍能重建当前动作、表情、位置、camera与时序，且没有名画句柄或管理说明。缺原画或未提供图片时退回资料门，不以冷审补救；只缺文字落位时修受影响CUT与接力。文字合格不等于成片已还原名画。
