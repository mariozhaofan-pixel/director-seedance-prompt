# 05E Expression Cues

scope: 表情僵硬、微表演精修、复杂情绪转换、关键近景细节不足，或明确要求表情描述/表情状态资产时按需读取。普通对白沿用05；本文件提供候选表达，不承担整段表演设计。

## 使用接口

[05表演模块](05_ACTION_PERFORMANCE_BODY_MECHANICS.md#情绪阶段与表演幅度门)是情绪管理、阶段、幅度、峰值和跨镜余态的唯一运行规则；[06对白协同](06_TIMELINE_EDITING_SOUND.md#对白动作与摄影协同)负责发声相位、哭笑呼吸与时间容量。已读取且未变的规则继续复用。

先沿05明确角色接收到什么、此刻想达成什么、采用何种表达策略，再从下表选择当前景别可读、与既有动作兼容的线索。优先用“部位/注意目标 + 可见变化 + 必要结束状态”；肌肉名称仅在确能消歧时补充，仍落到可见结果。情绪标签是检索入口，允许相近、混合及表外情绪；表中分号分隔的内容是候选，不是每次全部发生的套装。

视频中的表达直接写入既有CUT/BEAT，沿用原五栏；单独整理表情描述则交付所需描述，不扩展为整段视频编译。micro/local只处理当前指定表情及其直接连续性影响。无需为一个表情穷举全脸、数字化露齿/眼睑尺寸，或附加姿态、道具和运镜。

## 20类表情线索

以下是可供导演选择的实现，不是识别人物真实情绪的判定公式。人物目的、个体基线和实际参考优先；强度用表达是否启动、持续或收回，以及可见幅度区别。

| 检索情绪 | 可选可见线索 |
| --- | --- |
| 开心 | 嘴角随笑意展开；目光仍回应眼前对象；笑声结束后嘴角和呼吸逐渐回落。自然高兴可直接发生。 |
| 委屈 | 看向对方寻求回应，等不到答复后目光垂下；下唇轻颤或嘴角下落；眼缘湿润逐渐可见。按情境选择是否含泪。 |
| 紧张 | 注视在具体目标之间短促往返；眉间收紧；等待开口时嘴唇短暂压合，真正开口后按发声相位释放。 |
| 生气 | 视线停在冲突对象或其行为上；眉头收拢；下颌收紧后随回应放开。冷静质问也可保留较小外显幅度。 |
| 惊讶 | 视线骤然落到新信息；眉眼短暂打开或嘴唇分开；确认后转向新的理解，不持续停在同一张大嘴表情。 |
| 害怕 | 注视威胁或寻找具体出口；眉间紧张、呼吸变浅；嘴唇分开欲言又停。冻结、求助或应对由05结合人物任务选择。 |
| 悲伤 | 目光停在失去对象留下的位置；嘴角回落；眼缘湿润或呼气变长。落泪、抽泣及爆发按05选择，不把悲伤等同大哭。 |
| 厌恶 | 鼻梁轻皱或上唇短促抬起；视线从对象移开；嘴角收回。选择最可读的反应即可，鼻部不作为必填项。 |
| 惊喜 | 先确认意外对象，再让笑意展开；眉眼打开后趋于柔和；短促吸气转为笑或一句回应。与单纯惊讶的差异来自后续接受。 |
| 困惑 | 视线对照两个矛盾信息；眉头一侧略提或眉间收拢；嘴唇微启后停住，待新的证据出现才转为理解。 |
| 自豪 | 目光稳定接受对方的反应；嘴角轻扬后保持；原有眉间紧张松开。表达可分享喜悦，也可有意克制。 |
| 羞涩 | 对视后短暂避开，随后回看；笑意在嘴角出现；回应前一次短暂停顿。脸红、咬唇和遮脸均不是固定条件。 |
| 惆怅 | 目光留在有剧情意义的远处或空位；嘴角缓慢落下；一次较长呼气后注意力尚未回到手中任务。 |
| 平静 | 注视随对方或当前任务自然移动；眉间和下颌维持放松；呼吸连贯。保持对当下信息的回应，避免把平静写成凝固。 |
| 调皮 | 看向对方确认其反应；一侧嘴角略扬或笑意暂时收住；在笑点成立时重新对视。恶作剧动作仍来自原剧情。 |
| 冷漠 | 看过对方后把注意力转回原任务；嘴角保持平直；回应迟缓或短促。外在疏离不自动说明内心毫无波动。 |
| 焦虑 | 注意力反复回到尚未解决的具体问题；眉间持续紧张；准备说话又等待，呼吸难以恢复原节奏。避免无目标快速扫视。 |
| 惊恐 | 威胁被确认时目光停住、呼吸骤断或急促吸气；眉眼打开或面部僵住；随后出现求救、逃离或失去回应的具体后果。按人物条件选取，不把全脸写成最大张力。 |
| 欣慰 | 看见结果后原有紧张松开；目光停在对方身上；呼气变长，嘴角可轻扬也可维持。只释放此前成立的紧张。 |
| 期待 | 注视即将给出答案的人或事物；眉眼略打开；回应将至时嘴唇微启或笑意初现。保留等待中的信息变化，不持续瞪眼。 |

## 组合、转换与交付

使用05的因果链串联“当前表情、触发、处理、可见变化、余态”。需要区分表里时，挑选有用途的不同通道，例如嘴角维持礼貌笑而视线短暂回避；这是该情境的表达选择，不据此定义真笑/假笑。自然笑不用补憋笑，情绪转换也不必经过肌肉对抗。嘴部持续发声时，候选嘴部变化按06安排到真实停顿，不另改台词。

示例：已有中近景中，她带着礼貌笑听见拒绝，视线停在对方脸上；说完原句后嘴角才开始回落，呼气变长。下一镜从尚未散去的笑意承接，继续当前反应，不再重复“听见拒绝”。

远景若看不清面部，回到05选择头肩、路线、距离或既有任务的可读证据；确需读脸时，再按当前授权范围调整构图。表情精修不自动改变机位、原台词、时长或无关OUT。

## 表情资产与项目管理接口

文字足以控制时直接编译。用户明确要求表情参考图、当前用途确需可复用的表情图，或实际结果显示必须补参考时，才经[02F资产预制](02F_HIGGSFIELD_ASSET_PREPRODUCTION.md)和[02B角色板接口](02B_CHARACTER_BOARD.md)制作必要状态。同一表情跨镜出现本身不要求生成图片；20类词库也不对应默认20张资产。

中性身份板继续采用内置Higgsfield唯一标准。表情图引用已有身份基线，作为独立状态资产保留，主身份板不因强表情被改写。交接角色、母图精确资产ID与修订ID、目标表情、用途/适用镜头及需保护维度；局部修图只修改授权部分。无生图模式沿02F转02G交付对应提示词。

确实作为视频输入时，按[02参考绑定](02_REFERENCE_ROUTER_AND_LOCKS.md)将表情图限定为指定CUT的表达维度；身份、服装和比例沿用既有主参考，当前动作、场景和摄影由本段建立。静态表情图只能证明可见状态，不能代替动态转换与呼吸时序。只有真实提供给生成器的素材才写引用行，参考谱系和制作说明留在台账。

结果交回[02A工程流程](02A_PROJECT_WORKFLOW.md)，记录表情用途、母图精确资产ID/修订ID、实际文件与验收状态。已选飞书模式时，按[02H](02H_FEISHU_ASSET_WORKSPACE.md)先查已有资产再补缺，同步到原资产库的图片与对应生图提示词MD；文字表演随原段落提示词MD同步。首版沿用既有schema，母图谱系与适用镜头写入生图提示词文件的制作信息和台账，不进入可复制生成正文；`状态`仍是制作进度，`来源A`仍是场景反向图专用。新表情及改版按原资产/修订合同处理，不覆盖已验收基线。
