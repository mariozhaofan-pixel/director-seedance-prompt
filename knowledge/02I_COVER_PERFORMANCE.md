# 02I 演唱与翻唱接口

本文件只写导演侧的路由与差异，不维护第二份歌曲规则。触发后读取内置[翻唱演唱规则](../capabilities/cover-performance/COVER_PERFORMANCE.md)，按其任务阶段读取对应参考。翻唱能力随导演包提供并只在本仓库维护，不调用其他翻唱技能。

## 路由与输入

纯演唱为cover，剧情内穿插演唱为mixed；背景配乐、无声卡点、只有歌曲配乐但人物不唱的MV仍用02D/06B。歌曲分离、转写与切段由本能力完成；新歌创作、角色新音色歌声生成/转换需真实可用的音频工作流，不靠导演提示词假称已完成。

按翻唱规则“状态与读取”传入现有素材与真实状态，沿用已有决定，不重问工作方式、版本、声音或图像来源。

素材建议只加载翻唱规则及适用音频参考；表演微修只读目标句与所需表演规则；通用草稿加载翻唱规则和本接口，采用五栏但不虚构版本/Tmax或运行模型校验。编译具体模型时进入导演流程：资产仍交02A/02F/02B，沿用项目已选的工作区与登记方式；翻唱模块不创建第二套工程、角色板或资产登记。

## 整曲自动入口

歌曲文件与角色相关资产已给齐时，按[自动音频预处理](../capabilities/cover-performance/references/audio-preparation.md)运行内置`capabilities/cover-performance/scripts/prepare_song.py`，输出放当前项目的音频工作目录；安装、下载、分离、转写与切片由agent执行，脚本不借用其他技能的绝对路径。歌曲参考与视频段的时长上限按[参考音频总额度](../capabilities/cover-performance/references/reference-audio-budget.md)计算，当前版本Tmax计入其中。读`compiler-input.json`后，各段真实`vocals.wav`作为歌曲参考交02D与本接口，`instrumental.wav`备用，角色声线单列。复核候选歌词与切点后按五栏编译；候选未复核则保留草稿状态。

用户要求整首自动流程即继续处理全部授权段，不在分轨或02A默认两段批次后停住。用户只要分离时交该阶段；只改表演、已有预处理结果、已有最终音轨时复用相应材料。曲目或参数变化才重算依赖，不重新设计已有角色。

新曲有歌名时执行[公开歌词核对](../capabilities/cover-performance/references/lyric-verification.md)，来源与差异记入现有台账。

## 规则分工与覆盖

| 决策 | 演唱区间的有效规则 |
| --- | --- |
| 歌词、原气口、长音、留白 | 翻唱规则锁定；不能按戏剧OUT改词、补词或擅自压缩 |
| 时间 | 音频实测/核准边界优先；对白5.5字/秒、高潮比例、默认段长和凑整秒不用于演唱 |
| 峰值与OUT | 随实际乐句变化；可用视线/姿态/气息收束，不强加关系或权力反转 |
| 声音 | 区分歌曲参考、声线、最终演唱音轨；保留选定清唱/伴奏/弹唱，覆盖冲突禁乐项 |
| 声音身份 | 参考声线控制音色身份，歌曲控制音区变化、旋律与发音节奏；不把口播习惯套到唱词 |
| 摄影 | 当前用户/项目要求优先；固定机位演唱不因无运镜判退化；没有基线才轻微受控手持 |
| 分段 | 上限按参考音频总额度计算；整曲连续覆盖，已有选段的截取/保调加速按该文件执行，不补静音撑满视频 |
| 格式、工程和审核 | 导演入口负责；翻唱交付检查并入本次预检，不另起审核或强制安装依赖 |

mixed只覆盖演唱部分。相邻对白、动作、空间与OUT继续遵守原导演规则；与歌声同时的动作按真实并行占用，串行动作不能挤掉发音时间。

## 输出格式

演唱五栏映射只在[导演统一格式](../capabilities/cover-performance/references/director-output.md)维护。本入口负责具体模型规格、工程与包络，不恢复旧四段式。

## 交接与验证

全局歌曲范围先规划，未指定整首自动流程的工程沿用当前两段批次；用户要求整首自动流程或一次给完整范围则覆盖为全部授权段，独立建议/微修不启动批次。每段歌词范围独立，唱词、发声相位、姿态和镜头接力交回02A/06，不在新段重复起唱。

普通预检合并[翻唱交付检查](../capabilities/cover-performance/references/delivery-and-repair.md)；micro仅核对差分及受影响接力。精确模型稿继续用原validate_prompt.py检查五栏等机械项，可靠小数时码传decimal-allowed；它不校验歌曲音高或人声边界。需要复核多段/偏移时可按[时间计划](../capabilities/cover-performance/references/timing-plan.md)使用内置计算脚本，结果只证明所声明数据的算术一致性。

返回完整本轮提示词、正文状态、时间证据状态、当前步骤生成条件及必要受影响文件。后续生成仍按实际工具与授权执行，不因文字通过就声称音频已制作、已上传或口型已同步。
