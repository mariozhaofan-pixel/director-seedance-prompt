# 02I 演唱与翻唱接口

本文件只做导演适配，不维护第二份歌曲规则。由根入口触发后读取内置[共用翻唱规则](../capabilities/cover-performance/COVER_PERFORMANCE.md)，按其任务阶段读取对应参考。全部资源随导演包提供，不要求另装cover-performance-director，不跳转到独立版SKILL.md。

## 路由与输入

纯演唱为cover，剧情内穿插演唱为mixed；背景配乐、无声卡点、只有歌曲配乐但人物不唱的MV仍用02D/06B。歌曲分离、转写与切段由本能力完成；新歌创作、角色新音色歌声生成/转换需真实可用的音频工作流，不靠导演提示词假称已完成。

传入现有素材与真实状态、音频版本/范围、确认歌词和重复句出现次序、各句演唱者、音轨处理、声音组织、精确时间证据、人物声线、构图/光影、用户动作顺序与禁止项。沿用已有决定，不重问工作方式、版本、声音或图像来源。

素材建议只加载共用入口及适用音频规则；表演微修只读目标句与所需表演规则；通用草稿加载共用规则和本接口，采用五栏但不虚构版本/Tmax或运行模型校验。编译具体模型时进入原导演流程，资产仍交02A/02F/02B，已有工作区管理与同步策略继续沿用；翻唱模块不创建第二套工程、角色板或资产登记。

## 整曲自动入口

歌曲文件与角色相关资产已给齐时，读取[自动音频预处理](../capabilities/cover-performance/references/audio-preparation.md)并运行内置`capabilities/cover-performance/scripts/prepare_song.py`。输出使用当前项目的音频工作目录；安装、下载、分离、转写与切片由agent执行。共用脚本可独立运行，不依赖另装翻唱skill，也不借用其他技能的绝对路径。

视频段默认≤30秒；歌曲参考按[总额度规则](../capabilities/cover-performance/references/reference-audio-budget.md)先扣声线预留与实际其他音频，默认30−4=26秒，再与明确模型/用户更短上限取较小值。使用`--voice-reference`传入声线；已有选段超限用内置`fit_reference_audio.py`按完整乐句截取或温和保调加速，同步更新时码，不在参考WAV内补视频收尾静音。读`compiler-input.json`后，将各段真实`vocals.wav`作为歌曲参考交02D/本接口，`instrumental.wav`备用，角色声线单列。复核候选歌词与切点后按五栏编译；候选未复核则保留草稿状态。原歌手音色不会因分离而变成角色音色，后续生成按用户声音要求和实际工具接续。

用户要求整首自动流程即继续处理全部授权段，不在分轨或默认两段批次后停住。用户只要分离时交该阶段；只改表演、已有预处理结果、已有最终音轨时复用相应材料。曲目或参数变化才重算依赖，不重新设计已有角色。

新曲有歌名时，agent继续执行内置[公开歌词核对](../capabilities/cover-performance/references/lyric-verification.md)，按歌手、原作、版本和当前ASR排除同名错配；来源与差异入现有台账。实际翻唱改词/重复优先，歌词文本修订不自动改写音频或冒充重新对齐。疑似误识广泛时按共用工具做一次更强ASR复核，复用既有分离结果。

## 规则分工与覆盖

| 决策 | 演唱区间的有效规则 |
| --- | --- |
| 歌词、原气口、长音、留白 | 共用翻唱规则锁定；不能按戏剧OUT改词、补词或擅自压缩 |
| 时间 | 音频实测/核准边界优先；对白5.5字/秒、高潮比例、默认段长和凑整秒不用于演唱 |
| 峰值与OUT | 随实际乐句变化；可用视线/姿态/气息收束，不强加关系或权力反转 |
| 声音 | 区分歌曲参考、声线、最终演唱音轨；保留选定清唱/伴奏/弹唱，覆盖冲突禁乐项 |
| 声音身份 | 参考声线控制音色身份，歌曲控制音区变化、旋律与发音节奏；不把口播习惯套到唱词 |
| 摄影 | 当前用户/项目要求优先；固定机位演唱不因无运镜判退化；没有基线才轻微受控手持 |
| 分段 | 先扣参考音频总额度，默认歌曲≤26秒、视频≤30秒；整曲连续覆盖，已有选段允许的截取/保调加速按共用预算规则执行，不补静音撑满视频 |
| 格式、工程和审核 | 导演入口负责；共用检查并入本次预检，不另起审核或强制安装依赖 |

mixed只覆盖演唱部分。相邻对白、动作、空间与OUT继续遵守原导演规则；与歌声同时的动作按真实并行占用，串行动作不能挤掉发音时间。

## 五栏映射

独立翻唱与本路由均默认使用[导演统一格式](../capabilities/cover-performance/references/director-output.md)。本入口继续负责具体模型规格、工程与包络；不恢复旧四段式。

- 【角色/场景/素材锁定】：沿用唯一主行；列真实视觉素材、角色声音身份、歌曲参考或最终音轨及各自职责。声音素材单独成行，不虚构句柄/绑定。
- 【基础风格】：沿既定光影与摄影基线，不重复人物外貌或歌词。
- 【运镜与时间轴】：CUT是真切镜，连续乐句用同CUT中的BEAT。每句写完整唱词、开始/持续/结束、口型与气口、眼神/姿态进入及余态；覆盖实际留白。2.5仍用前提、核心关系、导演意图、演员指令、对白规则五行；对白规则包括本段唱词白名单，导演意图可为情绪与注意力变化，不凭歌曲发明剧情反转。
- 【声音设计】：写本次真实声音组织后，写“参考音频的完整歌词如下：”，完整列该生成段所用范围的确认歌词。纯器乐段明确无人声。唱词与时间轴逐字一致，保留重复句；只禁未请求的额外配乐，不能禁掉已选伴奏或乐器。
- 【画面限制】：沿本轮身份、结构、文字等要求，口型发音优先，不用固定抿嘴/冻脸达成稳定。

精确人声区间与动作窗口分别可辨，源时间/整片/段内时间的映射留在台账；模型正文只放该段实际可执行时序。生成平台不能读的源音轨、后期挂接、证据状态和管理说明不塞进正文。没有可靠时码时给有序节点草稿；严格逐句要求未满足不得标为已校准。

## 交接与验证

全局歌曲范围先规划，未指定整首自动流程的工程沿用当前两段批次；用户要求整首自动流程或一次给完整范围则覆盖为全部授权段，独立建议/微修不启动批次。每段歌词范围独立，唱词、发声相位、姿态和镜头接力交回02A/06，不在新段重复起唱。

普通预检合并共用交付检查；micro仅核对差分及受影响接力。精确模型稿继续用原validate_prompt.py检查五栏等机械项，可靠小数时码传decimal-allowed；它不校验歌曲音高或人声边界。需要复核多段/偏移时可按[时间计划](../capabilities/cover-performance/references/timing-plan.md)使用内置计算脚本，结果只证明所声明数据的算术一致性。

返回完整本轮提示词、正文状态、时间证据状态、当前步骤生成条件及必要受影响文件。后续生成仍按实际工具与授权执行，不因文字通过就声称音频已制作、已上传或口型已同步。
