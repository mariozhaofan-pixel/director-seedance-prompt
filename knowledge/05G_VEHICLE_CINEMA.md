# 05G Vehicle Cinema

priority: optional
scope: 画面里有需要保持身份的汽车、摩托等车辆主体，或用户要做车拍、驾驶戏、汽车产品展示时加载。负责车辆身份锁、车身左右、机位方位、日常驾驶物理、车漆与玻璃反射、产品展示段的写法和车辆专项修复。实际追逐、碰撞、车战的动作预算与物理仍归 [05D](05D_ACTION_SCENE_PHYSICS.md)，两者并用时05D决定动作，本模块只补车辆身份和光学。`content_purpose` 按 [00核心卡](00_CORE_CARD.md) 增补级别一节判断，本模块只消费。

## 一、车辆身份锁

车辆在【角色/场景/素材锁定】里占一条实体主行（[02](02_REFERENCE_ROUTER_AND_LOCKS.md) 实体主描述行唯一化），只写不随镜头变化的身份：

- 车型与代际：用户有权使用并明确要求时写品牌车型；否则写车身类型、比例和造型特征（低矮双门跑车、长车头短车尾、溜背、方正越野车身），品牌规则同 [资产预制](../capabilities/asset-preproduction/ASSET_PREPRODUCTION.md) 的“品牌或受保护设计”。
- 车身颜色与漆面：颜色加漆面类型（素色、金属漆、珠光、哑光、改色膜），哑光和金属漆的反射完全不同，必须写明。
- 轮毂与套件：轮毂样式、颜色、尺寸感；宽体、尾翼、前唇、侧裙等改装件逐项写，没有的不写。
- 车灯造型、车门数、敞篷或硬顶、内饰主色。
- **左舵或右舵**：只要有人上车、开车或镜头进车内，就写在主行里，例如“左舵，驾驶座在车身左侧”。这是驾驶位跳边的第一道锁。

会变化的状态写在对应CUT，不进主行：大灯/尾灯/刹车灯开关、前轮转向角、车窗升降、门开合、雨水泥点灰尘、悬挂姿态、损伤。跨段保留的状态（溅满泥、车门凹陷、车窗开着）登记到项目层 `状态事件链.md`（[02K](02K_PROJECT_SLOT.md)）。

车牌和车标是画内文字。需要读清时按资产预制的文字资产做图并写完整内容；不需要读清时，用机位和焦段让车牌处在侧面看不到的角度或焦外，不写“空白车牌”“无字车牌”。

车辆参考图默认只授权身份维度：车型、颜色、轮毂、套件、灯型（[02](02_REFERENCE_ROUTER_AND_LOCKS.md) 维度锁定）。参考图里的车身角度、背景和光不控制当前镜头，否则模型会把整张图贴进画面。

一个画面里有几台车就写几台，各自一条主行、颜色和外形拉开；需要时写“画面里只有这一台车”（同 R9）。

## 二、车身左右：第三套左右

[03](03_VISUAL_GRAMMAR_AND_SCENE_ROUTER.md) 已区分画面左右、世界方位和人物解剖左右。车辆另有一套：

| 写法 | 唯一含义 | 规则 |
| --- | --- | --- |
| `vehicle-local left/right`、车身左侧/右侧 | 坐在车内朝车头看时的左右 | 车怎么转、镜头怎么换，车身左侧永远是同一侧 |
| 驾驶侧／副驾侧 | 由左右舵决定的车身一侧 | 优先用这个说法，读者和模型都不容易反 |
| 车头朝向 | 车头在当前画面里朝哪 | 每个车辆CUT都写：车头朝画左、朝画右、朝镜头、背离镜头 |

- **车头朝哪边，就看到车身哪一侧**：车外机位看车，车头朝画左时看到的是车身左侧，车头朝画右时看到的是车身右侧，前3/4、正侧、后3/4都一样。所以左舵车要拍驾驶侧，车头就朝画左；右舵车要拍驾驶侧，车头就朝画右。两者写反就是一个不可能的画面，模型只能随便选一边。车内机位朝外看时方向相反，不套这条。
- 车身左右和人物解剖左右一样，进提示词时**同一句给出画面投影**：“（左舵车）camera在驾驶侧前3/4，车头朝画左，驾驶侧车门正对镜头”。只写“车左侧”不写画面关系，模型常随机选一侧。
- 换机位或车辆转弯后，车身左右不变，画面投影重算（[03](03_VISUAL_GRAMMAR_AND_SCENE_ROUTER.md) 投影契约）。
- 行驶中的车，画面方向就是轴线：连续几镜车头都朝画右，就一直朝画右；要换方向，先给一镜车辆转弯，或用正前/正后中性角度过渡。
- 世界方位（东南西北、路的哪头）只留编译卡，规则同 R3。

## 三、机位：先定站位，再定运动

车辆镜头先定摄影机在哪、多高、看哪里，再接 [04](04_CAMERA_LIGHT_COLOR_STYLE.md) 的运镜式。站位按下面四项组合写进 IN：

```text
方位（相对车身） + 高度（相对车身部件） + 水平或倾斜 + 景别/距离 → 再写运动和终点
```

**方位**

| 方位 | 画面里读到什么 | 常用于 |
| --- | --- | --- |
| 正前 | 车头脸谱、对称、正面压迫 | 驶来逼近、对峙、收尾定格 |
| 正后 | 尾灯、道路向远处延伸、离开 | 驶离、跟车、结尾 |
| 正侧 | 车身比例、轴距、轮毂转动、横向速度 | 掠过、平行跟拍 |
| 前3/4 | 车头和一侧车身同时可见，体积最足 | 静态主镜、低速移动、广告主视觉 |
| 后3/4 | 尾灯、后轮拱、宽体线条和离场方向 | 夜景尾灯、加速离开、转场 |

前3/4和后3/4大约在30°到60°之间按车型调：车头长、宽体或很低的车，角度偏侧一些才读得出比例。3/4机位同时决定看到的是驾驶侧还是副驾侧，要和人物动线一起选。

**高度**用车身部件做刻度，不写抽象的“低角度”：轮毂中心、车灯中心线、腰线、车顶、高于车顶。经验：低到车灯附近，车显得重、贴地、有力量，主任务是看车；升到车顶以上或俯拍，车和道路、建筑、人的位置关系变清楚，主任务是看空间；顶视只用来读路线和几何，人物情绪要靠前后镜补。

**倾斜**：默认水平。只有失控、危险、主观不安等叙事动机时才用 Dutch angle，写明倾斜角度并在本段回正（[04](04_CAMERA_LIGHT_COLOR_STYLE.md) 景别库 Dutch angle 行）。

几个常用起点，按项目改：

- 力量主镜：前3/4，低于车灯，中近景，极慢 dolly in。
- 速度：正侧，车灯到腰线高度，中景，同速 lateral tracking。
- 离场：后3/4，平视，中远景，camera减速让车拉开距离。
- 建立空间：高于车顶的高机位或顶视，大全景，固定或缓慢升降。
- 紧张驾驶：前3/4或正侧，低机位，轻微 Dutch，快速跟拍，持续不超过一个动作。

## 四、车拍运镜

每个动态车辆CUT分开写三件事，再接 IN/PATH/OUT：车怎么走、camera怎么移、camera一直看着哪里。

| 运镜 | 写清 | 稳定写法 |
| --- | --- | --- |
| 平行跟拍 `lateral tracking` | camera在车哪一侧、横向距离、与车同速 | （左舵车）camera在驾驶侧约5米，与车同速同向横移，全程拍到车身侧面，车头始终朝画左，背景从画左往画右流过 |
| 前导跟拍 `lead tracking` | camera在车头前方倒退，距离是否保持 | camera在车头正前方约8米倒退，与车同速，车头脸谱保持在画面中央 |
| 追尾跟拍 `follow tracking` | camera在车后，距离固定、拉近还是落后 | camera在车尾后方约6米，车加速后距离逐渐拉开，车尾在画面中变小 |
| 超越 overtake | camera比车快，从车后经侧面移到车前；车仍直行 | （左舵车）camera从后3/4以快于车的速度沿驾驶侧前移，经过正侧，停在前3/4，车始终沿车道直行，车头始终朝画左 |
| 绕车 `camera orbits` | 车静止或很慢；圆心、角度、方向、终点 | 车停在原地，camera绕车身中心顺时针走120°，从前3/4到后3/4，高度保持车灯中心线 |
| 固定掠过 `locked-off` + pan | 车从哪边入画、哪边出画 | camera固定在路边车灯高度，车从画右深处驶来，经过近景，向画左出画；镜头随车头 pan 跟随一段后停住 |
| 车内 | camera在副驾、仪表台或后座，驾驶者在画面哪边 | （左舵车）camera位于副驾座位高度朝驾驶侧拍，驾驶者在画左，车窗外景物向车尾方向流过 |
| 车外到车内一镜到底 | 经由打开的车窗或车门进入 | camera从驾驶侧车窗外低速推进，驾驶侧车窗正对镜头，经由降下的车窗进入车内，停在驾驶者侧脸近景 |

- 同样是平行跟拍，方位不同，看到的东西也不同：正侧看速度和车身比例，前3/4看车头力量和立体感，后3/4看尾灯、离场感和道路方向。选定后整段保持这个相对方位。
- 平行跟拍、超越、绕车是三种不同运动。只写“跟拍”“环绕感”，模型常把直行车的跟拍做成绕车，见第八节。
- 一个短CUT一个主运镜（[04](04_CAMERA_LIGHT_COLOR_STYLE.md)）；平行跟拍接绕车，中间要切镜或给一个明确的过渡点。
- camera不穿过车身、玻璃和墙；进车内必须经过开着的门窗。
- **速度证据一致**：车速、轮毂转速、背景视差和运动模糊必须是同一个速度。“轮毂辐条转出模糊，近处护栏快速掠过，远处楼群缓慢平移”，三者互相印证。车速快而轮毂静止，或背景不动，都会被读成车在原地漂。
- 拍摄器材不进正文：拍摄车、吸盘、摇臂车、稳定器、云台、无人机都不写，只写观察高度、路径和画面结果（[04](04_CAMERA_LIGHT_COLOR_STYLE.md) 术语对照后的说明）。

## 五、日常驾驶物理

追逐、漂移对抗、碰撞归05D；这里管普通驾驶：

- **起步**：车身重心后移、车头轻微抬起，驱动轮先发力；起步到看得出速度要有时间，不在同一拍里直接高速。
- **制动**：刹车灯先亮，车头下沉、车尾抬起，停稳时有一次轻微回弹；驾驶者身体随惯性前倾再回到座椅。
- **转向**：方向盘先转，前轮转角可见，车身才开始偏航；车身向弯道外侧侧倾，驾驶者身体朝弯外微倾。
- **接地**：轮胎始终压在路面上，有接触阴影；路面起伏时悬挂上下吸收，车身不跟着硬跳。湿路面轮胎后方带起水雾和水花。
- **上车顺序**：开门、侧身、坐入、关门是四个动作，一个短CUT装不下。时长不够就切镜省略入座，下一镜直接从“已坐在驾驶座”开始，并按 R12 写清新的起始状态。
- 车内人物：车窗外的景物移动方向、速度和车辆转向一致；窗外光随遮挡物掠过脸部（与 [phone-vlog](styles/phone-vlog/phone-vlog.md) 车内一行同理）。
- **驾驶者表演**：视线以前方道路为主，确认后视镜时先动眼睛再动头；紧张时肩颈绷紧、握方向盘的手指收紧、呼吸变深，不靠一直瞪眼。打方向、换挡等手上动作跟着当前路况和车速走。开窗或敞篷时头发、衣服和脸部受风，风的强弱和车速相称；车窗关闭时车内空气稳定。

## 六、车漆、玻璃与反射

车漆可以理解成一层清漆镜面盖在底色上：清漆映出环境，底色决定暗面颜色。写车辆光影时：

- **每道高光都有来源**：写出它映的是什么。“头顶长条天光在引擎盖上映成一道长亮带”“路灯在车门上映出一个拉长的亮点”。说不出来源的亮点就是凭空多了一盏灯（同 [04](04_CAMERA_LIGHT_COLOR_STYLE.md) 逆光规则）。
- **反射跟着视差走**：camera或车移动时，环境反射按环境的速度滑过车身，车身本体不动。这是车看起来像实拍而不是CG的关键证据，运动镜头里至少写一处。
- **用侧光或侧逆光沿腰线描出轮廓**；正面平光会把车身压平。
- **深色车靠反射边缘读形状**：写出沿车身曲面走的反射线；**白色和浅色车防过曝**，靠阴影面和接缝读体积。
- **哑光漆**没有清晰镜面反射，只有柔和的明暗过渡，不写环境倒影。
- **前挡风玻璃**：天空反射强时会盖住驾驶者的脸。要看见驾驶者，就写机位斜侧对挡风玻璃、头顶有树荫或高架遮住天空、车外环境较暗，或从降下的侧窗拍；只压低机位去不掉这层反射。
- **车灯是画内光源**：大灯照亮前方路面和雨雾，尾灯红光映在湿地面上，随车移动而移动；熄灯时不写光束。
- **夜景**：暗部仍保留路面纹理和车身反射，不做成全黑加几块霓虹（[04](04_CAMERA_LIGHT_COLOR_STYLE.md) 黑位与 [04A](04A_LIVE_ACTION_TEXTURE.md)）。
- 雨中车身：漆面上有水珠或水膜，雨刷动作和车速相称，轮胎溅水（[04](04_CAMERA_LIGHT_COLOR_STYLE.md) 天气接触）。
- 材质：轮胎橡胶是哑光，刹车卡钳、拉丝金属和碳纤维写清纹理方向（[04](04_CAMERA_LIGHT_COLOR_STYLE.md) 各向异性高光）。

摄影机系统按 [04](04_CAMERA_LIGHT_COLOR_STYLE.md) 摄影机与光学镜头风格库选一套写进【基础风格】，一段不堆多个机身；高速插镜和稳定器式运动按04的“高速与稳定运动不按机身写”处理。

## 七、产品展示段（content_purpose=product）

按00核心卡判为产品展示时，这一段的任务是让观众**看清楚、看出质感、相信它真实存在**，不是讲故事：

- 增补按00核心卡的“最小”执行：不新增剧情转折、台词、人物关系和听者反应；有人物时，人物只承担与车辆的接触任务（走近、抚过车身、开门、坐入）。
- 每个CUT的作用写成看哪个设计特征：车头灯组、腰线、轮毂、尾灯、内饰材质、整车比例。交付表“镜头｜画面内容｜作用”（[02A](02A_PROJECT_WORKFLOW.md)）照这个写。
- 运镜偏 ease-in/ease-out、匀速中段、在特征上柔和落幅（[04](04_CAMERA_LIGHT_COLOR_STYLE.md) 运镜速度表）；产品细节镜默认不叠加手持和画幅呼吸感（[04](04_CAMERA_LIGHT_COLOR_STYLE.md) 呼吸感的关闭情况）。
- 光以塑造车身为主：侧光、侧逆光、大面积柔光反射在车身上形成连续的长亮带；每道亮带写来源。
- 2.5的五行这样落：前提＝车辆、场景与时间；核心关系＝车与空间（或人与车）的关系；导演意图＝观众先看到什么、最后记住哪个特征；演员指令＝有人物时写其接触任务，无人物时写“本段无演员，车辆为唯一主体”；对白规则＝无对白，或写明旁白来源。
- 默认仍是“无背景音乐”；发动机声、轮胎滚动、关门声、环境声写清来源，用户要求配乐时按入口覆盖。
- 剧情片里夹的产品镜（`content_purpose=mixed`）只在产品镜所在CUT按本节写，剧情CUT照常导演扩展。

## 八、车辆常见问题与修法

审片按这个顺序看：身份（车型、颜色、驾驶者）→ 结构（轮毂、车灯、车门、内饰有没有畸变）→ 空间（左右、驾驶位、道路方向）→ 动作（起步、转向、制动有没有重量）→ 摄影机（轨迹有没有变成另一种运镜）→ 光线（反射和阴影有没有来源）。

返修按入口的 micro/local 范围：保留满意的身份、场景、光色和动作，只改失败的那一层。修法都写成正向状态，不写“不要绕车”之类的否定句（[08_MODEL](08_MODEL_QC_REPAIR.md) 机位连续性靠否定句）。

| 现象 | 常见原因 | 修法 |
| --- | --- | --- |
| 平行侧跟被做成绕车 | 只写“跟拍”“环绕感”，没锁camera在哪侧、和车什么关系 | 写camera固定在驾驶侧约N米、与车同速横移、全程看到车身侧面、车头始终朝同一画面方向（左舵车朝画左）；车沿车道直行 |
| 直行车被转向或漂移 | 运镜词里带了弧线，模型让车配合镜头 | 先写“车沿车道直线前进”，再写camera路径；车的路线和camera路线分句写 |
| 驾驶位跳边 | 主行没锁左右舵，车内镜没写驾驶者在画面哪边 | 主行写左舵/右舵；每个车内CUT写“驾驶者坐在画左/画右的驾驶座，双手在方向盘上” |
| 驾驶侧和车头方向对不上 | 左舵车写了驾驶侧又写车头朝画右，画面不可能成立 | 按第二节改：车头朝哪边就看到车身哪一侧 |
| 轮毂、套件、颜色漂移 | 只有一张参考图，或参考职责没限定 | 做车辆多视图资产（资产预制“车辆补充”），参考只授权身份维度 |
| 车像浮在路面上 | 没写接地和悬挂 | 补轮胎接触阴影、悬挂随路面起伏、轮胎与地面同一光向 |
| 速度感矛盾 | 车速、轮毂、背景视差各说各的 | 用第四节“速度证据一致”的一句话统一 |
| 镜头穿过车身 | 车外进车内没有开口 | 写经由降下的车窗或开着的车门进入 |
| 车身反射像贴图或乱闪 | 高光没写来源，运动中反射不动 | 每道高光写来源；运动镜头写反射随视差滑过车身 |
| 车牌、车标乱码 | 文字没有资产 | 需要读清就做文字资产；否则让车牌处在看不到的角度或焦外 |

## 九、示例：同一镜的两种写法

这台车按左舵写。

不合格：

```text
CUT 2：镜头跟着黑色跑车快速运动，电影感绕拍，车辆向前冲刺。
```

合格：

```text
CUT 2（4-8秒）：黑色跑车沿城市快速路中间车道直线前进，车头朝画左；camera在驾驶侧约5米、车灯中心线高度，与车同速向画左横移，全程拍到驾驶侧车身，中景收进整车和一段护栏。轮毂辐条转出模糊，近处护栏从画左快速掠过画右，远处楼群缓慢平移；路灯在车门和后翼子板上映出拉长的亮点，随车前进从车头滑向车尾。结束时车身仍完整在画面中部，车头朝画左。
```
