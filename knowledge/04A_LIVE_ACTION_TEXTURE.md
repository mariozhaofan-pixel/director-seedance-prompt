# 04A Live Action Texture

priority: optional
scope: 真人或写实质感项目（含超写实 CG、数字人和写实三维人物）、用户点名“光影精修”“抗CG”“实拍质感”时加载，与已选光影运镜规则或库内风格包并用；不替换它们，冲突时以用户规则和已选风格为准。动画、卡通渲染项目默认不加载。

## 一、逐镜光影（启用本模块时）

- 每个CUT可加一句“光影：”，写两件事：光此刻落在哪、穿过什么、照亮什么、把什么留在暗里；光在这一镜里怎么变化。
- 光的变化挂在别的东西的运动上（树冠被风推动、水洼被踩碎、人物进出亮斑），不写“光自己在动”。
- 物理细节按 [04 光影物理补充](04_CAMERA_LIGHT_COLOR_STYLE.md) 执行：光不带颜色、遮挡物决定软硬、逆光亮线只在外轮廓、极亮背景上没有边缘光。

## 二、抗CG质感

- 总思路：少给模型需要“渲染”的东西，减少画面里被照亮且清晰的表面积，而不是反复强调“实拍”。
- 可用的通用质感句（按项目调整）：真人电影摄影质感，自然肤色，受控反差，柔和高光滚降，暗部保留纹理，色彩分离清晰，人物与环境的色温和曝光一致，轻微细腻胶片颗粒，无细节堆砌，无虚假HDR感。
- 少用材质品质词（汗珠晶莹、油光、水润、反光闪闪），它们容易拉向CG或美妆广告；改用胶片型号、纪实质感、结构性瑕疵。剧情里真的淋雨、出汗时照写接触证据（湿贴、滴落、衣料吸水变重，见 [04 天气接触](04_CAMERA_LIGHT_COLOR_STYLE.md)），只避开这类美化形容。
- 最暗处不是纯黑，仍看得出一点起伏；高光柔和滚降，不过曝成死白。
- 生物、怪物、道具优先写成现场实体特效（实体服装、机械假体），玩具感靠生产痕迹（分模线、缩痕）而不是“光滑”。
- 视效产生的光照亮附近的皮肤、地面、烟尘，并随距离衰减。

## 三、写实人物肤质与眼睛

用于真人、超写实 CG、数字人和写实三维人物的近景与中近景；远景、剪影和面部被遮住的镜头不用。卡通、二次元和风格化三维不因为出现“3D”“CG”就套用，用户明确要真实人类质感时才用。

- **先锁不变项**：身份、年龄、原始肤色、五官结构、妆容和发型不因“更真实”而改变。不默认美白、提亮、年轻化或瘦脸，写实 CG 人物不改成照片，除非用户要求。
- **肤色有层次**：底色不是一块均匀颜色，脸颊、鼻翼、耳缘、嘴唇有轻微血色和冷暖差，额头和下颌略不同。
- **纹理跟景别走**：近景看得到细毛孔、绒毛、唇纹，强弱随年龄、妆容和环境；中景以后只保留肤色和面部体积。纹理不铺满全脸，睫毛不逐根锐化。
- **光泽分清来源**：自然光泽只在鼻尖、颧骨、嘴唇上有小面积柔亮；汗、油、妆面高光各有来源，剧情没给就不写。
- **透光只在逆光边缘**：耳缘、鼻翼、指缘对着光时透出一点暖色，全脸不发光。
- **眼睛**：眼神光的位置、形状和数量对应现场光源；眼白有柔和明暗，不是纯白；虹膜有纹理和深度；下眼睑有一线湿润但不过亮。眼睛或主要识别点最清楚，皮肤可以略软。
- **柔化有边界**：柔化只降低过锐，不抹掉鼻唇结构和阴影；低反差也要保留面部体积。
- **写实 CG 人物**：保持既定 CG 媒介，用“底色有细微不均、不同部位粗糙度不同、克制的皮下散射”描述材质；发际线、眉毛、睫毛和皮肤自然交界。渲染器参数没有经过工程验证时只算设计建议，不写成可直接使用的数值。

| 现象 | 常见原因 | 修法 |
| --- | --- | --- |
| 塑料脸、蜡像脸 | 肤色太均匀，高光太大太亮 | 加回局部血色和冷暖差，把高光缩到鼻尖、颧骨、唇上的小面积 |
| 硅胶、橡胶质感 | 高光边缘过软并连成一片 | 高光收成几处分开的小亮面，阴影保留结构 |
| 玻璃珠眼睛 | 眼神光太多或和光源对不上，眼白发亮 | 按现场光源只留对应的一处眼神光，眼白压回柔和明暗 |
| 假毛孔、过锐 | 纹理铺满全脸或景别看不到却写了 | 纹理降到当前景别读得到的程度，删掉逐根睫毛 |
| 死白、灰白 | 写了白皙或整体提亮 | 回到角色原始肤色，补回局部血色 |
| 美颜感 | 正面平光、全脸柔光 | 改成有方向的主光和真实阴影，补光只托住眼口 |

## 四、克制表演

- 内敛不是动作小，是做出来之后不收回：嘴唇分开一条缝后一直没合上；眉毛抬起一点后一直挂着。
- 一镜里只留两到三件面部动作，不套固定公式，其余写“脸上没有多出别的表情”；情绪可以只靠一件事承担（例如“忘了自己手里还攥着东西”）。
- 情绪用精确的词：犹豫不是害怕，茫然不是迟钝，克制的愤怒不是吼叫。
- 显年轻：少用“沉稳、克制、从容”这类成熟气质词，侧光不要硬到刻出纹路。
