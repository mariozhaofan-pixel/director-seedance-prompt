# Bright Ensemble

适用：明亮柔光的人物群像、轻喜剧式关系推进、由开放日景进入低照度空间、夜空下的共同观看与克制的情绪收束。用于 Seedance 提示词的摄影、表演、声音编译。具体人物、事件、场景、物件和台词以当前任务为准。

路由：由 [STYLE_ROUTER.md](../STYLE_ROUTER.md) 按类型选中，或由当前用户/项目明确指定时加载；入口的类型选择视为启用本包。文件名只标识适用类型，不是剧情与人物模板。当前用户规则、角色、画幅及媒介优先；只提取当前故事成立的拍摄和表演方法。

## 挂载与作用域

当前用户或项目启用本规则时，与主 Skill 的空间构图、摄影光色、演员表演、时间轴和声音模块配合读取。把成像、镜头、光源、材质、调色写入【基础风格】；把每镜构图、演员走位、摄影机路径、表情与接触的次序写入【运镜与时间轴】；把确有声源、距离、混音和跨镜声桥写入【声音设计】。保留原有五栏和 Seedance 2.5 时间轴开头的“前提 / 核心关系 / 导演意图 / 演员指令 / 对白规则”。

先锁定当前剧本、角色、场景、动作因果、对白、画幅、时长和每段 OUT，再选择本规则中成立的机制。明亮日景、暗廊和开阔夜景是可选的场景分支，不要求一条视频全部出现。已验收提示词只在本次授权范围内改动。实际传给生成模型的图片、视频或音频，按[02素材路由](../../02_REFERENCE_ROUTER_AND_LOCKS.md)写对应控制维度；分析资料与仅后期挂接的素材留在候选外台账。

下述焦段、机距、光比、占框和秒数是制作起点，不是必须逐字照搬的数值。优先保证人物位置、触点、目光接力和表情变化能被看懂。摄影机是否移动由当前 CUT 的信息任务决定；稳定机位本身就是明确的运镜选择。

## 一、整体视觉目标

让环境先给出人物之间的距离和行动方向，再将注意力交给手部接触、视线转移和另一人的接收反应。画面可以有彩色环境与较大的前景，但脸和触点始终是清楚的视觉目标。明亮段落以柔和、干净、有人像景深的日光为主；封闭空间维持青蓝暗部与少数暖色实灯；开阔夜景把人物压到下缘，为天空中的既有事件留出大面积空间。剪辑在宽景、三层过肩和稳近景之间换尺度，避免用持续推拉或漂移代替演员表演。

### 1. 成像基线 →【基础风格】

- 使用大画幅数字电影机的人像成像语言，例如 `ARRI ALEXA LF large-format look`；写出柔和高光滚降、自然脸部比例、细节不过锐的结果。机型词只是视觉速记，不替代摄影要求。
- 保留项目指定画幅。未指定且以本规则为主时用 16:9，借横向画幅同时容纳前景关系人、清晰主角和后景旁观者；转为竖幅时重新排列纵深和视线，不能直接裁掉第三层人物或手部触点。
- 以球面镜头式自然透视为基线。近脸不贴超广角；人物眼睛、眉形、嘴角和手指接触处保留局部清晰，背景退成可辨的色块和灯点。浅景深只服务于注意力，不让双人互动中一人的脸一直糊掉。
- 日间脸部受柔软大面积天光或既有窗光塑形，眼窝保有反光，白衣与浅色道具不烧成纯白。皮肤保持自然纹理和轻暖血色；深发、浅衣、织物褶皱、石墙、金属或玻璃各有不同的明暗响应。
- 背景可有较鲜明的暖色装饰、冷色衣物或绿植，但饱和色集中在一两个情节焦点。脸部保持中性至轻暖，不用整幅橙黄滤镜；暗景也不把所有肤色涂成青蓝。
- 空气清晰、柔和，允许自然散景和有限的高光扩散。当前场景没有雾、雨、花瓣或彩色光源时不自动补入；夜景现有灯点可以虚焦成背景，不能覆盖人物眼神。

### 2. 场景光色分支 →【基础风格】

每场先选一个主分支；人物跨门、从室外到室内或反向出门时，可以短时让两套光域同时入画。写清光源在场景中的方位，反拍时重新核对受光侧、墙面亮点和人物投影，不让灯光随摄影机转向。

| 分支 | 光源、方向与阴影 | 调色、空间与材质结果 |
|---|---|---|
| L1 明亮开放日景 | 天空漫射作脸部大面积主照，侧后方日光或开阔地反射轻勾发丝与肩；近脸可有低强度回填，保留鼻颧和下颌的柔和体积 | 浅暖石材/地面、自然肤色、低至中饱和绿植与局部明快色块分层；背景建筑或设施仍可辨，浅色服装保留褶皱和边缘 |
| L2 彩色环境中的关系交流 | 仍由真实日光照脸，让环境中既有的暖色面、彩色结构或反射落在后景与画框边缘；人物进入阴影时回填随位置变化 | 前景大物件可以比人物更亮或更饱和，但不抢面部；一侧暖色、另一侧浅冷色或绿色形成关系分区，手和物件处有清晰局部对比 |
| L3 门口与明暗交界 | 外部亮天光作为后方或侧向轮廓，门内冷暗环境逐渐接管脸部；跨界时让两种色温按真实站位同时存在，眼睛始终可见 | 亮地面/墙面与深门洞分开；人物从暗处走出后肤色恢复自然，黑背景保留轮廓，不让一次切换造成服装和皮肤整体换色 |
| L4 青蓝暗廊与暖实灯 | 蓝灰、青蓝环境光在墙面和远端给低照度底；现有壁灯、顶灯、台灯或其他实灯只在其实际方位形成少数琥珀亮岛；脸以弱侧前反射保住眼窝和手势 | 深青墙面、暖橙点光、低亮度肤色和细小亮边分层；通道仍有可读纵深，暗部不压成空黑，实灯不把每张脸均匀照成橙色 |
| L5 开阔蓝夜与远处事件 | 深蓝夜空作大面积背景，人物受城市环境或现有侧后光形成可认轮廓；远处事件的亮点只在发生方向短时影响边缘和近脸，必要时用低强度柔光保眼神 | 地平线与远灯压在下方，天空保留深蓝层次；若有可见亮色事件，颜色局限于事件及合理反射，不把整片夜空和所有人脸同步刷亮 |
| L6 夜间亲密近景 | 延续同一夜景的冷底与远处灯点，以现有反射或柔和近侧补光读出眼睛、唇线和面部转向；允许短暂粉紫/暖色反射，但有具体来源和持续范围 | 前景人物或肩线柔化，背景呈低亮度蓝紫散景；脸部轻暖、发丝有细亮边，暗侧仍有结构。情绪收束后回到空间基线，不整场加梦幻光晕 |

需要数字帮助编译时，可从日光约 5000–5600K、暖实灯约 2700–3400K 起步；青蓝暗域只需明确“相对日光明显偏冷”，不强行指定统一色温。日景面部约 2:1 至 3:1、暗廊约 3:1 至 5:1 的明暗关系可作起点；最终由眼睛、手势、走廊深度和灯的真实方位决定。近脸柔光与暗廊低照度可以并存，但不把暗廊提亮成普通日景。

### 3. 焦段与景深分工 → 基线写倾向，具体数值写 CUT

下表为全画幅等效的制作建议。先确定画面要同时展示的人数、手部动作和空间锚点，再选机距与焦段；同一 CUT 保持光学逻辑一致。

| 画面任务 | 建议起点 | 需要写出的可见结果 |
|---|---|---|
| 大型前景＋另一侧群像、环境首次建立、同行路线 | 24–35mm | 近侧结构比远处人群大，人物仍有自然比例；前景、中景、后景和出口/目标方位同时能读，避免广角把脸推到畸变边缘 |
| 两三人互动、并行行走、低照度通道 | 35–55mm | 人脸、肩线、手和彼此间距同框；通道线条保留消失点，多个动作人有足够景深，不因过浅焦而失去接力 |
| 三层越肩反打、主要人物反应 | 50–85mm | 前景肩背柔化但能辨认所属，清晰人物的眼睛稳落对方视线方向，后景第三人保有轮廓或可读动作；反拍保持轴线和前景归属 |
| 克制的单人表情、夜间侧脸 | 65–100mm | 眼神与嘴角清楚，背景压为蓝紫或暖色散景，脸部比例自然；头部小转动能被看见，不靠推近解释情绪 |
| 手部接触、握持变化、当前动作物细节 | 85–135mm 或相应近摄能力 | 真实接触点、两人的手位及物件方向清楚；局部镜之后回到人物关系，不把所有意义压在孤立特写上 |

如果双人必须同时表演“先看物—再抬眼—对视”，优先增加景深和退远机位，而不是让另一人的脸全程虚化。焦点从前景到后景只能在两个目标都已入画、情节确有注意力交接时移动一次。推镜是机位位移，拉焦是清晰平面移动，景别变紧也可能由剪辑产生；三者分别写。

## 二、构图机制 →【运镜与时间轴】

每个 CUT 先指定本拍信息落在谁身上、另一人如何在画面里被确认，再选一个主构图。下表占框比例只作起笔，按画幅、身高差、视线和具体动作调整。

| 机制 | 何时使用 | 可直接编译的构图关系 |
|---|---|---|
| C1 大型前景与群像对置 | 新场景有醒目的设施、建筑、门体、雕塑或树冠，需要同时交代人物位置 | 让近侧大型结构占约 1/3–1/2 画面，并留一条可通视的空隙；人物成组落在相对一侧或中远景，地面线与结构边缘指向行动区。先读环境尺度，再读谁向谁走，不让大前景遮住关键脸 |
| C2 关系宽景与人数锚定 | 有人加入、群体站位变化、从对话转同行、多人看向共同目标 | 用最紧且容纳动作的宽景交代人数、彼此前后左右、目标方位和行进路线；让各人以衣色、姿态和间距区分，不把后景人物当无逻辑流动背景 |
| C3 明亮柔光三层越肩 | 一人与另一人交谈，第三人在旁观察、接近或继续做自己的事 | 近处肩背/侧脸占一侧约 1/5–1/3，清晰说话或接收者落另一侧三分区，后方第三人留脸和动作的位置。近中远三层由虚实、大小和亮度区分；前景不能盖住清晰者双眼或接触点 |
| C4 反向越肩与轴线维持 | 轮到对方回答、先看物再抬眼、旁观者接收变化 | 保持人物屏幕方向和眼线高度，前景换为另一人肩背，清晰人物仍朝画框内看；若第三人移动，让其沿已建立的背景区域进出。反打时光源按空间方位续接，不随摄影机翻转 |
| C5 共享双人中近景 | 两人靠近、递接、扶持或需要同时看见互相反应 | 两人占左右或前后错位位置，手与当前动作物落在两人之间偏下，脸有足够焦深；先让低眼与接触可读，再容纳抬眼和对视。不要为了美型把手裁出画框 |
| C6 触点—眼神—接收者 | 当前剧情已有交接、触碰、扶臂、牵手或共同查看 | 先在关系画面证明两人的手可达，再局部拍清实际接触或握持变化；下一镜给感到或看到接触者的目光，随后回双人位置。保持手的左右归属、物件方向和动作持续状态 |
| C7 旁观者的稳定近景 | 群体里某人的微小反应是下一拍重点 | 让旁观者眼睛清楚，其他人退为边缘轮廓或后景；容纳低眼、闭眼、抿唇、抬眼的连续变化。拍完回到群体，确认此人看的方向与刚才的事件相连 |
| C8 门框与通道纵深 | 进入低照度空间、寻找前方、出门或从暗域回亮域 | 门框/墙边定左右边界，人物按前中后错列，沿通道线或墙灯建立消失点。先有可走通的路，再插入脚步、手扶墙或近脸；出门后用门洞和环境宽景重新锚定位置 |
| C9 下缘人物与大夜空 | 多人共同观看现有远处事件，或需要显出环境尺度 | 人物背影或侧背压在画面下方约 1/5–1/3；地平线与远灯形成窄带，天空占主要面积。预留事件发生方向的留白，人数、坐站和相互距离稳定；仅让一人有清晰手势时其他人动作收敛 |
| C10 夜景关系切回近脸 | 宽景中的共同目标已建立，要转入个人感受 | 先沿已有看向方向切单人或双人侧脸，眼睛仍朝事件或身旁人物的真实方位；保留一侧虚焦肩线和同色系远灯，近脸读出从仰望到侧看或从笑到收住的变化，再切回共同画框 |
| C11 目标与结果的视觉接力 | 现有行动物/目标会改变归属或可见状态 | 宽景交代谁发起、谁接收、目标在哪里；动作局部写清方向和接触；结果镜头给真实变化，随后接发起者或接收者反应。不能靠孤立结果镜暗示剧本没有发生的因果 |

人物美型以平视、轻微俯仰和三分之四脸为常用起点。低角度用于大型前景、脚步或行动方向；明显俯拍用于真实物件布局或多人围拢；倾斜机位和强鱼眼不自动附加。亮场可以留白，但脸不可贴画框边缘；暗场可以压黑，但人物手势和前后关系要可读。

## 三、运动机制 →【运镜与时间轴】

每镜只选一种主摄影机路径。摄影机、演员、动作物、焦点和剪辑分别写；表演已经完成注意力转移时直接写 `locked-off camera`。不把连续的脸部占框变化自动认定为推轨，也不把剪辑换景别写成一次不可能完成的变焦。

| 机制 | 起点与路径 | 终点、焦点与用途 |
|---|---|---|
| M1 稳定表演与反应 | 关系中景、过肩或单人近景已把眼睛与手置于可读位置；camera 固定，演员低眼、闭眼、抬眼、微笑、转头或开口 | 背景结构不漂移，焦点留在表演者；让表情在半拍内发展并读清后切出。适用于对视、旁观者反应、夜景近脸，不额外叠推镜 |
| M2 前景遮挡后的短横移 | 从大型结构、门框或近肩的遮挡边缘起，camera 沿一条可达的短横向路径移动；近物滑动快于远景，人物逐渐露出 | 到能同时看见脸、手和群体方位时减速停稳；真实视差只在镜头确需揭示时使用。可从约 0.2–0.6 米试排，不因“电影感”而持续绕人 |
| M3 演员主动进入稳定画框 | camera 保持固定或只作极小再构图，人物从既有画面边缘走入、靠近、转身或并肩离开 | 让站位变化成为运动主体；人到位后留足眼神或接触的阅读时间。后景第三人可以继续独立小动作，但不能突然换位置 |
| M4 同行跟随 | 宽景先建立人物路线；camera 侧向并行、从后方跟随或正面退行，与演员保持可达距离和相近速度 | 人物占框相对稳定，路面/墙柱产生方向一致的视差；人物停步前 camera 减速，落到中景或关系景。若仅人物在稳定背景前移动，应写固定机位而非跟拍 |
| M5 暗廊中的引导与停顿 | 从通道的前中后站位起，camera 稍随人物前进或保持轴线稳定；脚、手扶墙、脸可由不同 CUT 接力 | 暖实灯和墙面在各镜保持固定方位；人物看到或触及东西时停住，用稳近景读反应。跨越墙体、门洞或多人视角时切镜重新锚定，不能一次穿墙漂移 |
| M6 一次焦点交接 | camera 基本固定，近层手/肩/动作物与中层人脸都已入画；从触点到眼睛，或从前景说话者到后景接收者执行一次 rack focus | 目标变清晰后保留可读停顿，可从约 0.4–0.8 秒起步；不往返抽焦。前后人物站位不变，焦点变化不等于机位变化 |
| M7 动作高点的方向性重构图 | 当前行动确需快速重新寻找人物或出口时，从明确起点作一次 pan/tilt；过渡可以短暂拖影 | 在下一张脸、手或门洞处停稳；模糊只覆盖转向，落点至少能读一拍。若两端机位不可连续到达，在运动峰值 CUT，并保持左右方向与光源方位 |
| M8 夜空稳定宽景 | camera 固定或极稳，人物沿下缘，远灯与地平线保持位置；画内事件、抬手或头部转向提供主要运动 | 留出事件发生、手势完成及群体接收的时间，再切近脸；不为了动感推向天空或环绕背影，避免破坏空旷尺度 |
| M9 夜景近脸与关系回收 | camera 固定在侧面或三分之四近景；演员从仰望转为侧看、笑意稍收或把手从头侧放下 | 近处虚焦肩线、远处光斑保持相对稳定；微表情读清后切双人或群体关系镜。只有剧情确需缩短观看距离时才做一次短推，并写明确起止画框 |

每个运动句落成：

`IN（机位高度/距离/看向、焦段景别、人物屏幕位置、前中后景）→ camera 路径与演员路径分别变化 → 遮挡/占框/背景视差变化 → 焦点归属 → OUT（停稳或交棒时可见的人物关系）`。

同镜内的小幅转头、低眼、牵手、停步或一次拉焦写 BEAT；新机位、新时间或真实切换写 CUT。稳定镜头写 camera 零路径和背景不漂移，人物与物件仍可运动。追求可读的动作线路和表情到位时间，避免整段无因慢摇、环绕、推拉与连续浅焦抽动。

## 四、镜组与时间分配 →【运镜与时间轴】

- **环境进入关系：** 空间宽景或大型前景＋群像 → 被关注者中景 → 三层越肩建立对话 → 接收者稳近景。先让观众知道人数、目标和走位，再压紧到人脸；若脚步或设施只是环境，不强制补局部特写。
- **三层对话反打：** 前景关系人＋清晰主角＋后景旁观者 → 反向肩背与对方回答 → 第三人的细小反应或进入画面 → 共享关系景。按信息归属决定是否反打，不按每句对白机械切一次；跨反拍保轴线、视线方向和实灯方位。
- **接触与眼神链：** 关系景证明双方可达 → 手与当前动作物接触 → 感到接触的人低眼或停顿 → 双方抬眼对视 → 关系 OUT。可在一个稳定双人镜内完成数拍，也可拆成 CUT；不能为套镜组增添未写入剧情的亲密动作。
- **群体中的个人变化：** 群像先交代每人位置与共同焦点 → 一位旁观者单人近景读低眼、抿唇、抬眼或笑意 → 回群像确认目光落点。后景人物有小动作即可，不必让所有人同时夸张回应。
- **亮暗空间转换：** 亮场与入口宽景 → 暗处脚步/手势与队伍纵深 → 青蓝暗廊的稳反应与暖灯锚点 → 出口的亮暗同框 → 明亮环境中的双人或群体关系。跨门瞬间优先守住行动方向、人数和手部状态，剪辑可以承担尺度转换。
- **夜空到近脸：** 人物在画面下缘的稳定宽景 → 现有远处事件在留白里发生、人物单一手势完成 → 看向同一方向的近脸 → 双人或群体的关系收束。宽景要给观众看清事件和反应起点；近景要给眼神从远处转向身旁的时间。

可从“动作物/触点约 0.5–1.2 秒、清晰目光或表情反应约 1.5–3 秒、三层过肩对话约 2–4 秒、空间或夜空宽景约 2–5 秒”试排。对白长度、真实行动、表情形成和环境事件所需时间决定镜长；若同镜承载多个 BEAT，可相应延长。重要接触或转念不在最后一帧才发生，OUT 留给下一镜接续的朝向、握持、人数、距离和情绪状态。继续遵守主 Skill 的分段上限与既定时间码规则。

## 五、人物情绪与表演 →【运镜与时间轴】

每次情绪变化先给角色一个当下目标和外部刺激，再安排眼睛、嘴角、手、肩、躯干和脚的因果顺序。不能用“惊喜”“心动”“紧张”等抽象词替代可见动作；表演须有对方接收。脸部大部分时间保持克制，关键处通过半拍停顿和小动作变得清楚。

| 机制 | 表演指令 | 镜头和节拍 |
|---|---|---|
| P1 发现与靠近 | 先维持原有姿势，眼睛看向进入画面的人或当前目标；下颌、肩线再跟上，迈步或倾身稍晚于目光 | 先给宽景证明来向与距离，稳双人或越肩容纳“看见—靠近—被察觉”；摄影机无需同步推近 |
| P2 轻喜剧反应 | 原动作暂停半拍，眼睑抬起或短闭，嘴唇从绷住到微张/微笑；旁观者可以晚半拍看向当事人 | 先见真实触发，再切接收者；让观众读到变化过程，避免每人同时做夸张瞪眼、张嘴和后仰 |
| P3 物件与眼神的接力 | 双方先看同一动作物，一人抬眼看对方，对方再抬眼回应；手维持当前握持直到接触确实完成 | 共享中景把手放两人中间偏下，必要时一次局部镜或拉焦；对视后保留双方脸，不能跳过物件归属 |
| P4 克制的笑意 | 先低眼或短闭眼，呼吸松开，嘴角缓慢升起，再轻微侧转或抬头；不要求完整露齿笑 | 单人稳近景给至少一个可读表情节拍，背景和脸部占框稳定；下一镜给看到这变化的人或回关系景 |
| P5 警觉到互相照应 | 人物先收肩、停步或扶住可达的墙/同伴；视线寻找当前声源或出口。若剧情已有接触，手靠近、碰到、握紧，再由脚步真正带动两人同向移动 | 暗廊先给队伍顺序与出路，再给可达触点、双方眼神和同向离开；不能仅凭快速甩镜暗示牵手，跨镜保留握持的左右手与力度变化 |
| P6 从暗处回亮处 | 出门后先因亮度和空间变化眨眼或停住，头再转向同伴；一人可以微笑，另一人从紧张的嘴唇和肩线逐渐放松 | 门口反应近景 → 双人关系 → 稍宽环境景；不靠无来源的暖光突变来代替身体恢复 |
| P7 共同观看与私密回应 | 群体先朝同一远处目标，个别人抬手或调整姿态；近景里先仰望，再把眼睛移向身旁，笑意可稍收或加深，手部动作延续 | 稳宽景让夜空事件与单一手势有完成时间，切近脸看眼神方向和唇线，再回双人/群体。背影镜头不强行写看不见的口型或微表情 |

若原剧情没有道具、惊吓、接触、夜空事件或多人关系，对应机制不启用。人物心理可写为演员目标，但可视化指令必须落在具体动作；某人看向谁、谁先动手、谁跟着走都要与前后 CUT 一致。

## 六、音频与声画接力 →【声音设计】和【运镜与时间轴】

从当前剧本和场景里真实存在的声源起笔：对白、呼吸、衣料、脚步、人物接触、可见机械/门体、室内回响、环境人声、远处事件及已指定的音乐。每种声源写位置、距离、开始和退出时点。音效只增强看得见或剧本已给出的动作，不能替未发生的动作制造结果；对白给清楚口型起止及另一人的听后反应，音乐避开关键字句和触点。

| 机制 | 执行规则 |
|---|---|
| S1 开放日景的关系收束 | 空间底保留自然环境声与既有远人声；切入三层越肩时轻收远景密度，让当前说话者与接收者的呼吸、停顿可听。反打保同一空间方位，不因切镜让环境完全归零。 |
| S2 手部与物件声点 | 递接、扶臂、握手、放下或拿起当前动作物时，只有真实接触处发出合理的衣料、摩擦或轻碰声；与画面触点同拍。局部镜可短暂提高清晰度，随即回到对白与空间底，不用巨大拟音夸张普通小动作。 |
| S3 明暗空间的环境转接 | 接近门口时先听到当前空间中确有的另一侧环境底；跨门后按墙体和距离改变高频、混响与脚步反射。暗廊实灯是否发声由其真实装置决定，不能为暖光强加电流声或恐怖音效。 |
| S4 警觉与离开的动态层次 | 若剧情有惊动或急行，先给触发源，再让脚步、呼吸、衣料和人物短句随速度与距离变化；接触和转身时短暂让音乐或环境让位，出门后重建外部声场。稳近景的静可以是相对降密度，不是无来源的绝对静音。 |
| S5 夜空事件到面部反应 | 远处事件若实际存在，先按方向与距离给远声，再允许人群的吸气、笑声或一句对白在近景更清楚；从天空宽景切近脸时声源仍在同一方位，事件退场后保留夜间环境底。音乐仅在既定创作要求里进入或续接。 |
| S6 对白与表情的交棒 | 说话者最后一个可听字音可以跨到接收者镜头，接收者先听、再转眼或开口；停顿给完整表情，不用旁白替其解释。无台词的脸部特写可以由呼吸、衣料或环境底支撑，不强加内心独白。 |

声音栏总述空间底、声源层级、远近与音乐条件；逐 CUT 写准确的出声、触点和对白起止。可见事件与声音的远近、遮挡、左右方向应一致。当前项目未指定的歌词、配器、声源或心理旁白不生成。

## 七、编译约束

【基础风格】每个独立段按“摄影机/画幅 → 镜头与景深倾向 → 当段场景光色分支及真实光源方位 → 前中后景与空气 → 皮肤/衣料/建筑或当前物件的材质 → 调色、黑位和高光”编写。日景、青蓝暗廊、开阔蓝夜各按出现的段落使用；一个段落不需要同时叠加全部分支。

【运镜与时间轴】五行前提之后，每 CUT 写机位高度、距离、朝向、景别和焦段；明确谁在前景/中景/后景、谁看谁、手和当前动作物处在何处；再分别写演员路径、camera 固定或运动路径、一次必要的焦点交接、光区变化、可玩的眼口手身动作、声画触发和关系 OUT。三层反打守轴线与灯位；夜景宽景守人数和地平线；暗廊守出口、实灯与手部连续性。全段成像基线不在每镜重复，本镜独有的门内外光区或远处事件反射才写入 CUT。

【声音设计】只写当前段确有的环境底、语声源、动作与生理声、空间远近和可用音乐；关键声音的准确落点写在对应 CUT，声音栏总括混音与跨镜延续。未给定的歌词、声效、旁白和背景音乐不自动创作。

合并前只核对摄影选择的直接结果：大前景与群体能同时读懂；越肩三层不遮关键眼和手；接触—目光—接收反应有因果；暗廊的青蓝环境与暖实灯方位稳定；夜空留白和下缘人物关系成立；camera 运动、演员运动、焦点转移与剪辑被分别写清；已锁剧情、台词和时长结构保留。随主 Skill 的既有预检完成，不新增审批或独立验收关卡。
