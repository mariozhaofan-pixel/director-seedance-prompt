# Commercial Reversal

适用：人物关系迅速靠近、身份反转、明亮商业空间的动作接力、夜间短暂停留及室内反应戏。用于 Seedance 提示词的摄影、构图、表演与声音编译。

路由：由 [STYLE_ROUTER.md](../STYLE_ROUTER.md) 按类型选中，或由当前用户/项目明确指定时加载；入口的类型选择视为启用本包。文件名只标识适用类型，不是剧情与人物模板。当前用户规则、角色、画幅及媒介优先；只提取当前故事成立的拍摄和表演方法。

## 挂载与作用域

当前项目启用本规则时，将成像、光色和材质编译进【基础风格】，将构图、逐镜动作、摄影机运动和表演编译进【运镜与时间轴】，将对白、环境和动作声编译进【声音设计】。保持主 Skill 既有的【角色/场景/素材锁定】与【画面限制】；在 CUT 1 前保留“前提 / 核心关系 / 导演意图 / 演员指令 / 对白规则”五行。

以当前剧本、角色、人设图、场景、道具、对白、画幅、时长与 OUT 为准。以下空间和物件只作条件示例；没有柜台、商品、饮品、食物、面部覆盖物或发光效果的剧情，不在提示词中添加它们。实际传给生成模型的图片、视频或音频，按[02素材路由](../../02_REFERENCE_ROUTER_AND_LOCKS.md)写对应控制维度；分析资料与仅后期挂接的素材留在候选外台账。镜头焦段、机距、色温、光比和秒数是生成起点，画面关系和动作可读性优先。

## 一、整体视觉目标

用清楚、明亮、略带柔光的现代短剧影像承载近距离关系：先交代人物与通道、桌面或前景物件的相对方位，再用两张脸之间缩小的距离、眼神的横向接力和手中物件的转移推动情节。保留肤色、眼睛和口形的清晰度；暖米色室内、冷蓝窗景、夜间冷环境与局部橙金光形成可辨的场景转换。普通镜头以稳定持镜为主，让人物靠近、手伸向镜头、后景群体走入或细小表情自己造成画内变化。只有空间关系确实改变时加入短距离摄影机运动。

### 1. 成像基线 →【基础风格】

- 使用柔和的数字电影人像质感：脸部明亮但保有皮肤纹理，眼白、瞳孔、睫毛、唇线和口型清楚；高光边缘柔和，亮肤不泛成无纹理白块。摄影机机型可作为风格速记，必须同时写出这些可见结果。
- 保留当前项目画幅。未指定时可从 16:9 横幅起步，以横向空间容纳对视的两张脸、左右货架、另一人的肩背或后景走位；若使用竖幅，重新排前后景和视线空间，不直接裁掉关系人或伸出的手。
- 室内亮景以奶油白、浅木、暖米、低饱和金色为大底，深色服装、头发或少量识别色形成视觉锚点。夜景以冷蓝空间和橙暖局部灯区分主体与背景；卧室可降低亮度，用暖浅色寝具与柔和冷阴影保住脸。
- 使用自然的球面透视。空间宽景要看出柜台、通道和多人位置；脸部镜头避免贴脸超广角造成鼻梁、下巴变形。低机位近前景只在手、物件或台面需要被放大时采用，并在下一镜回到正常比例的关系景。
- 材质响应各不相同：玻璃或亮面台面保留有方向的反射，浅木和纸盒为哑光，衣料可见褶皱，皮革或金属有受控边缘高光，食物若存在才给适度油润或湿亮质地。近摄的反射不得遮住指尖与触点；高亮商品不把脸压成暗块。
- 画面中若有数字或图形效果，只作为已确定剧情的独立视觉层；其字句、数值和增长方式必须来自当前输入。眼部光效或面部暖色覆盖须有明确触发，先见真实表情，再逐渐变化，不以效果取代眼口动作。

### 2. 场景光色分支 →【基础风格】

每段从当前场景实际存在的光源选一个分支；人物跨越光区时，受光面随空间位置改变。反打后保持窗、柜灯、摊灯或床头灯在同一世界方位。

| 分支 | 光源、方向与阴影 | 调色和材质结果 |
|---|---|---|
| L1 明亮接待区或公共室内 | 顶部柔和暖白面光负责眼口可读；窗侧冷日光退到侧面和背景；货架、墙面、柜台提供弱反射填光 | 暖米墙面、浅石与木面为底，窗外浅冷蓝形成纵深；深色衣服与头发压住画面，脸保持中性微暖，接待台或展架不刺眼 |
| L2 反光台面与展示空间 | 长条顶灯和两侧货架建立收束线，台面反射灯带；近处手与物件可受更亮的局部光，后景人物依然看得见 | 亮面有清楚但受控的反射，手指边缘、卡片或其他小物轮廓清楚；暖室内与冷窗景分区，反射不盖住接触点 |
| L3 商业通道与双人交流 | 商铺暖灯形成侧后方点亮，走廊或中庭提供较冷的环境填光；人物转身时，受光侧依动作改变 | 肤色温润，远处招牌和灯点柔化为可辨色块；近景背景虚化而非全黑；衣料、头发与亮面地板分别有自己的反光 |
| L4 甜点、饮品或小物近摄 | 依当前场景的窗、柜灯或桌灯给表面侧前光，必要时用白墙反射抬暗侧；接触者的手不被高光吞没 | 玻璃透光、液体或食物高光、纸面边缘、皮革纹路分开呈现；色彩饱满只局限在物件，不把整场调成过饱和广告色 |
| L5 夜间开放空间 | 冷蓝环境光给地面与人群层次，已有摊灯或店灯给脸和食物局部橙暖亮区；远处点灯保持深度 | 蓝灰夜色与金橙暖岛并存，近脸能读眼睛，背景可辨路面和人距；热气或油亮只在当前动作物件存在时加入 |
| L6 夜间近距离情绪转折 | 沿用已有夜景光源，让两张脸在窄景深里仍有各自的边缘与反应区；效果光只在瞳孔、颧骨或已有物件附近小范围出现 | 背景暖色散景与冷色暗部相互分离；高亮效果逐步增强而不一次铺满双眼与整张脸，肤色和瞳孔方向不丢 |
| L7 安静卧室或休息空间 | 床头或室内暖灯为主，冷窗光或环境反射留在侧后；正面近景采用柔和低对比补光看清眼口 | 米色寝具、木质靠背、深发与浅脸形成温暖稳定构图；床单有细纹，暗部不浑浊。局部面部覆盖物存在时保留孔位、边缘和半透明质地 |

若需要数值，暖室内可从约 3000–3800K、冷窗或环境从约 5000–6500K 的相对关系起步；面部可从约 2:1–3:1 的柔和明暗差开始，夜间可稍增至约 3:1–4:1。数值服从当前服装肤色、眼部可读性和既有光源，不把室内统一染黄或把夜景统一染蓝。

### 3. 焦段与景深分工 → 基线写倾向，数值写在 CUT

下表为全画幅等效的生成建议。先确定这拍要让观众看见的距离、触点与眼神，再选机距和焦段。

| 画面任务 | 建议起点 | 需要写出的可见结果 |
|---|---|---|
| 柜台、通道、商铺或多人方位 | 24–35mm | 近处台面或门框较大，两侧货架与远处人物有透视，脸离画边和镜头足够远；路线、前后景同时清楚 |
| 双人距离、坐姿全身、人物进出 | 35–55mm | 人物比例自然，手和表情仍可辨，留出走近、转身或交接物件的实际空间 |
| 单人正面反应、过肩交流、双人侧脸 | 50–85mm | 眼口清晰，背景退为柔和色块，仍保留对方肩背或目光方向；两张脸同时需要读清时收足景深 |
| 手、卡片、杯沿、布料与小型物件 | 80–120mm 或近摄能力 | 接触点清楚，近处高光不过曝，物件从谁手中来、交到谁手中仍可由相邻关系景确认 |
| 贴台面仰视的伸手或落物 | 24–35mm，机位贴近反光面 | 手在前景明显放大，人物居中中景，两侧空间线向后收束；焦点在触点与脸之间有明确归属，不让“手大脸糊”成为意外 |

同一 CUT 内光学焦段保持稳定。若选择变焦，写明起止焦段和要交代的信息；若选择推镜，写摄影机实际位移与背景视差；若只是切到更近画框，直接写 CUT。浅景深服务于眼神或物件，不把两人同时对话的另一张脸糊到无法阅读。

## 二、构图机制 →【运镜与时间轴】

每个 CUT 只选一个主要信息归属：人物关系、脸部反应、触点、后景人群或空间转换。构图比例随当前画幅与人物身高调整。

| 机制 | 何时使用 | 可直接编译的画面关系 |
|---|---|---|
| C1 贴近双侧脸 | 双方原已靠近、言语试探或对抗 | 两张脸分别占画面左右，眼线横向相接；脸间留一条窄而清楚的空气，背景柔化。近侧脸可以部分越出画边，但眼睛与口形都要可读；先由眼珠转向，再由头部和肩部跟进 |
| C2 正面反应单人 | 收到对方话语、发现物件变化或心意转折 | 头顶留少量空间、脸处于中轴附近，眼睛落上半幅；让肩胸或手的起始状态进入下半幅。下一镜按目光方向给被看的对象，不让人物无对象直视镜头 |
| C3 关系宽景 | 新场景、人物加入或动作距离未清 | 双方完整站坐方位、柜台/门/通道或床缘同时可见；必要时一人先居中，其他人错列前中后景。人物靠近时保留可走的路线，画面边缘与距离变化可被看懂 |
| C4 低位反光台面 | 手、卡片、小物要从人物身前来到观众眼前 | 机位贴近台面，桌缘横贯前景，两侧货架或灯带指向居中人物；手从中景伸到大前景，落物和反射同框。脸可暂时较软，但眼口反应必须在前后镜头读清 |
| C5 过肩与看向离开者 | 一人持物或离画，另一人需要接收反应 | 前景肩背/手中物约占画面一侧，清晰人物落另一侧并沿走廊留出其行动方向；先见离开路径，再让人物回头，以眼神把视线拉回前景关系人 |
| C6 物件接力 | 剧情已有递物、试用、取物、放下 | 关系景先确认持有者和接收者；局部镜只放大实际触碰与重量转移；随后给眼口反应，再回到两人位置。前景物件大但不遮住交接手，数量与左右手连续 |
| C7 商品或动作蒙太奇 | 短时间展示多个已确定物件或行为 | 按“提起—指向—触摸—持有者反应”组织短 CUT，以相近颜色或手势方向接力。每个局部镜清楚一个动作，别把不同商品误拼成同一件，也不在无商品剧情里加入购物镜头 |
| C8 静态主体与后景走位 | 主体停在台前、后景人物趋近或围拢 | 主体占前中景并保持眼口清晰，后景通道容纳群体从远处逐渐走入。镜头固定、主体大小稳定，变化来自真实走位；人数和站位在反向机位里对应 |
| C9 前景物件围合的坐姿 | 人物短暂享受、放松或自得其乐 | 主体居中坐下，左右已有物件作为前景括号，手中小物处于胸前；左右物件高低错开，不遮脸和膝部动作。长镜里让眼睛、嘴角、杯子高度小幅变化 |
| C10 夜间空间与脸部收紧 | 从开放环境进入两人近距离关系 | 先用宽景看出冷夜、暖灯与人物相距，再切双人中景及窄景深近景；局部暖色散景留在眼线之后，脸部不被夜色吞没。特殊眼光只在触发后递进 |
| C11 床侧双人到卧床近景 | 安静室内、卧姿与坐姿或两人同床对话 | 宽景先看清枕头、床沿、双方朝向和动作空间；切正面卧床近景，让眼、口与贴近脸的手处于焦平面。面部覆盖物若存在，眼口孔位及取下动作连续 |
| C12 表面动作的极近镜 | 当前动作确有食物、液体、纸面或细小材质变化 | 宏观画面只保留一个可识别接触和纹理，液体、食物或纸张的方向性光亮清晰；局部镜后回到持有者或观看者，不能让表面特写独自承担完整剧情 |

在对视与触点镜组里，“前景压近、后景退远”是一种信息排序。保留必要脸部、手指与道具边界；面部太近造成五官变形时后退机位，用焦段和裁切调整，不靠超广角贴脸制造情绪。

## 三、运动机制 →【运镜与时间轴】

每镜只选一个主摄影机动作。固定机位不是停滞：眼睛、口部、手与后景人群都可在画内运动。景别因剪辑改变就写 CUT，人物向镜头伸手不写成摄影机推近。

| 机制 | IN 与路径 | OUT、可见变化和用途 |
|---|---|---|
| M1 稳定脸部反应 | camera 固定，脸部在近景已清楚；演员先以视线、眼睑或嘴角变化回应 | 背景大小与边线稳定；表情读清后切对方。用于对视、惊讶、浅笑、停口与再开口，避免每句都推镜 |
| M2 手向镜头的画内推进 | camera 在低位台面或既定中景不动；演员由身前伸臂，手与物件依次进入前景 | 指尖接触、手掌承重、物件落定后短停。前景快速变大而背景不变，这是演员和道具运动，不能写成 camera 前进 |
| M3 后景群体入场 | camera 固定在主体与通道关系景；后景人物沿已建立的两侧或一条纵深路线走来 | 主体基本不变，后景人影逐步变大，注意力由单人扩至群体；反向切镜时保持人数和手势方向 |
| M4 视线带动的短横移 | 当一人已朝画外转头、另一人处在同一可达空间时，camera 沿其目光方向短距离横移；前景肩背滑得比远背景快 | 到双方进入同框时停机，让目光真正接上；若横移会跨越空间轴线，改用切镜与重建关系 |
| M5 靠近关系的短推 | 剧情已有两人距离收紧、压迫或主动靠近；camera 从能看清双方身位的中景沿通道小幅前移，演员路径另写 | 人物占框逐步增大，近处台面/肩背退出边缘，远景产生小幅视差；到眼口需要阅读的位置减速停稳。无这些可见改变时不写推轨 |
| M6 台面到脸的可达仰摇 | 起拍台面触点与手，camera 沿人物手臂或身体向上仰摇，不跨越人物或实体柜面 | 终点见到脸和看向谁；一次镜内升降若无法保持物件与脸的连贯位置，就拆成局部 CUT 与正面反应 CUT |
| M7 跟随交接与离开 | 两人已建立递交方向；camera 可短距离随接收者转身，或在肩后保持固定，看另一人沿通道离开 | 手持物、肩背和背景门店位置连续；当离开者回头，camera 停住给可读眼神。不能让站着的角色在滑动背景前原地踏步 |
| M8 一次焦点交接 | 前后两个目标已同时入画，camera 基本固定；从台面触点/近手拉焦到中景脸，或从前景肩背转给后景接收者 | 新目标清晰后保留短暂停顿，原目标仍有可辨轮廓。移焦不等于变焦，也不与无因推镜叠加 |
| M9 夜间注意力收紧 | 先在冷暖并存的双人景稳定交代距离；出现明确凝视或靠近动作后，可做一次轻微侧移或短推 | 以两张脸的眼线、背景暖点和未被遮挡的口形为终点；效果光只在终点或动作触发后上升，不让整镜持续漂移 |
| M10 蒙太奇里的方向接力 | 多个短镜头由人物提物、指向、伸手、接受等同向动作相连；camera 每个镜头内大多稳定 | 前一 CUT 的手势方向和后一 CUT 的物件位置相接。镜头密度来自明确剪辑，不要求每一件商品旋转、推近或甩镜 |

运动句写成：`IN（机位高低、左右方位、景别、主体与前中后景）→ camera 路径与演员路径分别写 → 画面里的遮挡、人物尺度或背景视差怎样变化 → 焦点与视线落点 → OUT（停稳、动作结果、下一镜继承状态）`。固定机位写 camera 零路径，仍要写演员和道具的运动。移动机位的终点应在反应发生前到位，不在关键口型出现时急速晃动。

## 四、镜组与时间分配 →【运镜与时间轴】

- **对峙与身份关系：**关系中景先看清双方方位 → 双人侧脸近景压缩脸间空气 → 一个说话者近景 → 听者的眼口反应 → 需要时回到双方共享画框。台词可以跨反应镜延续，不能每一句都机械正反打。
- **手部主导的决定：**关系景确认手与物件 → 手在同镜伸向前景或切局部 → 接触与落定清楚发生 → 反向机位给被影响者 → 返回关系 OUT。若手向镜头的长镜已经说明全部动作，删去多余的局部镜。
- **多人靠拢：**固定中景让后景人物逐步入画 → 主体以眼口或伸手回应 → 切反向视角读取群体反应。避免人群突然从无路线的背景里跳出。
- **购物或挑选动作：**先建立人物与陈列位置 → 提起、指向、试用或接收的短局部镜 → 脸部反应 → 下一件物件。每件物件有独立归属和颜色锚点，密集剪辑仍能看懂谁在选择。
- **并坐停顿：**宽景交代已持物和左右留白 → 稳定中景等待眼部变化 → 小动作例如物件离唇、降低或放下 → 先转眼再开口。可让前景物件括住主体，长停留不等于添加无因推轨。
- **夜景转折：**开放宽景建立冷蓝环境与暖灯岛 → 食物或其他当下动作的局部触点 → 双人中景确认距离 → 眼口近景读出情绪 → 有剧情依据时才出现逐步增强的局部光效。
- **卧床反应：**床侧双人宽景建立同处空间 → 贴脸手势或面部状态动作 → 卧床者稳定近景，闭眼、睁眼、侧视、张口递进 → 回到双人景确认双方位置。近景里的脸部动作可持续一个完整 BEAT，不能用切镜掩盖状态改变。

短局部镜可从约 0.4–1.0 秒试排；对话反应、物件递接约 1–3 秒；双人关系和后景入场可从约 2–4 秒试排。对白长度、物件重量感、走位与眼神转移决定最终时长。显示时码时各 CUT 区间连续覆盖目标时长，停在动作完成且下一镜能够承接的状态。CUT 仅用于新机位或真实剪辑；BEAT 用于同镜的视线、口型、伸手、落物、停顿及短机位重构图。

## 五、人物情绪与表演 →【运镜与时间轴】

每次情绪转折先给演员一个可见刺激和当下目标；再安排眼神、口形、手部、肩背与步伐的先后。用动作幅度的反差组织轻喜剧：一方先出现较大眼口变化，另一方只在极近距离小幅回应；下一拍交换主动权。情绪标签要落成肌肉与行为，镜头在变化出现前已到位。

| 机制 | 可执行表演指令 | 镜头与节拍 |
|---|---|---|
| P1 近脸试探 | 先只让眼珠从对方眼睛落到嘴角或手，再让头小幅转向；肩和脚仍停在原位。开口前留短停顿，嘴角和下颌改变幅度小于视线变化 | 双人侧脸共享近景保留脸间空气；切正面反应时维持同一眼线，不让突然换轴改变谁看谁 |
| P2 惊讶递进 | 外部信息到来后，原动作先暂住，眼睑渐抬、瞳孔重新定向、嘴唇先分再张；身体与手臂晚于眼口反应 | 稳定近景让变化完整发生；切镜前保留一点读脸时间，不在一帧内从平静跳成大张嘴 |
| P3 克制者的反压 | 一方前倾或话语增大时，另一方不立刻退让；只轻转眼、收紧唇线或改变呼吸，再按剧情需要转肩或缩短距离 | 摄影机稳住两人相对占幅，先给动作较大者，再给几乎不动者的反应；权力变化来自谁先改变距离 |
| P4 手部决定 | 先看见视线落到物件，再让指尖靠近；接触后手掌承重、手腕改变角度、物件移动并落定，最后眼睛回到对方 | 低位前景镜可放大手，但不跳过“看见—碰到—持有”的因果；下一 CUT 保持持握手一致 |
| P5 短暂得意与回看 | 已完成的小成功之后，人物可以先闭眼或浅笑，手中小物下降一点；听到/看到画外人后先转眼、再转头、最后张口或抬臂指向 | 坐姿中景留足前景物件和眼线空间；离开镜头用肩后视角承接回看，不凭空加庆祝群像 |
| P6 群体反馈 | 后景人物沿通道逐步靠近，各人先互看或停步，再由一人伸手/开口，其他人依既有位置跟随 | 宽景保人数和进场方向；反打只在主体动作已发出后出现，前景伸手与后景目光能对上 |
| P7 夜间亲近与发觉 | 两人站位先稳定；一方靠近时另一方先移眼、轻微屏息或停口，随后才抬头或后退半步。若有光效，瞳孔先看向可见触发物，再逐级点亮 | 双人近景保留眼线与后方暖点；把特效作为已经发生的反应放大，而非替代人物面对面关系 |
| P8 卧姿反应 | 手贴近脸或当前覆盖物边缘时动作慢而轻；从闭眼到睁眼，再侧视、轻张口、眼睛扩大，头枕与肩背位置保持连续 | 固定卧床近景先读眼口，宽景负责证明另一人在哪里；覆盖物取下、坐起、后仰等大动作须在可见景别完整发生 |

在近景中写眼睑、唇线、呼吸带动的微小肩部运动；中景可写手腕、肩背、转头；远景改写行走、停步、靠近、离开或群体入场。人物站姿、坐姿、卧姿的变化不能只靠相邻镜头跳跃完成，必须有可见转换或明确剪辑衔接。

## 六、音频与声画接力 →【声音设计】和【运镜与时间轴】

只从当前场景真实存在的声源建立声音层。对白先行，呼吸、步伐、衣料、手与物件接触、室内环境、夜间人群及配乐依剧情选择。每句对白给说话者、起止 BEAT、口形与听者反应；音乐不能代替台词，也不能用拟音替没有出现的动作讲剧情。声音的强弱是相对关系，不把环境突然抽成无来源的真空。

| 机制 | 可执行规则 |
|---|---|
| S1 双人贴近的声场收窄 | 距离缩小时保留近处说话者的可听性，背景人声和音乐相对退后；看者停口的一拍留给呼吸或衣料小动。对视解除后恢复原空间环境，不在所有近景里加心跳声 |
| S2 手与物件的触点同步 | 提起、指向、触碰、放下、递接依可见物件材质给短促且不过分放大的声音；重点落在接触帧附近。没有触碰时不补“啪”声；镜头切近不意味着声音也无因突增 |
| S3 反光空间的距离层级 | 柜台近手、台后说话者、远处人群保持近、中、远三个层次；camera 固定而人群接近时，后景声逐渐增大并保留方向。反打后音像位置与画面轴线对应 |
| S4 蒙太奇与长停留交替 | 多个短局部 CUT 可让声音触点形成节拍，但每件物件只配它自己的接触声；转到坐姿或卧床稳镜后减少触点密度，留出语尾、呼吸和一段低位环境底 |
| S5 暖室内到冷夜的声桥 | 切场景时，新场景的环境底随画面建立，可用上一镜真实存在的语尾、脚步或物件声短暂跨镜；夜间开阔处的空间感较宽，局部暖灯附近的近动作声较清楚 |
| S6 表情与效果的层级 | 眼神、面部或光效逐渐增强时，优先让演员的停口、呼吸和对方反应可听；如项目要求非写实效果声，仅在效果确实出现的 BEAT 加入，且不盖对白或把静止凝视变成持续轰鸣 |
| S7 卧室低动态 | 安静室内以对白、轻微呼吸和已出现的布料动作维持低强度声场；坐起或躺下时声点与床垫、衣料接触同步。面部近景可暂退音乐，让眼口表演和一句短话拥有空间 |

对白出现时，音乐和环境不争夺 1–4 kHz 的可懂度；需要突出关键触点时，可在触点前后短暂降低非必要声层，再恢复场景底。若当前剧情明确没有配乐，则无需新增音乐。逐镜写明声源在画内还是画外、与人物的相对距离、何时进入和退出；跨 CUT 保持连续场景的声场一致。

## 七、编译约束

【基础风格】每个独立段按“当前画幅与摄影倾向 → 当前场景光色分支 → 人脸、衣料和关键物件材质 → 背景纵深与景深”写成可见指令。只选本段确有的光源与材质；不把全套场景分支抄进一段。人物脸和动作触点的可读性优先于柔光、散景或商业空间亮度。

【运镜与时间轴】五行前提后，每个 CUT 写：机位高度与方位、焦段/景别建议、人物在画幅中的左右前后关系、正在发生的动作、camera 固定或可见路径、焦点归属、眼口手与身体 BEAT、当前光区、必要声点、关系 OUT。换机位写 CUT，同镜动作写 BEAT。演员向镜头伸手、后景人群走近、切近景与摄影机推近分别写清；不以一句“镜头缓缓推进”代替可到达的路径。

【声音设计】写当前场景的环境底、语声源、动作或生理拟音、远近及配乐条件。对白与动作声的触发落到对应 CUT/BEAT；声音栏只总括混音层级和跨镜延续。反应镜保留说话者的必要声桥，停口时不添加新台词。

合并前确认：关系双方的位置、眼线和距离能看懂；伸手、持物、接触、交接与离画都有可见因果；脸部反应有足够阅读时间；摄影机、演员、剪辑和移焦分开描述；反打之后光源仍在同一方位；字幕、屏幕和数字只使用当前项目给出的文字；已锁角色、对白、时长、画幅与 OUT 得到保留。检查随主 Skill 的既有预检完成，不新增独立审批步骤。
