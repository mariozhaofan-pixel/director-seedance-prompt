# Style Router

scope: 光影、运镜、构图、表演和声音方法的条件选择。先读本轻量目录，再读取唯一选中包；不为比较而先读五个全文。规则只服务当前剧本，具体角色、场景、道具、对白和OUT始终来自当前项目。

## 选择顺序

1. 规则来源消费入口已确认的“用户规则 / 库内选择 / 新反推”决定；入口询问 Seedance 2.0/2.5 时可以同轮确认来源，已明确的项目不重复询问。当前用户提供或指定了光影运镜/表演规则时直接采用；本次要求新反推时先完成下方内置规则反推功能，以生成的规则文件作为当前用户规则。两者均高于旧项目规则与库内默认；若用户未要求变更，已有项目已确认规则继续生效。缺项沿主Skill相关模块补足，不自动再搭配库内包。仅用户明确要求融合时组合，并按其指定范围解决冲突。
2. 用户选择库内，或没有用户/当前项目规则且未要求新反推时，根据下表的故事任务、关系/表演方式和场景光域，从现有库选择**一个最合适的包**。先比较叙事与表演机制，再比较场景条件和节奏；作品名、历史提及或单个词不构成触发。多个同样适配时选择需要新增假设最少、最能保持当前故事的一个，不加载第二个补齐。
3. 现有包与题材差异较大时，仍选择方法最接近的一包，只抽取其成立的通用摄影/表演机制；例如奇幻或动画保留用户媒介，只借空间关系、眼神/接触接力和声音层次，不改成真人校园或商业剧。无明显特征时使用“克制写实/信息触点”包的稳镜、清楚关系和自然光源方法，不强行采用其方幅、场景或色调。
4. 在制作台账记录 `style_source=user|derived|project|library`、实际规则文件和选择理由；`derived` 与 `user` 具有相同优先级，仅规则文件真实完成后才记录为已生成。选定后沿用当前项目，后续批次只按场景切换该包内分支；当前用户改风格或故事任务实质改变时才重新选择。这个记录不写进模型提示词。micro/local沿入口保护基线，仅在本次修改确实涉及风格时加载受影响包，不借自动选择重做已验收稿。

## 新反推：调用内置功能，再返回规则文件

用户提供需要参考的对标视频/链接，且没有限定仅作剧情事实、身份或尾态证据时，默认进入新反推；明确要求参考光影、运镜、构图、表演、声音或整体拍法，或选择“新反推”时同样，完整路由到内置[光影运镜表演规则反推](../../capabilities/reference-rule-extraction/REFERENCE_RULE_EXTRACTION.md)。只有故事事实、动作尾态或续写连续性证据用途的视频，分别沿 [02E](../02E_MEDIA_EVIDENCE.md) 或 [02C](../02C_CONTINUATION_REFERENCES.md) 处理，不因出现视频自动反推风格。

运行时实际读取内置功能入口及其要求的规则书写合同、视频取证协议与配套脚本，执行完整取证、规则写作和验收流程；所需功能资源均随导演Skill分发，无需另装反推或视频分镜技能。已经完成的有效证据按协议复用，不用几张关键帧或口头“已参考”代替全帧与听音要求。本路由只维护触发、输入和规则文件回传，细则在功能目录唯一维护。

选择新反推却缺少可访问的对标视频时，询问目标视频或链接；用户明确了分析范围则沿用。视频不可访问、实际媒体工具不足、证据或验收未完成时，保留未完成状态并说明具体缺口，不静默改用库内包，也不声称新规则已建立。用户只要求反推规则时不索取Seedance版本，完成规则交付即结束；同时要求导演编译时，规则完成后回到此前的版本、剧本和授权范围继续编译。

规则文件保存到当前用户项目，默认命名为 `<名称>-光影运镜规则.md`；用户指定名称优先。正文按内置规则书写合同写。来源与证据留内部台账；导演编译只读取已完成规则文件作为 `style_source=derived`，不把源视频、取证报告或功能协议正文当生成参考。用户明确把视频传给生成器时，另按02分配实际素材职责。

青春轻喜剧与明亮群像同时出现时，双人亲近/动作对抗为主选前者，第三人反应、群体走位与空间共同经历为主选后者。克制对话与商业空间同时出现时，空间只是背景且眼神/信息压力为主选克制写实，物件接力/身份反转推动故事时选商业反转。整段画面都是剧中手机录下的（用户说手机 Vlog、自拍、iPhone 质感、他拍、镜面自拍）时选手机 Vlog；正剧里只有个别镜头是手机屏幕或手机视角时不换包，那几镜按 04 的 POV 规则写画面来源。

## 编译边界

选中包只提供镜头、构图、光色、演员行为组织与声画节奏。文件中的学校、球场、柜台、夜空、屏幕、购物或接触例子均有场景条件；当前故事没有的对象、行为、特效、音乐和台词不随包进入。机型、焦段、画幅、色温、镜长和光比均是可覆盖起点。

将成立的方法分别落实到既有基础风格、时间轴和声音栏目，不新增风格说明栏目。版本/时码、五栏、2.5五行合同、微修改和检查次数统一消费入口及对应模块的生效规则；风格包里的旧项目措辞不重新定义这些公共规则。检查并入当前已选预检，不增加审批、选包确认或独立验收回合。
