# Restrained Realism

适用：由克制对话、人与空间尺度对比、信息触点和短暂空间转换组成的写实或轻类型叙事。用于 Seedance 提示词的摄影、构图、运镜、表演及声画节奏编译。

路由：由 [STYLE_ROUTER.md](../STYLE_ROUTER.md) 按类型选中，或由当前用户/项目明确指定时加载；入口的类型选择视为启用本包。文件名只标识适用类型，不是剧情与人物模板。当前用户规则、角色、画幅及媒介优先；只提取当前故事成立的拍摄和表演方法。

## 挂载与作用域

当前项目启用本规则时，将成像、光色、材质写入【基础风格】，将构图、镜头路径、剪辑、人物动作写入【运镜与时间轴】，将语声、环境、触点声和音乐层级写入【声音设计】。保留主 Skill 的五栏，以及时间轴开头的“前提 / 核心关系 / 导演意图 / 演员指令 / 对白规则”。

人物身份、造型、空间、道具、对白、画幅、段长和结局均从当前创作输入取得。只有当剧情真的包含相应的对峙、触物、行走或离场时才调用对应机制。方幅是本规则可优先使用的构图起点；项目指定其他画幅时，重新安置主体占幅与留白，不把构图简单裁切。下文机距、毫米焦段、光比及镜长均为生成建议，最终以当前画面中动作和表情的可读性为准。

## 一、整体视觉目标

让安静人物置于尺度明确的环境：大前景与小人物、近脸与远城、规则网格与不规则旧物相互牵制。先用宽景告诉观众人物之间的距离和空间轴线，再用稳定近景让眼神、停口或手部迟疑承载变化。景别转换多数靠清楚的切镜；少量连续靠近和侧移须让桌沿、人物占幅及远背景发生可见变化。色彩以低饱和蓝灰、褐灰及扎实暗部为底，低位暖天光、窗边暖灯、远城点光或屏面青蓝只在空间中有依据地出现。

### 1. 成像基线 →【基础风格】

- 采用自然比例的人像电影成像：高光柔和收束、面部不过度锐化、暗部不压死。眼睑、唇线、发丝、衣料折痕和手指接触点保持清楚；背景的城市点光、窗外树影或散射光可虚化，仍要留下方位。
- 画幅未指定且适合双人谈话或人与环境对比时，可用 1:1 方幅。近景让人脸占中部或略偏一侧，头顶留少量空气，肩胸占下部；宽景可让双人落在下边缘、两侧或中轴，留给天空、水面、旧建筑或走廊纵深更大的空间。改为横幅或竖幅时保留主体相对距离、前景遮挡和留白方向。
- 宽景使用较广的空间视角形成可追踪透视，人物与桌、门、廊、地平线同时可辨；近景用较窄视角和浅一些的背景景深分出脸与空间。不要用极广角贴脸把五官、手掌和近物夸张变形。
- 黑位厚实但保持黑衣布纹、边缘与褶皱；浅衣保留纤维和局部阴影，皮肤保留柔和肤理与自然血色。粗砾地面、磨旧物表面、玻璃反射、布纹、金属和屏面应有不同的高光宽度，不统一做塑料光泽。
- 主体脸通常比远背景更可读，亮部不泛白。城市雾化、玻璃反光、远景灯点用于纵深；清晰空气为默认，当前场景有窗雾、尘或自然散射时才加轻薄空气层，不自动铺满浓雾和耀斑。

### 2. 场景光色分支 →【基础风格】

每场选一个主分支，人物跨门窗或触碰发光物时可短暂叠加第二分支。反拍时保持光源在同一空间侧，不让冷暖与阴影方向随机互换。

| 分支 | 光源、方向与阴影 | 调色与质感结果 |
|---|---|---|
| L1 开阔暮色与高处关系 | 低位暖天光只从地平线一侧进入，灰蓝天空作大面积环境光；人物正面偏暗，侧脸和肩边有很窄的暖亮，留面部轮廓与眼神 | 冷灰人物、灰蓝城市与橙褐窄天际分三层。粗砾地面、旧物边缘与远处雾化建筑各有质地；暖色不漫灌整张脸 |
| L2 河岸或城市留白 | 阴天、黄昏或城市环境光柔和包住人物；水面与远处灯点只给低强度的横向亮层，近脸可由合理环境反射补出眼白 | 蓝灰服装、青灰水面和零散暖灯保持低对比；人物在宽景中可较小，但岸线、城市线和双人距离仍清楚 |
| L3 卧室或私密室内 | 一侧既有台灯/墙灯形成暖局部，另一侧窗光或夜色给冷蓝轮廓；光交界落在两人之间或床与窗之间，局部屏面光仅照到邻近眼颊与手 | 暖棕木面、灰蓝窗影和深色衣物分区，布料、床品与面部不糊成一片；屏幕亮点不能代替整个房间主光 |
| L4 规则化人工空间 | 顶灯、灯带或成排屏面建立重复透视，前方人物脸可用柔和补光保留细节；青蓝发光层位于环境上方或远处，不压住眼口 | 重复桌列、通道线、墙格与冷色界面形成秩序；深色座椅和地面仍有分层，局部暖灯只在实际存在的区域出现 |
| L5 夜间街面与车厢 | 环境冷白或蓝灰为底，店面、路灯和窗外城市给少量方向性暖点；人物走过不同光区时，脸上的冷暖比例跟着改变 | 深蓝灰街道、衣服和车窗玻璃有不同反射；运动景不把所有灯拖成等亮光带，人物肤色仍可识别 |
| L6 信息触点 | 当前剧情已有屏幕、指示灯或其他发光物时，先明确其所在手、距离与方向，只给附近指尖、眼下或领口局部受光 | 用青蓝、绿色或当前指定色作小面积焦点，周围仍维持场景主色。画面文字和界面内容按当前输入，不凭光色自行补写信息 |

### 3. 焦段与景深分工 → 生成建议，具体写入 CUT

| 画面任务 | 建议起点 | 必须读到的画面结果 |
|---|---|---|
| 环境规模、两人距离、桌或门的完整关系 | 约 24–35mm 等效的较广视角 | 桌沿/门框/地面线形成透视，人物可较小，仍能判断谁在前、谁在后与可走路线 |
| 双人对峙、并坐、物件位于两人之间 | 约 40–65mm 的自然视角 | 面部比例自然，肩、手、桌边和远景各有一层；双方反应都需读清时提高焦深 |
| 单人倾听、正反打、城市灯点人像 | 约 65–100mm 的较窄视角 | 眼睛清楚，背景收成有方向的灰蓝城市或暖点，不把另一人物和空间线索完全抹去 |
| 眼、唇、手指、屏面或接触点 | 人像长焦近摄或相应近摄能力 | 局部只回答一个问题：谁看见、谁触碰、何时变化；随后回到关系景确认双方状态 |

毫米数、光圈和光比仅作生成起点，以可见透视、遮挡、景深和读脸结果优先。

## 二、构图机制 →【运镜与时间轴】

| 机制 | 何时使用 | 可直接编译的构图关系 |
|---|---|---|
| C1 方幅中央或左右二分 | 双人对话、身位较均衡，项目允许方幅 | 一人可居中，另一人占画面侧边或前景；两人可左右分处且中间留出桌面/触点，不让一人的目光冲出空白边。横幅或竖幅按同样视线关系重排 |
| C2 背影大前景与对面中景 | 对峙、倾听、权力距离 | 背影或肩背占画面下半/一侧较大区域，对面人物较小且清晰，二者之间的桌面或空地可见；地平线和天空/城市留出上层空间。前景不盖住对方的关键眼睛 |
| C3 低置双人与大留白 | 人物言行需要与宽阔环境对照，或对话暂时停止 | 双人压在画面下边缘，水面、远楼与天空占大半画面；一条水平岸线/桥线把近人和远景分开。人物仍保留可辨轮廓和相对朝向 |
| C4 大型非对称环境块 | 基本居中或均衡构图显得过于平 | 在一侧放入与当前空间一致的旧设施、建筑块、桌角或阴影，另一侧给人物或远城，形成不对称重量；不要凭空加入不属于本场景的大物 |
| C5 单点消失与重复网格 | 秩序、规模、被系统包围的空间 | 让成排桌位、灯条、地砖或窗格朝一个消失点收拢，人物占轴线或偏三分位；上方青蓝光线可加强深度，重复物件从近大远小连续递减 |
| C6 一人清晰、一人残留 | 正反打、重要信息正在传递 | 清晰者用居中或三分构图，另一个人以虚焦肩、侧脸或手留在边缘；背景有一层低对比环境，使观众知道双方仍在同处。反打后左右轴线一致 |
| C7 触点在关系中间 | 递物、屏面提示、桌上信息或手势改变关系 | 先在中景给出物件位置与所属，再让眼神落向它；必要时插局部，不使物件忽然换手、换侧。局部之后回到接收者脸与双人关系 |
| C8 室内对角冷暖 | 两人同处较私密空间、需要以光区区分状态 | 暖实灯落在一侧床面/桌面，冷窗光在对侧背景；两人占据不同光区或跨越分界，灯、窗、脸与手的相对位置持续一致 |
| C9 单人近景与暖点远城 | 演员以眼口小变化承担镜头 | 脸居中或略偏，头顶只留少量空气，肩胸占下半；远处暖灯虚化为少量点，冷灰背景仍能认出方向。眼睫、嘴角与呼吸带动的肩部保持可读 |
| C10 离画后的空处 | 一人起身、走开或短暂切断对话 | 人物穿过近前景从既定边缘离画，桌、地平线及剩余人物继续停留；空出的面积成为下一反应位置，不能让摄影机立即乱追而丢掉留者 |

## 三、运动机制 →【运镜与时间轴】

| 机制 | 起点与可见路径 | 终点、焦点与用途 |
|---|---|---|
| M1 稳定持镜读表演 | 关系或近景已让眼口和肩手可读；camera 保持机位，演员垂眼、抬头、停口或小幅转身 | 背景透视与人物尺度稳定，关键表情出现后停留一个可读 BEAT，再切对方。日常对话优先使用，不以持续推近代替表演 |
| M2 切镜式景别接力 | 先有双人/多人关系和空间轴线；触发后切单人近景、手中物、再切接收者 | 每个 CUT 重建方位和焦点，不把镜头中人物占比骤变误写成物理靠近；让一镜只交代一项新信息 |
| M3 连续缓靠近加轻横移 | 当前剧情确需让双方从全身距离收成腰上对峙时，从能同时看见桌面、两人全身和远背景的机位起；camera 低速靠近，轻微向一侧横移，演员若向对方走近须另写路径 | 桌沿从画面下缘逐步退画，两人占幅连续变大，背景大物在二人之间发生侧向位移；到双人腰上/中景减速停稳，保留双方手和脸。生成时以一次约 4–7 秒的连续路径试排，禁止突然跳尺度 |
| M4 近前景人物穿行 | 一人已站起并沿画面已建立的方向走过镜头近处；camera 可保持不动 | 人物变大、遮住一部分画面后从既定边缘消失，桌与远城位置基本不变，留下双人与空背景。此处的尺度变化由演员路径造成，不额外添加推轨 |
| M5 短距离同向行走 | 人物由车厢、廊道或街面进入另一空间，双方行进关系需连续 | 先有可走路线；可用侧向或背后跟随保持人物占幅近似，门柱、路人和路面形成视差。停步时减速落到中景；若空间无法连通则用方向一致的动作切镜 |
| M6 焦点从物到人 | 触点与人物眼睛已同时或先后处于可达画面内 | camera 尽量稳定，焦点只交接一次：手/屏面清晰→接收者眼睛清晰；到脸上后停住。若目标不在同一机位可读范围，使用两个 CUT，不作无依据的复杂绕行 |
| M7 空景或背影的收束 | 关键问答和动作完成，下一段需停顿或转场 | 返回较宽机位，人物占较小比例，岸线、城市或走廊轴线稳定；只留下轻微呼吸、头部或环境画内运动。人物消失、缩小或淡出须与真实动作/剪辑一致 |

每个运动句写为：`IN（机位高度、距离、画幅内人物与前中后景）→ camera 路径和演员路径分别描述 → 桌沿/肩背/门框的占幅与背景视差 → 焦点交接 → OUT（停稳后的关系与视线）`。固定机位写 camera 零路径，人物仍能改变占幅；景别切换写 CUT，画面内动作写 BEAT。

## 四、镜组与时间分配 →【运镜与时间轴】

- **对话镜组：** 环境关系宽景 → 双人中景确定轴线 → 说话者近景 → 听者不立即开口的反应 → 必要时回共同画框。按信息归属切，不为每句台词机械反打。
- **权力距离镜组：** 大背影前景/对面双人 → 单人眼神与唇线 → 关键停口 → 宽景显示人物与城市的比例。情绪由谁先移眼、谁保持原姿势来组织，不把身份标签直接写成画面效果。
- **信息触点镜组：** 关系景先给物件所属 → 手或屏面局部 → 接收者下视/抬眼 → 对方回应 → 关系 OUT。只在当前剧情确有物件或接触时调用；读不清触点时不要以字幕补因果。
- **行走与空间转换镜组：** 当前空间路线 → 双人保持行进方向 → 新空间宽景或门窗锚点 → 一人近景。车厢、街面、走廊、室内属于不同机位时以动作方向和光色变化连接，不强迫成一条不可能的长镜头。
- **安静收束镜组：** 关键表情完成 → 低位并列或背影宽景 → 让远处环境占画幅主体 → 按当前故事指定的结尾停住或收暗。镜头不因对白结束立即切走，给观众读到人物之间剩余的距离。

可从触点局部约 0.5–1.2 秒、眼口反应约 1.5–3 秒、关系镜或空景约 2–5 秒、一次连续靠近约 4–7 秒起排；实际镜长由对白、演员动作、观众阅读物件和镜头停稳需要调整。显示时码时 CUT 区间覆盖当前片段目标时长，BEAT 写在对应 CUT 内；关键表情在镜头已经到位后才出现，动作读清再切。

## 五、人物情绪与表演 →【运镜与时间轴】

先给演员一个外部刺激与可玩的目标，再把眼、口、手和重心按先后写明。近景读眼睑、唇线和轻微呼吸；中景读肩背、坐姿和手部；宽景读起身、走离、相对距离。任何“犹豫、震惊、释然、施压”都落到可见动作，不只给抽象情绪标签。

| 机制 | 表演指令 | 镜头与节拍 |
|---|---|---|
| P1 克制倾听 | 原姿势先保持；眼球移向说话者或触点，嘴唇短暂放松再收紧，头部和肩膀晚半拍跟上 | 稳近景留给眼口变化，下一镜才决定是否给说话者。听者未开口时不补台词或大幅手势 |
| P2 视线压力 | 一方保持直立或坐定、下颌略收；另一方先低头、短暂停口，再抬眼看向对方，身体距离暂不改变 | 先用大前景和双人关系证明位置，再切脸；稳定姿态与迟到的眼神构成力量差，不靠无因环绕制造压迫 |
| P3 触点引起的反应 | 手先靠近或停在物件旁，眼睛落到接触点；接触完成后可短暂停手，再由眼睛回到对方，嘴才开口 | 触点局部必须有前后因果；回到关系景时保持持物手、放置位置和双方视线一致 |
| P4 突然信息与收束 | 原来低垂的视线被触发后逐渐抬起，眼睑扩大、下颌轻松、嘴微张；随后可再次低眼、收眉、把呼吸和口部归位 | 稳近景中完整给出从察觉到收束，不用连续快速切镜遮掉反应；对方的微小回应稍晚出现 |
| P5 慢半拍的行动 | 起身或俯身前先有视线目标，重心移动后手臂才动作；走离时头和肩可短暂保留对谈方向，脚步沿既定路线离画 | 宽景保证起点与出口，离画后仍留一拍给其他人物和空处；近景无法交代路线时不要硬写步伐 |
| P6 余波与相伴 | 双人并坐或并立，面部变化很小；一人先偏头看另一人，另一人稍后转头或维持朝前，手保持原处 | 以低位双人和广阔环境延长停顿；若剧情要求关系变化，用相对距离与转头顺序证明，不自动安排拥抱、牵手或夸张笑容 |

## 六、音频与声画接力 →【声音设计】和【运镜与时间轴】

按当前项目确有的环境与动作设计声源。对白必须与可见口型、停口和听者反应对应；环境、动作和音乐在语声周围分层。每个声层标明出现位置、近远、强弱变化和何时退出。没有确认的具体音乐、拟音或台词，不由风格规则替剧情补写。

| 机制 | 执行规则 |
|---|---|
| S1 克制对话 | 语声位于前景，远城市、室内或人群底层保持较低且稳定；一句关键话之后让听者的停口、呼吸或衣料小动作有可听空隙。画面同时从说话者切到稳定反应近景 |
| S2 触点声与观看反应 | 当前动作有真实接触、放置、拿起或脚步时，声点与可见触点同步；接触后暂时降低竞争声层，让眼神转移和对方回应被读到。未发生的碰撞、提示音或结果不添加 |
| S3 宽景与近景的远近 | 切到开阔宽景时，可让环境层相对展开、语声按人物距离变远；切近脸时收低环境并保留清晰语声与呼吸。空间远近变化须跟随景别和遮挡，不让背景突然无因消失 |
| S4 空间切换 | 从街面/车厢进入房间或从房间走向开阔处时，按当前场景已有声源重新建立环境底和反射感；用真实连续的脚步、门口动作或一句跨镜台词搭桥，切入新空间后及时更新远近与混响 |
| S5 动态收放 | 信息或动作段可增加节奏密度，重要表情前抽低非语声层，宽景停顿保持一层可解释的环境声；若当前项目要求音乐，只在不遮盖台词和触点时渐入/渐出，音乐不能代替人物情绪的可见变化 |

## 七、编译约束

【基础风格】每段按“当前画幅和成像基线 → 场景主光源及方向 → 人物与背景冷暖/明暗关系 → 景深和材质 → 本段独有的光区变化”写。相同基线不在每个 CUT 重抄，屏面、城市灯点或窗光只写当前场景真实存在的分支。

【运镜与时间轴】2.5 段在 CUT 1 前写五行段级执行合同，内容按 [06](../../06_TIMELINE_EDITING_SOUND.md) 的定义。本包的偏重：核心关系写清谁面对谁、谁听、谁持有触点；演员指令按眼→口→手→身体重心的先后写。

随后每个 CUT 写 IN 构图、演员与 camera 各自的路径、焦点/光区变化、可见触发、BEAT 及 OUT 状态；稳定机位明确写 camera 不移动。显示时码时各 CUT 区间连续覆盖目标时长，OUT 要把人物位置、持物手、视线与下一镜接起来。只有连续路径确实有画面内视差时才写移动镜头，其他尺度变化明确写剪辑。

【声音设计】先写语声与当前环境底的优先级，再写动作声点及跨镜声场远近；音乐只在当前创作要求时出现。关键触点的声画同步写在对应 CUT，声音栏写总体混音和声层进出。

编译结束检查：人物和空间关系一眼可读；脸、眼、手与关键触点都有合适景别；方幅或其他画幅没有误裁关系人；冷暖方向在反拍中持续；演员动作、摄影机移动与真实剪辑分别成立；当前剧情、对白、时间码和结尾要求完整保留。
