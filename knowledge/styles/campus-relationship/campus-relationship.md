# Campus Relationship

适用：高美型校园人物关系、轻喜剧、雨夜追逐、球场对抗及相近短剧。用于 Seedance 提示词的摄影、表演和声音编译。

路由：由 [STYLE_ROUTER.md](../STYLE_ROUTER.md) 按类型选中，或由当前用户/项目明确指定时加载；入口的类型选择视为启用本包。文件名只标识适用类型，不是剧情与人物模板。当前用户规则、角色、画幅及媒介优先；只提取当前故事成立的拍摄和表演方法。

## 挂载与作用域

当前用户或项目启用本规则时，配合主 Skill 的空间构图、摄影光色、演员表演、时间轴与声音模块读取。将光色质感编译进【基础风格】，将逐镜构图、运动和表演编译进【运镜与时间轴】，将声源与混音编译进【声音设计】；保留原有五栏及 Seedance 2.5 时间轴开头的“前提 / 核心关系 / 导演意图 / 演员指令 / 对白规则”。

先保留当前剧本、角色、场景、对白、动作因果、画幅、时长与 OUT，再选择成立的摄影、表演和声音机制。已验收提示词按本次指定范围调整。实际传给生成模型的图片、视频或音频，按[02素材路由](../../02_REFERENCE_ROUTER_AND_LOCKS.md)写对应控制维度；分析资料与仅后期挂接的素材留在候选外台账。

以下焦段、机距、构图比例、色温、光比和秒数仅作生成起点。实际构图、动作、对白和表情可读性优先；每场只选与剧情成立的机制。

## 一、整体视觉目标

以人物关系组织画面：先让观众知道两人在哪里、距离如何，再让观众看见触点、眼神与对方接收到的反应。人脸柔润清晰，深色服装有重量，空间有明确冷暖分区；前景关系人或物件与清晰主角共同构成画面。稳定持镜、主动走位、焦点迁移、真实剪辑和少量有目的的运动共同形成节奏。

### 1. 成像基线 →【基础风格】

- 使用大画幅数字电影机的人像成像语言，例如 `ARRI ALEXA LF large-format look`，并写出柔和高光滚降、自然面部比例、受控锐度等实际视觉结果。机型词只是生成风格速记。
- 保留项目画幅。未指定且以本规则为主时用16:9；借助横向空间保留关系人、视线空间和环境。改为竖幅时重新排纵深和遮挡，不直接裁去另一人。
- 球面镜头式自然透视，标准到中长焦承担人物文戏；广角承担空间、低位前景和完整动作。普通镜头不额外叠加横向变形耀斑或超广角贴脸畸变。
- 光学柔化集中在皮肤细碎反差和高光边缘；眼睛、睫毛、眉形、唇线、关键发丝保持可读。皮肤细腻、低颗粒，保留轻微肤理；头发、织物、皮革、木纹和水滴仍有不同表面响应。
- 黑发与深色服装保持扎实暗部和褶皱层次；高光柔和收束。肤色中性至轻暖，唇部保留自然血色；背景可冷可暖，不把整张脸统一染成橙色或青色。
- 空气以清晰或轻微透光为基线。雨窗、水滴、湿地、纱帘、少量虚焦枝叶在当前场景存在时承担层次；普通室内不自动加浓雾、花瓣或全画面光晕。

### 2. 场景光色分支 →【基础风格】

每场选一个主分支；处于门窗内外时允许两域同时入画。把光源固定在场景空间里，反拍后重新描述其投影方向和人物受光侧。

| 分支 | 光源、方向与阴影 | 调色与材质结果 |
|---|---|---|
| L1 日间窗边教室/生活室内 | 窗侧大面积日光作侧光或侧逆光，纱帘漫射和低强度正面回填使眼窝可读；室内另一侧保留塑形阴影。窗格可以在墙地形成较硬光斑，脸部仍然柔和 | 奶油白、浅米灰和暖木形成大底，深蓝/深灰服装压住画面，肤色轻暖；窗与纱帘明亮，白衬衫保留折痕，地板细亮反射不过度镜面化 |
| L2 日间庭院/户外交流 | 侧后方自然光勾亮头发和肩线，天空漫射照亮面部；树影/建筑阴影提供环境节奏，眼睛有小而清晰的反光 | 米白石材、低饱和绿植、金色边光与深色服装；肤色保持中性偏暖，亮部柔和。保留户外空气感，不把所有植被调成黄褐色 |
| L3 暖室内与冷雨夜同框 | 室内吊灯、壁灯或柜台灯形成暖主光，门窗外冷蓝环境光照入侧面/背面；人的位置改变时，冷暖占比随其跨越光区而变 | 琥珀墙面/木面与冷蓝雨窗分区，脸保持中性或轻暖，局部冷边；雨玻璃点状高光、湿地条状反射、皮革方向性高光各自清楚 |
| L4 冷色走廊/雨夜室外 | 冷蓝灰环境为底，既有墙灯/门灯形成局部暖光岛；以柔和侧前补光或环境反射保住眼睛，阴影侧有结构；走廊沿门框和灯条建立纵深 | 海军蓝、蓝灰、深绿配少量暖金亮点；湿地存在时留灯影，背景暗于关键肤色但不压成空黑；避免全脸青灰、均匀蓝色滤镜和所有灯同亮 |
| L5 短暂心动/主观感受 | 先沿用当前真实光源，在关键目光/接触节点短暂加强逆光、柔亮边缘与高光扩散；脸部信息仍然清楚 | 少量暖金或粉色点缀、发丝/衣角的细微运动、较柔的背景与稍延长的反应。花瓣、悬浮、速度变化仅在现有故事或风格已允许时加入；离开主观段恢复场景基线 |
| L6 日间球场与暮色校园 | 低角度日光从人物侧后方勾亮头发、肩线和球体；天空/场地反射给脸部低强度回填，逆光不吞掉眼睛、球与关键触点 | 低饱和草绿、奶油白球衣、深蓝校服、暖金发缘并存；球缝、草叶、汗珠和校服褶皱清楚，远建筑保留方向锚点 |
| L7 夜间球场与樱花巷 | 球场冷白高灯形成主照明与可见光区，围墙/草地偏蓝灰，脸另受柔和侧前回填；巷道以冷夜作底，现有路灯暖亮花枝和发缘 | 深海军蓝、草绿、土黄与局部琥珀高光形成分区；红布、伤处或金纸屑只作小面积高饱和焦点。背景保持可识别，强灯不把皮肤烧白，夜色不把眼睛压黑 |
| L8 蓝夜泳池、石材长廊与江桥 | 水池或江面接受既有蓝色环境与远处灯点，走廊沿石墙、门框或灯带建立单点纵深；头灯、壁灯和桥灯只在所在方位形成局部亮区，近脸另用柔和反射保住眼神 | 深蓝石材、黑色水面与湿地保留不同反射，暖灯只作方向锚点。对话停下来时背景仍可辨识人物距离，水光不把脸打成无来源的均匀蓝色 |

需要数字帮助编译时，可从这些制作预设起步：日光约5000–5600K、室内暖灯约2800–3400K；冷域写“相对日光明显偏冷的蓝色环境”。日间面部约2:1至3:1、夜间约4:1的明暗关系可作描述起点。最终以鼻颧塑形、眼窝和暗侧细节是否可读决定，不机械固定数值。

### 3. 焦段与景深分工 → 基线写倾向，具体数值写 CUT

下表均为全画幅等效的制作建议；先定画框内必须看见的信息，再定机距和焦段。

| 画面任务 | 建议起点 | 需要写出的可见结果 |
|---|---|---|
| 新空间、进场路线、两人完整接触、群体关系 | 24–35mm | 桌椅/门窗提供透视，前景较大，人物与动作路径同时可见；脸离画边和镜头足够远 |
| 中景对话、并行/相对双人、自然跟随 | 40–65mm | 面部比例自然，两人距离可读，保留肩手与少量环境；双方都需表情可读时使用足够景深 |
| 单人近景、过肩反应、窗边/雨夜人像 | 65–100mm | 清晰眼睛与虚焦关系人分层，背景被压缩为可辨颜色/灯点，人物鼻梁与脸型不夸张 |
| 眼睛、手指、袖口、唇部、关键物件 | 85–135mm或相应近摄能力 | 只聚焦当前信息，细节清楚且接触点在框内；局部镜结束后回到能确认人物关系的画框 |

近景不必固定使用长焦，浅景深也不必固定为某个光圈数值。同一 CUT 光学焦段保持一致；变焦需要明确的起止与目的。推镜写摄影机位移，拉焦写清晰平面的移动，两者分别选择。

## 二、构图机制 →【运镜与时间轴】

每个 CUT 先确定“本拍关系/信息落在谁身上”，再选一个主构图机制。比例是起笔参考，按角色脸型、眼线和现有画幅调整。

| 机制 | 何时使用 | 可直接编译的构图关系 |
|---|---|---|
| C1 关系宽景 | 首次进入空间、有人加入、距离/支撑改变 | 用能容纳必要动作的最紧宽景；看见人物相对朝向、间距、桌/门/窗的锚点以及可走通的路线。双人不必左右等大，群体可让主角前置、其他人错后 |
| C2 前景关系人＋清晰主角 | 对视、质问、倾听、近距离交流 | 对方虚焦肩背或侧脸占画面一侧约1/5–1/3，清晰主角落另一侧三分区；前景只遮边缘，不盖关键眼睛或接触；视线朝向画框内的对方，背景另有一层环境 |
| C3 前后景信息交接 | 后方人物接话、被注意到、举物或显露反应 | 近景人物先清晰，另一人物在后景留出脸的位置；触发后一次拉焦给后景，对方仍以模糊轮廓留在近处。反向交接同理，先让观众看见目标存在 |
| C4 紧双人共享画框 | 原剧情已有靠近、搀扶、伞下同处、递接 | 用三分之四侧面让两人向画面内部相对；两眼和关键触点处于可读焦深，保留脸间的狭小空气；因身高差产生的视线斜线可以保留，不强行齐头平视 |
| C5 触点—眼神—接收者 | 已有扶持、拦腕、拉袖口、递物、握伞 | 先保证宽/中景交代动作所属；局部镜只拍真实接触或变化，下一镜给看到/感到它的人。眼唇特写只在当前关系需要时使用，局部之后能回到双方状态 |
| C6 框中框与遮挡揭示 | 出入门、隔窗看、被伞沿/书本/他人挡住 | 门框/窗框/伞沿定义观看边界；明确谁移动才解除遮挡。保留一个可识别人脸的开口，揭示后稳定读脸，不无理由穿过实物 |
| C7 低位前景与主角出场 | 身份显露、步入空间、动作姿态需要放大 | 手、鞋、桌沿、椅背作近层，引导到人物；领带/脚步/脸可由不同 CUT接力，也可在同镜明确仰摇揭示。不要把原本剪辑出的多视角写成一次镜头升降 |
| C8 回眸与余留空间 | 离开、被叫住、关系暂未结束 | 先建立离开方向，侧后近景保留视线返回的空间；头部转回时可固定持镜，另一人反应后再回到离开或宽景。花枝等既有前景可柔化上缘，不盖眼睛 |
| C9 轴线秩序与群像中心 | 校园长廊、团队集结、球场、比赛通道 | 用门框、灯带、柜列、本垒白线或桥梁收束线建立消失点；主角占中轴或三分位，其他人错列成前中后景。群像举手/冲跑先有关系宽景，再给手与脸的接力，不让背景人物随机换位 |
| C10 高速物件的空间接力 | 球、钥匙、车把、红布或其他关键物件改变方向、所有权、危险范围 | 在宽/中景先交代物件从谁那里出发、朝谁而去；再给出手/飞行/接触的局部镜，接收者反应与落点必须可见。快速主观近物镜可加强速度，但下一镜要回到可定位的人与空间 |
| C11 镜面与水面关系框 | 车辆反光镜、雨窗、水面或玻璃本来就在场，人物需要同时看到彼此或隔物观察 | 让反射中的两张脸、实体与倒影、或窗内外人物有清楚的对应方向；反射只叠在必要边缘，关键眼睛保持可辨。离开镜面后用实景关系镜重新锚定双方位置 |

美型机位以平视、轻微俯仰和三分之四脸为常用起点；低机位、明显俯拍和倾斜构图服务于出场、接触证明、失衡或喜剧节点。它们不随“浪漫”标签自动加入。

## 三、运动机制 →【运镜与时间轴】

每镜以一种主摄影机运动为主。表演、景深和剪辑已能完成信息转移时，明确写稳定机位或 `locked-off camera`；不能为了满足“电影感”而让每镜漂移。

| 机制 | 起点与路径 | 终点、焦点与用途 |
|---|---|---|
| M1 稳定反应 | 近景或过肩已把眼神放到可读位置；camera固定，演员转头、眨眼、呼吸或改变表情 | 背景保持稳定，焦点留在接收刺激的人；反应完成或新信息出现时切出。适用于对视、回眸、低头抬眼，不额外叠加推镜 |
| M2 低速横移揭示 | camera沿明确侧向短距离移动；近侧肩背/桌沿/门框比远背景滑得快，主角从遮挡边缘显露 | 在关键脸或关系构图出现时减速停住。演员是否走动另写，保留真实前后景视差；可先以约0.2–0.6米短位移试排 |
| M3 同向跟随/正面退跟 | 主角沿已建立路线行走；camera并行或在正面同速后退，让主体大小近似保持；两侧桌椅/墙柱形成相反方向的视差 | 人物停步前camera减速，落到可读的中景或关系景。走位、camera位移、速度和终点分别说清；不能让人原地走路而背景自行滑动 |
| M4 局部向脸的揭示 | 起拍手、脚或衣领，仰摇/短升降沿可见躯干到脸；若同时行进，明确跟随距离 | 看见脸时稳住，再接对方反应。单镜必须路径可达；脚步→远处正脸若是换机位，应写CUT |
| M5 一次焦点交接 | camera基本固定，前后两目标都已入画；由握持触点到脸，或近侧人物到远侧反应者，执行一次 rack focus | 在目标眼神/表情变清晰后留一个可读停顿；主体不因失焦而消失。可从约0.4–0.8秒移焦起步，不来回抽焦，也不同时无因变焦 |
| M6 快速寻找与停稳 | 从明确的信息源出发，快速pan/tilt带方向性拖影，到下一人物或信息点减速锁住 | 模糊只占过渡，落点保持足够阅读时间。用于寻找座位、榜单信息、突然注意力转移；多个停点写BEAT。机位跨越不可达空间时在运动峰值有动机切镜并重新建立空间 |
| M7 轻微收紧/弧向重构图 | 当前场景确实需要让观看距离缩短或绕开肩背遮挡时，选择一次短dolly-in或小弧移，写清固定焦段、圆心/方向和起止构图 | 到关键眼神前减速，结束时脸和接触点可读；人物靠近另写。它是可选复现手段，不把所有更紧画框、侧脸变化解释成真实推镜或环绕 |
| M8 追逐与同向跟随 | 先用俯视/宽景建立巷道、车道、阶梯、转角、追兵与逃者的位置；camera 在一侧并行或从后方/正面保持可达距离跟随 | 墙柱、路灯、湿地反射与近侧人物产生可追踪视差；低机位轮胎/鞋/手只在动作因果上切入。人物出画、转角遮挡或动作峰值交给下一机位，停跑后回到稳镜读脸和呼吸 |
| M9 强动作与稳镜反应交替 | 起势时稳住球场/身体支点，关键物件启动后用一段快速镜头或方向性甩镜，切到其真实落点 | 先呈现投/击/躲的身体路径，再用短镜头接球体、触点和受击者；高速运动结束立即给稳定接收者反应和关系 OUT，避免整段持续摇晃或用运动模糊遮掉接触 |

每个运动句落成：

`IN（机位高度/距离/看向、焦段景别、人物屏幕位置和前中后景）→ camera路径与演员路径分别变化 → 遮挡/占框/背景视差变化 → 焦点归属 → OUT（停稳或运动交棒、可见关系状态）`。

不需要在正文机械罗列坐标术语；写出的画面必须足以重建。locked-off对应camera零路径、无摄影机引起的视差，演员和道具仍能运动。

## 四、镜组与时间分配 →【运镜与时间轴】

- **人物关系镜组：** 关系景 → 触发/说话者 → 接收者反应 → 必要触点或共同画框。按照信息归属选择镜头，不按每句台词机械反打。
- **触点镜组：** 关系和接触可见 → 手/物件局部或同镜移焦 → 接收者眼神 → 关系 OUT。删去其中任何一镜后仍能读清因果时，可以合并；不能为套镜序增加原剧情没有的触碰。
- **出场镜组：** 空间及观看者 → 当前动作局部 → 主角脸/关系全貌 → 他人反应。多次剪辑与连续揭示是两种写法，按实际生成需要选。
- **心动镜组：** 当前动作真实发生 → 接触或目光使观看节奏短暂延长 → 被影响者反应 → 回到共享空间。只有主观段局部放大柔光或放慢，不让整场动作漂浮迟缓。
- **动作转关系：** 先用可读景别交代接触、路线和结果，再用稳定近景接眼神变化；极浅景深和密集脸部插入不能替代清楚的动作因果。

制作时可从“物件/触点约0.5–1.2秒、目光反应约1.5–3秒、双人关系或短跟随约2–4秒”开始估时。对白、串行动作、移焦、阅读与停稳所需时间决定最终镜长，不机械固定节拍。

镜头在关键表情出现前到位，在变化读清后切出；OUT保留下一镜要继承的朝向、握持、距离和视线。CUT只用于剪辑/新机位，BEAT用于同镜的目光、移焦、停步或重构图。继续遵守主 Skill 的分段上限和既定时间码规则。

## 五、人物情绪与表演 →【运镜与时间轴】

每次情绪变化先给角色一个可玩的目标与外部刺激，再把微表情、手部、躯干和对方接收反应按因果排序。表情不是“悲伤/心动/愤怒”标签，必须落到可见肌肉与动作；镜头在变化出现前到位、变化读清后切出。

| 机制 | 表演指令 | 镜头和节拍 |
|---|---|---|
| P1 克制与试探 | 视线先到对方眼睛或道具，眉眼稍收/放，唇线短促变化；肩和脚先不动，随后才俯身、转头或让出距离 | 关系景交代两人谁先靠近；近景稳住脸，给对方接收反应，不让摄影机运动代替眼神戏 |
| P2 惊讶与轻喜剧 | 原动作保持一拍，触发后眼睑抬起、下颌松开、上身反冲；旁观者可晚半拍交换视线、张口或缩肩 | 先证明球/物件与人发生了什么，再切受影响者及旁观者；疼痛和喜剧分开处理，不以夸张表情掩盖动作后果 |
| P3 疼痛到决意 | 受击处先有本能躲闪和支撑脚变化，手摸伤处、呼吸变短；恢复时下颌收紧、握持重新稳定、眼睛重新锁定目标 | 同一处伤痕和服装状态跨 CUT 保留；用脸、手、脚和关系宽景交替，让观众读出从失衡到重新行动 |
| P4 行动中的信任转移 | 一方伸手或抓袖时，另一方手臂、肩线和步频被真实带动；回头确认后才同向运动 | 先见可达的接触，再给触点、双人同向运动和追者相对位置；情绪从戒备到接受由握持松紧、回眸和距离变化证明 |
| P5 群体凝聚与胜利余波 | 每人沿已有位置把手叠向同一中心，接力动作后才共同发力/喊口号；结果出现时主角可先发怔、再呼吸和微笑，群体从外围靠近 | 宽景保人数、站位和动作中心；手部近景只在真实叠手/触垒/接物时使用；高潮后留稳定近景给情绪落地 |
| P6 隐忍与权力试探 | 人物先维持站姿或原手势，视线短暂落到钱、钥匙、伤处或对方手，再抬眼；握拳、抿唇、放松下颌或缓慢俯身必须有外部触发，另一人用停步、抱臂、退半步或不避眼神回应 | 先用走廊轴线、桥边留白或室内双人中景给出身位，再用稳近景读小幅变化；一次视线交换后回到双方距离，不用无因环绕替代权力变化 |

## 六、音频与声画接力 →【声音设计】和【运镜与时间轴】

声音设计从当前场景真实声源出发。对白、呼吸、衣料、脚步、雨水、球/手套、车辆、群体和音乐分别写声源、距离、强弱与出现/退场位置；不存在的声源不自动添加。对白有可听起止并给演员口型和接收者反应。音乐仅在剧本或当前创作要求成立时加入，避开需要清楚听见的话和触点。

| 机制 | 执行规则 |
|---|---|
| S1 亲密/警觉的声音收束 | 动作高点后暂时降低群体与音乐密度，让脚步停止、衣料、呼吸或一句短对白有可听空间；镜头也从高速切换回稳近景。声音变小是相对层次，不把场景变成无来源真空。 |
| S2 动作点同步 | 投球、挥棒、球入手套、受击、钥匙接手、车把交接、脚踩垒包都先给可见接触点，再把相应拟音准确落在同一帧附近；前后声桥只连接真实连续动作，不用声效补造未发生的结果。 |
| S3 追逐声场透视 | camera 与角色相对距离变化时，脚步、轮胎、呼吸、雨声、发动机或追兵呼声按真实出现的声源和近远层级变化；转角或遮挡让高频与混响短暂改变，进入新空间后建立新的环境底。 |
| S4 群体与高潮 | 比赛、围观或集体动作先保留个人声源，再将观众/队友声压逐步扩展；击中目标、触垒或叠手时让关键声点清楚，高峰过后抽低群体与音乐，留主角的表情和一句回应。 |
| S5 歌曲与对白共存 | 若故事明确有歌词/配乐蒙太奇，歌词只占音乐层，不替角色说话；音乐推动运动镜组，到需要听清对白或接触的 CUT 暂退。不要在无音乐剧情里自动补流行歌。 |

## 七、编译约束

【基础风格】每个独立段重复：摄影机/画幅 → 镜头与景深倾向 → 当前光色分支和真实光源方位 → 空气与纵深 → 皮肤及关键材质 → 调色与黑位。只写本段成立的分支。

【运镜与时间轴】五行前提后，每 CUT 写具体机位、画面人物关系、当下动作、camera 路径或固定、焦点转交、光区变化、可玩的表情与肢体动作、声画触发点及关系 OUT。全段基线不在每镜重抄；本镜独有的窗光入脸、跨门冷暖变化、雨伞遮光等才写入 CUT。

【声音设计】只写本段确有的环境底、语声源、动作/生理拟音、空间远近和可用音乐；对白与动作声的精确触发写在对应 CUT，声音栏只总括混音与跨镜延续。

合并前只确认本次摄影选择的直接效果：空间和接触能看懂；脸与目标反应能看清；摄影机、演员、剪辑、移焦被分别写清；光源在反拍中仍成立；已锁剧情与时长结构保留。检查随主 Skill 的既有预检完成，不新增审批或独立验收关卡。
