# Phone Vlog

适用：手机记录的生活、旅行、情侣、家庭与人物 Vlog，包括自拍、同伴手持拍、镜面自拍和把手机放在某处录。用于 Seedance 提示词的成像、拍摄关系、画幅运动、表演和同期声编译。

路由：由 [STYLE_ROUTER.md](../STYLE_ROUTER.md) 按类型选中，或由当前用户/项目明确指定时加载。正剧里只有个别镜头是手机画面时不换包，那几镜按 [04](../../04_CAMERA_LIGHT_COLOR_STYLE.md) 的 POV 规则写清画面来源。当前用户规则、角色、画幅和媒介优先；只提取当前故事成立的方法。

## 挂载与作用域

成像、光色和景深写入【基础风格】；拍摄关系、持机手、画幅运动、构图、表演和切点写入【运镜与时间轴】；人声、环境和动作声写入【声音设计】。保留主 Skill 的栏目和时间轴开头的“前提 / 核心关系 / 导演意图 / 演员指令 / 对白规则”。

“手机质感”来自观看位置、真实光源、人物动作和同期声共同成立，不来自品牌名、4K、HDR 或“电影感”一类词。用户指定机型时可以写进【基础风格】首行，但它不保证模型模拟出该机型，后面仍要写可见结果。

## 一、成像基线 →【基础风格】

- **画幅**：全段只用一个画幅。用户没给时，Vlog 常用竖屏 9:16，作为可撤销的建议写明。
- **近距离透视**：手机贴近拍时近处更大，伸向镜头的手、鼻尖和额头容易膨胀。写清人物离镜头约多远（一臂远、半臂远），合照给画边的人留出位置，不只写“不畸变”。
- **景深保留环境**：背景要认得出是哪条街、哪间屋，人与环境的距离可读。只有近物特写或用户明确要人像模式时才有自然虚化；不写大光圈奶油虚化。本包选中时，04 的默认浅景深写法让位于此。
- **细节不过锐**：保留皮肤起伏、细发、布纹和眼睛里的真实反光；不写毛孔刻线、锐化白边、蜡样皮肤，也不要求远景脸和近景一样细。
- **亮暗层次**：亮天空、窗外和人脸可以同时有层次，但不像分别打光后合成；暗部保留方向和对比，不整体抬灰。
- **曝光与白平衡稳定**：人物从树荫走进阳光，亮度随之适应一次即可，不反复抽动；混合灯光保留合理冷暖，肤色不每镜跳变。
- **对焦跟着观看对象**：对镜讲话时脸清楚；展示物件时焦点转到物件，人物成为可读背景，回到脸时再回焦。不在每次转头时安排跑焦。
- 不为“像手机”刻意加噪点、跑焦、曝光抽动、果冻变形或碎脸拉丝。高质量手机画面和故意做坏是两件事。

## 二、光源分支 →【基础风格】

每场确定光源、方向、软硬和人物与背景的明暗关系，选一个分支为主。

| 场景 | 写法要点 |
| --- | --- |
| 晴天户外 | 太阳方向明确，直射处亮，阴影有地面和墙面反射；大反光面可自然补亮脸。不把每天都写成日落金光 |
| 逆光 | 发丝有亮边，脸靠环境反射可读，五官和眼睛保留明暗，不被大片光雾盖住 |
| 阴天 | 光柔但有层次：天空开口、建筑遮挡和人物朝向造成脸上的轻微明暗 |
| 窗边室内 | 窗是主光，室内墙面反射补光；人物转身时脸上亮暗关系跟着变。窗外不过曝成一片白 |
| 夜间街头 | 路灯、店招、车灯照亮脸，暗部可有少量自然噪点；不默认重颗粒、脏和糊 |
| 车内 | 车窗方向决定脸上的光，经过遮挡时光影随之掠过；窗外景物移动和车辆转向、人物身体惯性一致 |

## 三、拍摄关系 →【运镜与时间轴】

`前提` 或 CUT 1 先写清画面是哪台手机看到的、谁拿着、哪只手。一镜之内不换拍摄关系；要换，用 CUT，或写出可见的交接（把手机递给同伴、把手机靠在包上）。

| 关系 | 画面来源写法 | 手和空间 |
| --- | --- | --- |
| 自拍 | “阿某右手举起的手机前置镜头视角，约一臂远、略高于眼睛”；画内是她的脸、肩和身后环境，举手机的手臂可以从画边伸出画外 | 持机手只在手臂可达范围里抬高、拉近、转向身旁的人；镜头不会绕到她背后看她自己。另一只手做当前任务 |
| 同伴手持拍 | “同伴手中手机的视角，同伴在画外镜头后方，本镜看不见”；人物可以看镜头、走向镜头、逗镜头后的人 | 写清同伴相对人物的位置和跟随路线，路线不能穿过车、家具和人。同伴说话从镜头近处传来，用声音特征写，不点名到画内 |
| 镜面自拍 | 镜中可见她和她手里的手机；分开写实际持机手、镜中看到的位置和镜子背后反射出的房间 | 镜中只有她一个人、一部手机。手机在镜中可见是正常的，不和“手机不入画”同时要求 |
| 放置机位 | 手机靠在桌面、包上或窗台上录，固定视角 | 画幅静止，人物进出画面改变构图；本镜不写呼吸漂移 |

- **手的分配**：持机的那只手一直被占着。另一只手拿饮料、牵人或展示物件时保持这个状态；需要双手的动作，先写把手机放下或交给同伴，不凭空加三脚架或自拍杆。用户要自拍杆时，作为道具写进【角色/场景/素材锁定】。
- **前后镜头**：要拍对面景物时三选一：把当前手机转过去拍、CUT 到后置镜头画面、剪入另一镜。不暗示同一镜里无缝切换前后镜头。
- **画面来源只写正面**：写画面里有什么、手臂从哪边出画；不写“无手机入画”“没有拍摄者”之类的否定清单，也不写拍摄者、摄影师、稳定器（会触发 M32）。
- **车内**：锁定座位、靠哪侧窗、持机人坐哪排。行驶、倒车、转弯在时间轴里连续交代；驾驶者视线以道路为主，不为对镜讲话持续回头。

## 四、画幅运动 →【运镜与时间轴】

本包选中时，04 的画幅呼吸感照常开启，但来源写成剧中持机的人：

| 状态 | 画幅表现 |
| --- | --- |
| 站着对镜讲话 | 随持机手臂的细小修正轻微漂移，构图偶尔被拉回 |
| 边走边拍 | 随步伐不均匀起伏和侧摆，转弯时构图修正略迟 |
| 笑、跳、上台阶 | 手臂跟着身体颠动一下，随即回稳；关键表情那一刻留出辨认机会 |
| 同伴跟拍 | 随画外同伴的步伐起伏，同伴停下时画幅也落定 |
| 放置机位 | 静止 |

- 手持不等于全程震屏，稳也不等于滑轨般悬浮。有原因的跟随、转向和惯性留下，其余保持稳定。
- 镜头转向时写转向谁、往哪边、为什么转（“她把手机转向身旁的阿某，让他看见路边的猫”）。
- 自然遮挡转场要有真东西经过镜头：衣袖、门框、路人、桌沿。写进入方向、遮满的时刻和下一镜从哪里接出。手捂镜头只在本场明确需要时用。

## 五、镜组与时间 →【运镜与时间轴】

先决定本段是一次连续记录、同一次记录里的几个镜头，还是跳时间地点的 Vlog 蒙太奇。蒙太奇可以跳，但每一镜仍有一台手机作为来源，不写成一镜到底又凭空换机位。

| 镜组 | 顺序 |
| --- | --- |
| 对镜开场 | 自拍近景说出今天要做什么 → 转向身后的地点 → 回到脸上的反应 |
| 展示发现 | 看见物件 → 把镜头转过去并靠近 → 焦点落在物件上 → 转回脸说感受 |
| 同伴互动 | 自拍里说话 → 转向同伴等他接话 → 同伴的回应 → 两人同框 |
| 边走边讲 | 自拍或同伴跟拍的行走中景，背景持续变化；停步时落成中近景 |

镜头数按观众要看见几件不同的事来定，不按固定秒数配额。时间区间用连续整数秒，不用小数秒假装能控制每个微表情。动作中切和一句台词跨镜按 [05](../../05_ACTION_PERFORMANCE_BODY_MECHANICS.md) 的对话双向表演和 [06](../../06_TIMELINE_EDITING_SOUND.md) 的切点规则写：前镜只送出动作，后镜从中段接住；完整台词只说一次，后镜写“画外继续说完”。

## 六、表演 →【运镜与时间轴】

- 对镜讲话是剧情里的发声，不是旁白。眼神对象每一刻都明确：看镜头、看同伴或看景物，不随机漂移。
- 先写发现了什么、想让谁看见或答应什么，再写身体动作。活泼的人可以兴奋地凑近镜头、蹦一下、抢着展示、笑到说不下去；强度由人物和事件决定，不默认“电影感就要克制”。
- 不靠歪头、眨眼、嘟嘴这类卖萌清单撑场面，每个可爱动作都对着一个具体的人或物。
- 同伴是听者也要有反应：在画内时按 05 写语义节点的反应；在画外时用声音回应（笑出声、接一句已有的台词）。
- 保持角色的脸和身材，不因“灵动”“好看”改五官、拉长腿或缩小头。

## 七、声音 →【声音设计】

- 近处人声清楚、离得近，带当前空间的真实反射；画外同伴的声音按他离镜头的距离写远近。
- 写少量有辨识度的同期声：近处呼吸、笑声、衣料、手里物件的声音，远处脚步、车流、人群或风。不为每次转头加呼啸音效。
- 默认无背景音乐、无对白字幕、无额外解说；用户指定配乐、字幕或静音时按本次要求。对镜讲话是剧情发声，不因“无旁白”被删掉。

## 八、常见问题修复

| 症状 | 多半的原因 | 改法 |
| --- | --- | --- |
| 自拍变成外面的机位拍她举手机 | 同时写了自拍和环绕、外部机位 | 只保留手机前置镜头的视角，删掉外部机位路径 |
| 手机或自拍杆突然入画 | 拍摄关系没定，或镜面参考被整体继承 | 先定自拍、同伴拍还是镜面自拍，再按第三节正面写画面来源 |
| 持机者双手都在忙、画面却悬着 | 持机手被安排了别的动作 | 换成空着的那只手做动作，或先写放下、交出手机 |
| 像广告或影棚 | 全脸柔光、极浅景深、滑轨般平稳、空笑摆拍叠在一起 | 换成真实环境光、可读背景、人物有目标和对象的动作 |
| 塑料皮肤或过锐 | 写了无瑕、每根毛孔、极致清晰 | 回到第一节的细节写法，删掉磨皮和锐化相关的词 |
| 脸忽明忽暗、肤色跳 | 光源方向或时间跨镜重置 | 锁定主光方向，亮度只随遮挡和走位变化 |
| 满屏乱抖 | 堆了强烈晃动、失焦、快速甩镜 | 按第四节只留有原因的晃动 |
| 车停了背景还在动 | 对白段没写持续的行车状态 | 时间轴里每段都写清行驶、转弯或停下，以及窗外移动方向 |
| 自己加了音乐或字幕 | 参考素材带音乐/字，或正文写了 MV 感 | 声音栏写明本场的声源；必要时提醒参考素材可能带入 |

## 九、编译约束

【基础风格】按“画幅与手机记录感 → 主光来源与方向 → 人与背景的明暗和景深 → 本段独有的光线变化”写，相同基线不在每个 CUT 重抄。

【运镜与时间轴】CUT 1 前的 `前提` 写清拍摄关系、持机的人和手、镜头离人多远；每个 CUT 写画面来源、取景、手臂或步伐带出的画幅运动、人物动作和对象、切点和 OUT 状态。时间区间连续覆盖总时长。

编译结束检查：观众始终知道自己在哪台手机里看；持机手和道具手不冲突；透视、景深、背景和主光互相支持；动作、台词和反应在总时长内放得下，跨镜不重说、不重启动作；行车、视线、服装、道具方向和光线连续；结尾停在可承接的状态，没有要求时不发明下一场。
