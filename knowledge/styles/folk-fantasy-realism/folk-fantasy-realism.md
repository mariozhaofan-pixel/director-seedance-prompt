# Folk Fantasy Realism

适用：写实人物置于具有生活痕迹的城市、室内或舞台空间，以人物关系、民俗幻想、超现实动作和克制喜剧形成反差的段落。用于 Seedance 提示词的摄影、构图、光影质感、表演与声音编译；其他题材只调用空间条件成立的机制。

路由：由 [STYLE_ROUTER.md](../STYLE_ROUTER.md) 按类型选中，或由当前用户/项目明确指定时加载；入口的类型选择视为启用本包。文件名只标识适用类型，不是剧情与人物模板。当前用户规则、角色、画幅及媒介优先；只提取当前故事成立的拍摄和表演方法。

## 挂载与作用域

当前项目启用本规则后，以当前剧本、参考角色、场景结构、道具状态、对白、画幅、段长与结尾 OUT 为确定输入。本规则决定这些输入如何被观看，不添加固定人物、专属服装、指定建筑或额外剧情。每段选一套主光色、一组主次关系和一条主要运动逻辑；按动作需要调用补充机制，不把所有效果叠在同一镜。

光影质感是本包无条件的最高优先级：每段【基础风格】都写清光源、方向、明暗反差和光质（软硬与扩散），再落实真实明暗塑形、肤眼细节与独立发丝，然后才安排运动强度和焦点接力。光源按场景成立：确为夕阳时用 L8 的侧逆光；夜景、封闭室内或其他时段用场内成立的光源，延续同样的真实质感。角色肤色、瞳色和身份沿用当前角色锁定，不因风格挂载统一改色。

保留主 Skill 的五栏：`【角色/场景/素材锁定】`、`【基础风格】`、`【运镜与时间轴】`、`【声音设计】`、`【画面限制】`。素材锁定只列本次实际提供给生成模型的素材，并按[02素材路由](../../02_REFERENCE_ROUTER_AND_LOCKS.md)写清各自控制维度；分析资料与仅后期挂接的素材留在候选外台账。成像、光源、综合色与材质写入基础风格；构图、演员路径、摄影机路径、移焦、动作节拍与停稳点写入时间轴；声源、距离、层级和跨镜延续写入声音设计。

版本格式：Seedance 2.5 段在【运镜与时间轴】CUT 1 前写“前提 / 核心关系 / 导演意图 / 演员指令 / 对白规则”五行，各行定义按 [06](../../06_TIMELINE_EDITING_SOUND.md)；只有显示时码时，各 CUT 区间才连续覆盖本段时长。2.5 五行的本包偏重：导演意图写清观众接收信息的先后，例如“先让观众看清牵引关系，再让接收者发现危险”；演员指令写具体眼手身步的顺序。独立视角使用真实 CUT，同一镜内的表演、移焦和重构图使用 BEAT。

## 一、整体视觉目标

让人物先站在可信的空间里，再让异常从门窗、器物、身体动作或远处目标中发生。宽景负责路线、尺度与受力关系，局部负责手眼、接触和材料变化，反应近景负责接住后果；前景遮挡、远近视差与明暗分层始终帮助观众辨认谁在行动、谁在接收。

以有方向的自然光或场内光塑造人物，保留帽檐、发丝、衣背和房间角落的暗部；把暖亮边、少量饱和色和细小材质反光放在信息位置。速度由主体近远变化、遮挡、衣物惯性和触点前后的节奏建立，摄影机在完成信息任务后停稳，给表演和空间后果留时间。

### 1. 成像基线 →【基础风格】

**【光影——最高优先级】**每段先写光：光源、方向（以场景平面为准）、明暗反差和光质。暖感来自真实光源与环境反射，不靠全幅橙色滤镜。面部形成真实明暗轮廓，背光侧允许自然压暗，但眼下、鼻翼、唇线与必要五官仍可辨；朝光边缘与正面的环境反射柔和过渡，不能把整张脸压成死黑剪影。曝光保持克制，保住皮肤、亮发与天空层次，不为提亮面孔把环境一起抬白。摄影机移动或反拍时，光源固定在同一场景方位，受光侧随真实几何变化。确为夕阳时，侧逆光的角度与写法按下方 L8。

- **画幅与空间：**采用当前项目要求的画幅。横幅可容纳两侧夹框、长动作线与多人关系；竖幅将同一关系改成近下方遮挡、中部人物、上部目标或出口，重新安排站位和视线空间。保住手部连接点、落脚处与目标，不能直接裁掉横幅两侧后仍声称关系完整。
- **透视：**空间建立和全身动作允许近大远小，近镜鞋底、袖口、横杆或巨型物体可以明显放大，但关节连接、人物比例和远处尺度参照要稳定。人物反应以自然脸部体积为先，避免把每个近景都处理成压扁的长焦肖像。
- **景深：**关系宽景让行动路线与环境锚点可读；人物近景允许背景软化，保留窗格、灯点、墙色或对手轮廓。近景遮挡可以很虚，焦点必须有归属。眼睛、手部触点和被操作物之间只在信息交接时移焦，不能整镜随机呼吸式失焦。
- **真实皮肤与眼睛：**肤色层次、纹理、光泽和眼睛按 [04A](../../04A_LIVE_ACTION_TEXTURE.md) 第三节“写实人物肤质与眼睛”写。本包补充：暖光不能把皮肤涂成均匀橙色；受力或狼狈状态允许汗点、泛红和压痕；眼神光随视线和机位自然移动，不贴一圈固定补光灯光斑。
- **逆光发丝：**头发处在侧逆光或逆光中时，显出大量可分辨的独立发丝、半透明碎发与局部亮轮廓边（暖光下为金色）。迎光碎发透亮，密集发束内部仍有深浅和遮挡；风动或转头时，发丝先后摆动、亮边随朝向变化。禁止把整头头发糊成一团、涂成连续发光外壳，或让每根发丝都同样明亮。
- **衣料与其他材质：**棉布、针织、绒毛用细碎漫反射；缎面沿褶面形成较宽柔亮带；皮革和金属只在曲面转折上出现局部亮线。保持它们与皮肤不同的粗糙度和反光尺度，不全部磨成同一种塑料。
- **高光与黑位：**亮窗、天空、灯泡和金属反光可以比脸亮，明亮边缘平顺过渡；重要窗格、漆面凸纹与皮肤不过度糊成白片。黑衣仍分出前后叠层，阴影里保留必要结构；近镜遮挡或深门洞允许接近黑，以面积与层次组织画面，不给全场统一加灰。
- **空气与材料：**尘、烟、碎屑只在有动作和光路的地方出现；逆光使尘边显亮，暗背景让碎片切面可读。湿地面的反射沿道路延展并受石缝打断，旧墙以剥落、污迹和粗糙颗粒承接侧光。漂浮特效仍服从景深、遮挡、速度模糊与材料响应。
- **速度质感：**快动作保留合理方向性拖影，短暂减速用于接触、裂纹扩展、反应或姿态的可读性。慢下来的主体仍有衣角回落、碎片离开、眼睑变化或尘粒运动，不把一张静态姿势无限冻结。

**成像检查：**整体亮度克制，皮肤保留结构与自然血色，面部明暗由场景光源塑造；质感来自真实光比、材质和细节层次，而不是锐化、全幅柔光晕或饱和橙青调色。脸部暗面、自然血色、角膜湿亮与半透明碎发同时成立，不能只保留其中一种。这些目标用正向句写进【基础风格】，不在【画面限制】里列否定清单。

### 2. 场景光色分支 →【基础风格】

以下按空间和动作选用。光源的左右描述以场景平面为准，反拍后只改变画面中的左右位置，不让同一扇窗或同一盏灯跳到另一面。光色强度按可见结果调整，不把数值参数当作统一配方。

| 分支 | 光源、方向与阴影 | 调色与材质结果 |
|---|---|---|
| L1 暖窗与青绿旧室 | 用于高窗、柜墙、木箱或狭长旧室中的对话。让一排窗位于人物侧后上方，暖日光沿地面形成斜亮条，擦亮头发、白袖、箱沿与金属弧边；脸的正面只由室内反射轻托，帽檐下和背窗侧保持暗。人物走近镜头、离开窗区时受光面积自然缩小，不能面部亮度始终锁死。 | 墙、柜和阴影压在低饱和青绿、橄榄或灰绿，暖肤色与木面成为局部亮区；红装饰只作小面积色点。金属有窄亮线，粗木有断续暖反射，黑衣以轮廓与褶皱分层。 |
| L2 亮窗前的受限关系 | 用于人物坐低、被物体遮挡或需要手腕与窗框建立关系。把高亮窗放在人物身后，窗格保持可辨，近处深衣、器物或门柱占一侧；后光勾肩发、手指和袖边，正面补光只到眼口与抓握可读。 | 亮窗、人物中间调、近黑遮挡分成三层。肤色暖于青白窗光，银色连接物保留细亮边；反打继承同一光位，不把所有脸均匀打亮。 |
| L3 旧街日光与暗店面 | 用于街头行走、桌边对峙与巷道追逐。上后方日光勾发梢、鼻缘和肩边，宽软天光托住脸；店内、骑楼顶和背光墙保持深棕或灰绿。人物经过柱影时，让额、脸、袖的亮区按走位依次变化。 | 地面与旧墙以暖灰、米褐为底，青绿桌面或冷墙形成次色层；服装饱和色不污染皮肤。瓷沿、戒指、指节与牌块圆角分别出现小高光，背景磨损可读但不争主次。 |
| L4 暖木茶室与镜前工作区 | 用于桌边从容动作、镜前停顿或室内人物揭示。让窗外青绿日光形成远层，台灯、镜周暖灯或暖反射落在脸侧、瓷器与台面，房角与近处发背保持深暗。镜中亮暗必须对应真实人物所在位置。 | 木、竹、旧箱面用琥珀至深褐色；米白袖与瓷面承接小片暖亮，黑衣保留软褶。暖色集中于有人活动的区域，不能把窗外景与阴影一起染成橙黄。 |
| L5 舞台暖场与暗观众层 | 用于多人表演、台口动作和器物触点。让场内顶侧暖光照木地板、帷幕与演员，台前及包厢观众压暗；栏杆或灯点按远近逐层重复。人物靠近侧幕时，身体一侧进入深影，受光袖口和皮肤仍可识别。 | 木地板有宽而不刺眼的暖反光，金线与红布形成有限亮点。前景黑幕、台上暖中间调、远处观众暗层并存。火焰只增加邻近面和地板的局部反射，不抹掉舞台原有光位。 |
| L6 青白交通空间 | 用于车厢、连廊或拥挤通道。以侧窗的大面积青白日光为主，人物暗侧保留柔和反射；让窗外亮景、车内人群和近镜肩背形成层次。顶灯存在时只在扶手、头发和瓷面留下窄长亮带。 | 背景偏冷灰、青绿，肤色略暖；主角的综合色与周围低饱和衣服分开。白衣和白瓷保留褶皱、脏迹或细裂，绿色小发光点只照邻近边缘，不把整张脸染绿。 |
| L7 金色城市与蓝黑夜空 | 用于夜间高架、江岸、桥梁或高处追随。将密集暖楼灯放在路径一侧，另一侧是低亮江面或蓝黑天空；灯光在朝向城市的发、裸肩、衣缘上形成暖边，背向城市一面保持冷暗。月或远楼可作稳定的远景锚点。 | 暖金建筑、蓝黑大底与少量红色动态物形成三层；红缎只有朝光的窄亮褶，暗面仍有厚度。高速移动时近栏杆拖影强、远楼慢移，不能用整幅光斑遮掉路线。 |
| L8 夕阳侧逆光与暮色湿街 | 仅在确为夕阳时使用；本包的夕阳角度只在此定义。让低位夕阳从角色背后偏画面左约 25°—35° 照入，形成低角度暖金侧逆光：以首个主机位为参照，把“镜头→角色”连线越过角色后的方向作为正逆光零位，向画面左侧偏转；25°—35°指水平偏角，太阳高度另写为贴近地平线的低角度。光擦亮发丝、鼻唇边与衣肩；脸部由自然环境反射柔和承托，背光面保留结构。用于高处通话、城市俯视或湿街行走时，远端留暖亮口，地面反射顺消失点延伸。 | 自然暖光为整体基调，阴影可较中性或略冷，但不把脸染青。浅肤色保留白里透红与局部血色，独立碎发透出金边；衣料亮面随角度变化。帽檐压暗眼区时仍保留必要眼口结构，不用环形补光强行照亮。 |
| L9 冷暗动作空间 | 用于群战、粗壳破裂或低位身体动作。高处窗缝或定向冷顶侧光落在发顶、肩、鞋顶和碎片切面；背景压深，地面仅保留支撑点与粉尘亮边。暖色衣物或能量轨迹只占局部。 | 白灰壳体要有旧污、厚度与裂口后的暗层；橙色鞋、红轨与深蓝哑光服装各自成块。能量扫过时短促照亮邻近轮廓，离开后恢复原场景，不持续给整个空间加红光。 |
| L10 巨型对象与亮天逆光 | 用于屋顶、窄街或包围式威压。人物放在下部或一侧，巨型对象占上部与两侧，让亮天空从头部、手指或建筑间隙透出；对象靠近会逐步挡住光口，人物背面和脸的暗侧随遮挡变暗。 | 保留小人物轮廓、亮天与巨型体表的明暗差。彩绘漆面以凸鳞、刻纹、磨损和窄亮边显形；金红蓝是分开的表面色，嘴内与结构缝保持深影，不能全体成为自发光金属。 |
| L11 局部燃烧、烟尘与解体 | 仅在当前动作确有燃烧、撞击或材料变化时使用。效果从接触点、破损处或实体轮廓内起，先点亮紧邻面，再出现碎屑、烟边或烧蚀口；附近照明随效果增强和衰减。 | 纸壳先有焦边与薄片，厚壳先开裂再掉块，陶瓷保留锐利断面，金属/漆面按自身材质响应。红烟只照后缘和凸起脊线，前景仍可保持黑；禁止用全场白闪或均匀粒子溶解替代所有材料。 |
| L12 平面风格插段 | 仅在项目明确允许真人与平面动画切换时使用。以背光纸幕、木格窗或平面色块建立新的成像规则；保持上一镜动作方向、轮廓识别点与肢体相位，切回真人后恢复该空间的真实受光。 | 纸幕用暖米黄透光、深色剪影和关节化形体；手绘段允许平涂、线条与夸张惯性。平面角色不混用真人毛孔和体积光，真人回归后不继续漂浮或橡皮式变形。 |
| L13 屏光、招牌与脚灯分区 | 用于夜间室内、商街和石阶。屏幕靠近面颊时，只增加朝屏一面的冷蓝亮区，额头与后景仍保持原有暖色；人物经过商街不同招牌光区时，额、脸、腿和衣料按位置先后换色。阶边暖灯只擦亮踏步、鞋缘和附近墙面。 | 冷青或紫蓝大底中保留局部红暖点；屏光与环境光在脸上相接但不过度涂色。人物经过固定光区与灯光本身增强、回落是两种机制，分别编写；不能把光色改变都归因于移动灯具。 |

### 3. 焦段与景深分工 → 基线写倾向，具体选择写 CUT

先安排机位、人与物的距离及需要同框的信息，再选光学类别。下列类别是制作选择，不指定唯一机型或固定数值。

| 画面任务 | 建议起点 | 需要写出的可见结果 |
|---|---|---|
| 建立路线与全身受力 | 广角至适中广角，机位能看全落脚点和目标 | 两侧建筑、桌椅或台口导向人物；近物大、远人小，但脚、手与连接物没有透视断裂。背景可读，避免全景也化为散景。 |
| 双人、多人关系 | 标准视角或克制广角，先确定前后距离 | 对手的虚肩或袖口保留在边缘，主体脸和关键手势清楚；高矮差、座位差与人物间隔由同一空间呈现。 |
| 单人反应 | 标准至中长焦倾向，按所需环境余量调整机距 | 眼口细节可读，脸部体积自然；背景只保留窗格、墙色、灯点等定位线索。眼神转向一侧时留出视线空间。 |
| 手、眼、鞋与受力触点 | 近距离局部取景，按透视需求选择标准或较广视角 | 抓握、指缝、接触面、裂纹或唇缘成为清晰平面；另一人的局部或衣袖保留因果关系。极近眼部允许发丝遮挡，但眼球方向与湿亮边须可读。 |
| 压迫式近远并置 | 近前景广角关系镜 | 鞋底、器物或巨型体局部显著大于远处人物，远处脸或全身仍能定位；不能只夸大前景而把目标完全盖住。 |
| 注意力交接 | 具有可分离前后焦面的固定或缓移构图 | 先让前层清楚、后层可识别，再在动作提示后把清晰面交给后层；屏幕内的取景变化、演员接近与主摄影机移动分开编写。 |

## 二、构图机制 →【运镜与时间轴】

| 机制 | 何时使用 | 可直接编译的构图关系 |
|---|---|---|
| C1 近黑框住远亮人 | 人物被观察、被包围，或需要延迟露出 | 低至平视机位，用极近肩背、门柱、柜门或器物占一侧及下缘；人物放在中后景较亮通道，窗或门作远端锚点。先留能读眼口的窄口，遮挡移动时再露出手或全身，焦点不追近物。 |
| C2 高低三人关系 | 群体中有人主说、有人附和、有人维持压力 | 把较低或靠前的人放下中部，两名较高人物在后左右形成不对称竖框；允许部分肩头被切边，但当前说话者的嘴和主要手势必须完整。依次行动，一人开口时另一人停住，不做整齐同步群演。 |
| C3 低位过肩反打 | 一人坐低、受限或需要仰视站立者 | 接收者虚焦后脑或肩占近下角，站立者在中上部，梁架、管线或墙边向其身后汇聚；保留站立者持物手与接收者的方向。反打继承同一轴线和窗光，不为“强势”随意翻转空间。 |
| C4 顶视保住关系图 | 多方向逼近、器物变化、人员散开 | 接近垂直俯视，桌、窗边或地面图形为中心锚点，各人物先有明确方位；变化只发生在对应身体或道具上，未参与者和环境不跟着消失。看完变化后的空位再切近景。 |
| C5 低位触地与支撑 | 跨窗、落地、蓄力、起身或踢击 | 机位靠近地面，让前掌、鞋底、掌根或杆端落在可读位置；接触面有石缝、木纹或尘屑参照。触地局部之后接含膝、胯、肩的全身关系，观众能回溯重量如何传到地面。 |
| C6 宽景保连接点 | 牵引、旋转、对抗或有道具传力 | 抓握端、被牵端和至少一个支撑脚同框，身体转轴位于中景；近处经过的身体可短暂遮挡，但下一拍须重新露出连接。禁止把抓手改成抓脚，禁止用近景遮掉所有受力逻辑。 |
| C7 近大远小的动作轴 | 需要夸张力量或目标距离 | 鞋底、拳、杆端或巨型物局部靠近镜头，占前景一侧，行动者脸或接收者在斜后方；把接触区放在清晰平面。近物放大时保留完整方向线，不让透视把手臂或腿折断。 |
| C8 物件先于面孔 | 一次按压、扣合、落物或持物足以改变关系 | 用桌面或腰胸局部先给手指、器物和承接面，背景人物只留轮廓。让触点落稳、残余摆动减弱后再切面孔反应；贵重金属、布带或瓷器各有不同反光和惯性。 |
| C9 前后焦面交接 | 近处人物停口，后方有人举手、进入或被注意到 | 前景脸与手占一侧，后方接收者在未被完全遮住的通道。前人先停、后人动作提示，再转清晰面；两者位置保持，观众靠焦点理解注意力变更。 |
| C10 屏幕与现实双层 | 剧情需要拍摄、观看或展示设备 | 保留设备边框、持机手和屏外真实人物/窗光，先看到现实对象，再让设备升起并移焦至屏内。屏内换人或放大由设备转向、画面切换负责；主摄影机不随屏内倍率虚假推进。 |
| C11 中轴行走与两侧变化 | 人物稳定行进，周围发生异常 | 窄街、栏杆或扶梯向中心汇聚，人物在中轴或略偏轴，双侧对象分布近中远。背面宽景交代环境变化，正面中景读嘴、手掌和步态；近景对象变化后仍保留路线出口。 |
| C12 小人物与巨大包围 | 尺度差是本拍重点 | 小人物置下中部或右侧，巨型对象占上方、左侧或形成椭圆围合；用屋檐、柱列和地面保留尺度。巨物下压、第三对象进入或光口被挡构成升级，不能只让所有物体同时放大。 |
| C13 指缝与亮天 | 一个小手势控制大范围结果 | 侧面近景将脸置一侧、手置另一侧，双指之间留出亮天空，手和脸可近剪影但轮廓清楚；手指转向或轻压后切回宽景，让环境变化承担体量。 |
| C14 镜面多一层关系 | 同室内需要揭示另一人或背面状态 | 镜边、台面和近处头肩形成三层，镜中人物必须与实体人物位置对应；侧移使近头遮住再让开后方人，镜内只补充可成立的角度。避免无缘由出现双份身体或镜中反向动作。 |
| C15 固定倾斜关系镜 | 对峙或异常需要短暂失衡 | 用墙线、桌边或窗格形成稳定斜线，仍完整保留双方站位和可走路线。倾斜是机位姿态，镜内不必持续旋转；下一反应近景可以回正，让倾斜有使用边界。 |
| C16 动作后贴地静止 | 撞击、失败或狼狈需要落差 | 切地面极低近景，让帽檐、散发或衣角半遮脸，地面砂粒和磨损布纹在焦内；只给眼睑渐露、微张嘴或肩部松动。留住不能立即起身的状态，不在下一帧自动恢复整洁。 |
| C17 暗门与亮缝 | 出入、取物或段落结束 | 从柜内、门后或低位物堆旁观看，门板先形成细亮缝再打开，手伸入时允许近手失焦、脸保持清楚；关门时由门板真实覆盖人物，黑场来自遮挡完成。 |
| C18 动势匹配跨风格 | 当前段落允许图形化表达 | 真人侧跑或扑身占中部，下一平面镜接同方向和相同肢体相位；再以窗框、车窗或门口接回真人。每次切换保留一个稳定识别点，空间或材质改变要由 CUT 明确承担。 |

## 三、运动机制 →【运镜与时间轴】

每条只选择有信息目的的路径。摄影机的路径与演员的路径分别写；人物变大、物体飞近或布料遮满画面，都不能单独充当“摄影机推近”的指令。需要实体位移时，明确近处与远处的相对位移。

把“主路径、画幅微动、焦点路径”分开编写：主路径决定摄影机从哪里到哪里；画幅微动表现呼吸般的节奏、重心转移和步伐起伏；焦点路径决定哪一层清晰。纪实感不等于每镜都摇晃，镜头呼吸感在此指画幅的细微起伏，与 [04](../../04_CAMERA_LIGHT_COLOR_STYLE.md) 的自然呼吸感是同一件事，不是反复失焦或焦距抽动。正文只写画面怎么变，不写摄影师或器材，也不因此加喘息、脚步或操机声。M1、M14 等明确固定机位的镜头保持固定；需要肩扛时选择 M15—M17，并写明强度与结束时机，不同时要求零路径和明显晃动。

| 机制 | 起点与路径 | 终点、焦点与用途 |
|---|---|---|
| M1 稳机接住动作与反应 | IN：标准视角中近景，脸在一侧，窗格或墙线固定。camera：零路径。演员：眼先偏转，头随后转，手入画、抬起或收回；近处遮挡随演员动作变化。 | 焦点留眼或当前手部触点，OUT 在动作完成后的新视线、新持物状态上保持。适用于说话、忍住反应和接收信息，不给每次眨眼附加推进。 |
| M2 沿街侧前跟随 | IN：腰上中景，主体居中偏一侧，前方留行进空间。camera：沿街与人物近似同速平移；演员：持续前走，头可短看手中物。近人头快速横擦，柱列、店面较慢后移。 | 焦点锁主体，不追路人遮挡；近物过去后原主体重新露出。OUT 在人物停步、接收新信息或进入下一关系前减速，保留路向。 |
| M3 正面后退承接靠近 | IN：广角全身或中全景，路径在中轴。camera：沿同一路径后退，固定路面标记和两侧建筑向远处收拢；演员：更快向镜头跑来，使双方距离逐步缩短，人物从全身变中近景。人物与背景不做同步缩放。 | 焦点随人物推进，手中物、摆臂和落足有连续关系。OUT 在需要读眼口或举物时稳住；若下一拍仰向天空，先写明确仰摇，不把跑者放大当作变焦。 |
| M4 有视差的尾追与侧追 | IN：目标背面居中，近栏杆/轨道一侧、远楼与天空另一层。camera：沿目标路线追随，再以连续弧向变化转至平行侧追；演员或飞行物各自前进。近车体擦过快于远楼。 | 目标大小尽量稳定，方向改变由前景和远景视差证明。OUT 在双方相对位置清楚的侧全景停住或切接；不让背景与主体同速贴着画面移动。 |
| M5 视线触发快摇 | IN：人物侧脸或正面反应近景。演员先转眼、再转头指向画外；camera 随这一方向横摇或仰摇，途经墙面、桌椅产生方向性模糊。 | 在被看者、远跑者或持物动作上减速停稳，焦点恢复到新的信息点，至少留一个可读 BEAT。OUT 是明确关系镜，不能把整段写成持续甩动。 |
| M6 前后景自然移焦 | IN：聚焦前景物品、手或近脸，虚化背景人物，但仍能辨认其位置。camera 保持机位，或沿已指定的单一路径运动；前景动作结束、视线转移或后方人物举手后，焦点沿实际纵深连续移向背景。 | 转换中前景逐渐变软、背景人物逐渐清楚，不能整个画面同时糊一下再突然全清晰。焦点落在背景眼睛或当前信息点并稳住，OUT 由后方人物接过主要表演。反向移焦同理；设备升入前景时可由真人移至屏幕。不要同时加无动机变焦，移焦引起的轻微视角变化也不夸大成推镜。 |
| M7 短弧绕过头肩揭示 | IN：侧脸或伏台人物中近景，近肩、头发与台边形成遮挡。camera：绕人物一侧做有限弧移，先让后脑占中间，再绕出遮挡；演员身体基本留在原处。箱边、镜框、后方人差速移动。 | 焦点根据最终信息交给新露出的脸或关系层，OUT 在后方人物和镜中角度可读处停止。不用无差别环绕来装饰静止对话。 |
| M8 多向绕行后归正 | IN：侧脸近景，扶手或墙线倾斜，主体位置稳定。camera：沿可通行路径从侧面经过背面到另一侧，再抵达正面，同时适度拉开；高低和距离变化均由环境线条连续显示。快速近物只负责遮挡与速度。 | 最终消除起始倾斜，收于居中、近对称的半身关系；焦点守主体，碎片在各自景深层。OUT 留静止持物与周围余波，不强加完整一圈或重复绕行。 |
| M9 从人物退至空间外层 | IN：脸近景，后方人和窗格虚化。camera：连续后退，先露肩与桌面，再露整屋、近窗框、外墙与相邻建筑；近框移动显著快于远墙，原人物持续可定位。 | 焦点逐步容纳空间，亮暗随室内外占比变化。穿窗路径须由当前场景允许的虚拟机位或可通行开口成立；若空间不允许，就拆成 CUT。OUT 停在能交代外部关系的宽景。 |
| M10 低位跟物穿过障碍 | IN：台面器物或贴地目标在中景。camera：先俯摇承接落点，再沿地面侧移跟随；演员/物体独立落下、弹起或前走。近桌腿、桶边、门柱快速擦镜，远排桌椅慢移。 | 接触地面、起步和被遮后重现均须可读。OUT 在新空间的目标位置上稳定；黑柱遮满后的空间若改变，以遮罩转场编写（真实遮满画面后接新空间，不算隐藏切），不强求物理上一镜穿墙。 |
| M11 沿传力线找接点 | IN：伸手或绷紧的带、绳、杆从画内指向画外。camera：沿它的方向横摇到远端连接处，短停确认，再反向跟随回收的物体。演员完成牵引、接住、握紧。 | 焦点在连接处与握持处各稳定一次，不能一路模糊。OUT 可落在刃尖、指节或持物完成姿态，为下一行动提供清楚起点。 |
| M12 俯仰连接高低目标 | IN：地面人物抬眼或高处物体处于画面上部。camera：仰摇跟上升物，或俯摇跟下降物；建筑边、横梁和天空面积连续变化。主体路径另写上升、下坠或沿斜面滑行。 | 在屋顶目标、街面落点或落地人物上减速，先恢复空间可读性再接下一动作。OUT 保留脚点与余波，不在目标还未落稳时又反向甩走。 |
| M13 受控滚转 | IN：高俯或低仰宽景，窗格、楼层或地面线可定位。camera：绕自身视轴有限滚转，使这些线由平变斜；演员完成收腿、抓栏或回身，目标另走自己的路线。 | 不把滚转写成绕主体公转。OUT 停在仍可读路线的斜构图，或进入稳定反应镜；巨大物体绕人运动时也不自动追加相机绕圈。 |
| M14 静机看主体冲近与离框 | IN：固定俯拍地面或仰拍天空，主体在中远层。camera：零路径；主体向镜头、上缘或侧缘移动，按身体先后顺序离框，环境锚点不同比放大。 | 焦点跟主体或留在后果面，按本拍目的择一。OUT 继续看空地裂纹、尘云、残留物或被挡后的亮口，给离位造成的改变一个明确时段。 |
| M15 轻微肩扛呼吸感 | IN：对话、观察或人物近景，主体在明确构图区，前景与背景有距离。提示词用“肩扛视感，轻微晃动”。主机位基本停留，画幅随呼吸般的节奏和微小重心调整产生低幅、不完全等周期的上下起伏与细小左右修正；起、停有重量。 | 保持眼口、轮廓和关系位置可读，近边缘视差略大于远景；脸部与背景作为同一空间一起响应机位变化。焦点持续落在当前主体，不借呼吸感反复找焦。OUT 在表情或接收点轻缓稳定，保留少量自然微动，不呈完全机械悬浮。 |
| M16 中度肩扛跟随 | IN：同行、穿人群或紧张接近的中景，明确跟随方向和跟随对象。提示词用“肩扛视感，中度晃动，随步伐起伏”。画幅起伏来自跟随时的落步、转向与避让，构图对人物变向稍有滞后，再自然修正；近处遮挡与远景产生不同位移。 | 主体大部分时间留在可读区域，允许短暂偏离构图中心，但不能反复撞出画框。镜头重构图和跟焦分别响应实际距离变化；停步后起伏逐渐减弱，OUT 落在关键手势、眼神或下一行动目标上。 |
| M17 剧烈肩扛与冲击恢复 | 仅用于观看位置本身也在奔跑、急避或承受冲击的短段。提示词用“肩扛视感，剧烈晃动，随奔跑/冲击短促起伏”。沿已交代的行动轴前进，突发角度偏移与模糊由脚步或撞击触发，不作持续无方向振荡。 | 冲击前先给方向和空间，冲击后迅速重新找到主体；关键抓握、命中或落脚至少保留一个清楚的阅读拍。需要表情与对白时降至轻微肩扛或固定机位，OUT 随观看位置停稳而衰减，禁止整段同强度乱晃。 |
| M18 短促抽焦与自然追焦 | 当近物突然进入、人物快速越过原焦面或远处事件抢走注意力时使用。IN 先交代清晰对象；以该动作作触发，把焦点短促移向新的距离，主体纵向移动时继续跟随实际距离。主机位运动与焦点改变分别写。 | 可以有一次极短的清晰度滞后，随后准确落在新主体眼睛或触点并保持；普通移焦不必故意失准。OUT 必须明确落焦对象，不做持续前后抽动、自动对焦搜索或全幅脉冲式模糊；焦点变化不伴随人物变形、曝光跳变或无故改色。 |

**强度选择与组合：**静态观察和近景表演优先轻微肩扛，需要走动跟随时用中度，奔跑或冲击只在局部短拍用剧烈。每 CUT 选择一个主强度，只有动作条件改变才升降；两种强度过渡要有起因和衰减。画面侧逆光、脸部暗面与发丝轮廓随真实机位改变，不随晃动闪烁。需要移焦时先写“谁清楚→什么触发→焦点经过哪一层→谁接过清晰面”，再叠加选定的肩扛强度，不能把随机失焦当纪实感。

**可直接编译的写法：**“肩扛视感，轻微晃动；以人物中近景为主构图，画幅随呼吸般的节奏和重心微调缓慢起伏，眼口始终可读。先聚焦前景手中物品、虚化背景人物；前景手停住，背景人物抬眼时，焦点连续移向其眼睛，前景自然转虚，落焦后保持。主光仍固定在场景原方位，发丝亮边与脸部暗面随机位微动自然变化，肤色和曝光稳定。”夕阳场景再按 L8 写明夕阳在场景后左方。将示例中的人物、物件、触发动作及强度替换为当前 CUT 的实际内容。

## 四、镜组与时间分配 →【运镜与时间轴】

先按“关系成立—动作触发—接收反应—新状态”安排镜组，再分配镜长。下面的时长仅作生成排演起点；根据本段对白、动作距离、移焦速度和目标段长调整，不能把每个镜组都塞进同一段。

| 镜组 | 信息与镜头接力 | 时间、切点与继承 |
|---|---|---|
| A 物件启动对话 | 关系中景保留人物和物件 → 物件亮起、落稳或被拿起的局部 → 脸旁持物近景 → 接收者眼口反应。屏光只影响邻近面，桌上其他器物保持原位。 | 关系约 1–2 秒，物件动作约 0.5–1.5 秒，反应按完整眼口节拍留 1.5–3 秒。切在注意力已经转向物件之后；下一镜继承持物手、物件朝向和身体姿态，不凭字幕换镜。 |
| B 群体施压与迟一步回应 | 先给主说者居前、同伴居后的关系 → 中近景里一人说完、另一人附和 → 切接收者的低眼、闭眼、侧瞥 → 回到群体的新手势或离开。 | 主句允许一个稳定镜头承载，不逐句机械切碎。接收者反应要容纳“眼动—短停—头/口响应”，通常留约 1–2 秒；附和短句可在同镜内完成。离开用宽景看人走出，留后方未动者作为关系结果。 |
| C 从容者与急行者 | 跟随急行者进入空间 → 其目光触发快摇 → 停在从容者的喝水、整理或持物动作 → 切回急行者从张口到收口的反应 → 其转身或撤离。 | 快摇可短至约 0.2–0.6 秒，落位后给 1–2 秒读取手与脸，不能摇完立即切。反应的笑形、抿嘴或低头先完成再起身；跨镜继承杯盖、手势和视线方向。 |
| D 连续追逐与短暂失控 | 正面后退或侧追交代路线 → 宽景给障碍和方向 → 触地、跨越或翻滚局部 → 固定低位接近与落地 → 趴地短停、撑起、重新定位。 | 奔跑按路线长度给时间，触点可短至约 0.3–0.8 秒；落地后至少给衣发余动和一次重心恢复。背后上阶到阶下迎接必须切镜，切后人物仍沿同一路径靠近。不能用不可能的连续穿越维持“一镜到底”。 |
| E 蓄力—接触—材料后果 | 眼与嘴收紧的短近景 → 全身支撑与手部连接 → 动作沿清楚方向发出 → 触点近景减速看裂纹或火花 → 宽景看目标失高、碎片落下或人群散开 → 行动者收势。 | 蓄力约 0.5–1.2 秒，关键接触约 0.4–1.5 秒，后果与收势各保留约 1–2 秒作为起点。接触前材料完整，接触后才开裂；切宽景继承施力方向和目标落向，不能倒置因果。 |
| F 小手势与大尺度回应 | 固定远景先交代小人物与巨大群体 → 逆光指缝、握持或手腕近景 → 切回相同方位的远景看聚散、移动或让路 → 人物仍保持手势，环境逐渐安静。 | 手势近景以完成一个变化为限，不加无目的绕镜。远景给变化从起点到衰减的完整过程，通常比手势镜更长；声画可延续，但具体声源与音色由当前项目决定。 |
| G 空间层层揭示 | 近脸或局部动作开始 → 后退露出桌面与其他人 → 窗框进入成为近层 → 外墙和周围环境展开 → 外部事件触发下一 CUT。 | 一个连续路径只承担一次从小到大的关系升级，焦点逐步由单人转为空间。按距离为路径留足时长，不能用突然缩放替代近框视差；后续街道高俯或门口低位另写 CUT。 |
| H 物体异常与遮挡串联 | 固定或缓移镜先给正常器物 → 器物倾倒、落地、出现新的支撑 → 低位跟随穿桌腿 → 近柱遮满 → 新空间中目标接续同方向移动。 | 每次变化保留“原状态—过渡—新状态”，不能只跳到结果。遮挡前后必须继承方向、物体数量和速度趋势；若空间不连续，用遮罩转场连接，不虚构穿墙路线。 |
| I 高速群战与突然安静 | 低位宽景交代支撑和多方向目标 → 中景随转体守住动作轴 → 近景敌体擦镜但触点可读 → 宽景看残片落地 → 稳定俯角脸近景接抬眼与嘴角变化。 | 快段动作可连续，但每次攻击都有起点、接触、回收；最后一击后减速至站姿稳定，给碎片先落、肩再松的时间。面部镜不继续大幅晃动，让速度落差成立。 |
| J 巨型包围与微小回应 | 低仰宽景给两侧大体量和中央小人物 → 受力线中近景保留抓握点 → 眼部极近景看视线重新聚焦 → 回到威胁逼近的宽景 → 新动作从明确方向介入。 | 眼部镜允许较长停留，但须有眼球、眼睑或角膜高光的细微变化；不可添加倒影中的新剧情。宽景与局部之间继承人物朝向、受力侧和巨物位置，不能靠不停放大替代层级升级。 |
| K 动作姿态接平面表达 | 真人动作达到清楚轮廓 → 以相同方向与姿态切入纸幕、线稿或有限色动画 → 用窗口或相同身体相位切回真人 → 完成真实支撑、落地或穿行。 | 图形段可以压缩路程或夸张惯性，不能承担当前剧情必须看清的真实触点。切回后留一个恢复体积、材质和重心的 BEAT；二维缩放、漫画速度线与摄影机运动分别标注。 |

对白长度决定主说话镜的最低可读时长；听者必须有接收时间。对长句，优先在同镜内安排眼神、手势和接收者反应，不为增加镜数强拆语义。对短问短答，允许同一关系镜内交接主次；只有信息对象、空间关系或情绪策略改变时才切。

每个镜组末尾记录人物的位置、朝向、视线、支撑脚、持物手、衣发损伤与场内残留。下一 CUT 必须继承这些结果。动势可以连续，视角可以剪切；相同人物突然出现在另一地点时，必须由场景切换、风格切换或明确时间省略承担。

## 五、人物情绪与表演 →【运镜与时间轴】

情绪通过可见变化被理解。每个 BEAT 选择一条主要反应链，其余部位提供支撑或延迟，不让眼、嘴、手、肩、躯干同时达到最大幅度。头发、带子、衣摆和手中物通常晚于身体主动作到达终点。

| 机制 | 触发与表演顺序 | 镜头和对手如何接收 |
|---|---|---|
| P1 忍住即时回应 | 对手提出让角色不愿立刻回答的信息 → 目光先降低，眼睑缓合或短闭 → 嘴唇收拢，下颌保持低势 → 睁眼后先侧瞥，头与肩晚一点转。手维持原持物，不额外握拳。 | 稳定中近景保住眼口与少量肩线；让对手先等到侧瞥才再次动作。OUT 是“仍克制但注意力已转向对手”，不在同一拍又突然咧嘴或大幅退步。 |
| P2 低强度从容与对手忙乱 | 另一人急行、张口或催促 → 从容者先完成杯盖、指尖或腰前物件的小动作 → 手停后抬下巴、轻偏头、半眯眼 → 嘴开始响应，身体重心仍靠墙或留在座位。 | 用稳定侧近景或过肩关系保留对手虚肩；急行者的动作幅度与从容者形成差别，镜头停在小动作完成处。禁止让从容者也同步挥臂、跺脚。 |
| P3 笑形逐步收住 | 角色原本放松，随后发现画外异常 → 笑形和闭眼先维持短拍 → 睁眼并固定视线 → 嘴角停止上扬、嘴缝略开 → 头转向目标，肩稍后跟随。 | 近景先稳定，转头才触发摇镜或反打；对手或异常进入下一构图后，角色才缩身、离位或作答。让“看见”发生在“躲开”之前。 |
| P4 夸张说话与静态同伴 | 主说者需要占据谈话中心 → 眼睑开合、眉抬或眉间收紧 → 嘴从撮圆到张开，下颌前送 → 必要时肘外抬或手落腰腹。旁边人物仅轻偏头或保持直立。 | 多人中景保留三者不一致的节奏。主说者收口后，较矮人物的双手才从下沿举到头侧，附和完成后手落下；镜头不必为每个嘴形切换。 |
| P5 面部先蓄势，身体后发力 | 明确目标逼近 → 视线固定，眼下收紧、鼻翼或鼻梁微皱 → 唇线压紧、下颌收住 → 肩开始扭动，随后腰髋、膝与支撑脚启动。 | 脸近景只拍蓄势，切全身让力量来源可见；下一镜继承目标方向，不能先在脸镜出现大幅身体位移后又回到未发力姿态。 |
| P6 旋转牵引的真实支撑 | 当前动作需要牵住另一人或重物 → 先明确抓握部位并闭合手指 → 身体后坐、屈膝抵消牵拉 → 腰肩带动旋转，脚下小步换位 → 被牵对象延迟越过近景，头发和衣带再次滞后。 | 中全景先保住连接点和脚，近侧身体掠过时可短遮脸；目标接触后人物必须回收手臂、调整重心或失衡，不能无限匀速旋转。 |
| P7 减速接触中的细部 | 出拳、踢击或身体碰撞即将接触 → 肢体到位、接触面压紧 → 裂纹扩张或火星出现 → 碎片离开、衣袖继续前摆 → 施力者才回收或松臂。 | 焦点优先在接触面，后方脸可略软。对手材质先保持整体再分离；火花跟着接触位置短促衰减，禁止把摩擦火花改成嘴部喷射。 |
| P8 狼狈后的延迟恢复 | 翻滚、撞地或失败已经完成 → 身体先保持贴地，衣发余动停止 → 嘴微张、眼睑慢露 → 手掌放到肩旁，肘肩撑起 → 头离地并重新寻找目标。 | 固定贴地近景与低位全身分工，给地面接触真实时间；遮脸角色用手肩头轴表达，帽檐遮住的眼睛不强加夸张眼神。OUT 可以仍未站起。 |
| P9 受限后重新聚焦 | 手腕或肩袖受到限制 → 双臂维持受力方向、肩颈不能任意放松 → 头低、眼睑半落、嘴唇松开 → 目光先向上找目标，下巴随后缓抬，颈部逐渐伸直。 | 中近景保住两侧抓握点、布料拉伸和中央脸；可以接单眼近景，但不能让身体突然脱离限制。对手的握持状态持续到剧情明确改变为止。 |
| P10 眼先于头的认知变化 | 新对象进入视线或一句话改变判断 → 眼球先偏向一侧/上方，短停 → 唇合紧或下颌轻抬 → 头再沿视线转，肩最后响应。 | 稳机近景让眼球和散发都可读，不用额外摇晃。极近眼镜保留眼表反光、睫毛和微小湿亮，反光只作材质，不凭它添加未给出的画外事件。 |
| P11 高强度行动后的收势 | 最后一击或关键动作结束 → 支撑脚先稳住，身体维持动作终点 → 衣物、尘和碎片继续运动 → 手臂降低、肩部放松 → 头低位抬眼，嘴角可极小变化。 | 先宽景确认余波，再稳定面部接抬眼；不要让人物动作完成后立即换成无汗无尘的静态定妆照。接收者可后退、停住或重新注视，但不整齐同步。 |
| P12 行走中的稳定主体 | 周围对象解体、飞过或靠近，而角色保持行动目标 → 步伐连续、躯干相对稳定 → 手掌逐渐向外松开或维持持物 → 口角轻抬，帽檐下眼区可继续隐藏 → 衣摆随着每步延迟起伏。 | 中轴跟拍守住人物尺寸，异常在两侧发生。先让环境变化被读清，再给角色微反应；不能让脚下滑行、衣摆静止，或全身随每件飞物乱转。 |
| P13 人与手中角色分拍 | 人物与手偶、道具角色或小型伙伴交流 → 主人说话时手中对象可轻动 → 人嘴收住、低眼或抿唇时，小对象继续开合/摆动 → 人抬臂或转头才改变两者相对高度。 | 双主体近景让脸与小对象并列，动作一静一动；真正抓握处在画外时也保持手臂和道具连接合理。对话主次由动作停顿区分，不让两张“嘴”全程同步。 |

## 六、音频与声画接力 →【声音设计】和【运镜与时间轴】

按当前项目提供的对白与声音素材执行。以下为条件化声音设计：未提供的声线、配器、唱法和固定音效不设为风格必选项。画面的光影、构图、触点和表演先独立成立，再让声音加强距离、因果和节拍。

| 机制 | 执行规则 |
|---|---|
| S1 对白主次与接收时间 | 有对白时，以当前正在表达主要信息的人为前层，短回应和附和不得压住主句。接收者镜头允许主说者声音继续存在；在接收者准备开口前给收口、吸气或停顿的时间，具体是否有可闻呼吸按表演决定。台词逐字沿用当前脚本，不由表情或口型补写新句。 |
| S2 近景不等于全世界静音 | 从宽景切脸近景时，可适度降低环境层以突出语声或反应，但保留同一空间的基础声场。街道的远近层、室内的房间感、车厢的持续底声按场景建立；画面停住或没有对白时，不自动清空所有声音。 |
| S3 触点声按材料分工 | 如需要动作拟音，落脚、掌压、布料绷紧、瓷器触地、金属扣合分别对准可见接触。厚壳破裂从主接触到细碎脱落分层，薄纸燃烧与厚重坠落不用同一声音。画面先接触、声音同步到点，尾声随碎片落地延续，不能在接触前提前爆响。 |
| S4 画外信息引导视线 | 需要先声夺人时，让画外语声或动作声来自明确方向，人物先听到、转眼、再转头，相机随后摇向声源。摇到目标后声音的远近和遮挡要与新机位相符；不把任何无源巨响都用作转场。 |
| S5 对话跨镜接力 | 同一房间内的反打可用 L-cut，让上一说话者的尾句延续到听者脸上；下一空间确需预示时才用 J-cut，且在画面切入后交代声源。跨地点不能无条件继承同一混响，室内外变化由新空间的声音层完成。 |
| S6 快动作与落稳 | 默认无背景音乐；项目要求音乐或节奏音时，把主要重音放在动作发出、接触或信息揭示之一，避免每次挥动都加同样重击。快摇落位后给对白、器物细声或安静反应留余量；收势时减少密集音层，让衣料、脚步或余波成为节拍。 |
| S7 特效保持空间距离 | 只有当前剧情需要相应声效时才给能量、粒子或巨物设计声音。近处掠过的声像可移动，远处群体保持距离感；接触火星、局部烟与小光点不自动配成大范围爆炸。声音的起点、峰值和衰减须与效果范围一致。 |
| S8 喜剧延迟与动作后停顿 | 撞击、翻滚或意外后，可先让动作尾声结束，再让角色小声回应或迟一步开口；停顿长度服务可见反应。保持场景底声或极轻衣物余动，不用每次出丑都配固定滑稽音色；若项目本身不需要喜剧声音，就仅保留时间落差。 |
| S9 平面插段与真人回归 | 项目允许风格切换且需要声音桥时，保留同一动作方向或节奏作为桥，平面段可改变音色密度；回到真人的触地、抓框或入车动作时，恢复该空间的距离与材质声。音乐不能遮住切回后的关键触点与对白。 |

## 七、编译约束

### 1. 五栏职责

| 栏位 | 编译内容 |
|---|---|
| 【角色/场景/素材锁定】 | 列出本段实际使用的角色、空间、道具与参考素材。锁定人物身份、外观、持物关系和可通行结构；只把当前剧情确有的物件写入，不为了套规则补出窗、镜、手偶或巨型生物。 |
| 【基础风格】 | 每段先写光源、方向、明暗反差和光质，以及真实明暗与肤眼发细节；确为夕阳时按 L8 写侧逆光，并写柔和环境反射及克制曝光。再写材质、成立的 L 分支和景深倾向。肤色与瞳色沿角色锁定，不因本包统一改色。反打继续同一场景光源，不只列“电影感、写实、高级质感”。 |
| 【运镜与时间轴】 | （2.5 段写在五行之后）逐 CUT 写 IN、画内关系、演员动作顺序、camera 主路径、固定/肩扛方式及晃动强度、焦点/光区变化、BEAT、声音点和 OUT。移焦须写起始焦面、触发动作、转移过程和最终落焦对象。调用 C/M/P 机制时展开成具体人物位置、方向、连接点和停稳状态，不能只写机制编号。 |
| 【声音设计】 | 指定实际对白、声源位置、近远、优先级、进入与退出点、跨镜延续和必要留白。采用 S 规则时补足当前场景的条件；没有输入依据的特殊声线和配器不写成固定事实。 |
| 【画面限制】 | 保留入口的固定技术卫生模板。再用正向句写本段确需守住的关系：接触发生前材料保持完整，抓握手和支撑脚连续，灯位固定在场景中，镜中人与实体位置对应，特效从触点外侧展开、不盖住触点。成像质感已在【基础风格】正向写明，这里不重复列否定清单；确需否定时用简短英文短语，例如 `no beauty filter`、`no ring-light catchlight`。 |

### 2. 单 CUT 的执行句法

按以下顺序组织，不必每次增加小标题，但信息要完整：

`IN：机位高度与角度、景别/视角类别、主体占位、前中后景锚点、焦点、受光侧。`

`演员：外部刺激 → 眼手身步的先后 → 持物/接触/支撑变化 → 对手何时接收。`

`camera：固定或明确主路径；采用肩扛视感时写轻微/中度/剧烈晃动、画幅起伏的成因与衰减点；写近物与远景如何相对移动、遮挡如何打开或闭合、主体占幅如何改变。`

`BEAT：同镜里的主要信息转折、光区跨越或短暂停顿；移焦写起始清晰对象→动作触发→前后景清晰度连续交换→落焦并保持。`

`声音点：本镜确需的语声、触点声或声桥，与可见动作对应。`

`OUT：停稳构图、焦点归属、人物朝向/持物/支撑、新状态，以及下一 CUT 继承的方向。`

固定镜头也必须写演员路径，不能用“镜头静止”代替动作；肩扛停留可以保留细微画幅起伏，但须明确它与绝对固定机位不同。有运动的镜头必须写结束条件，不能用“缓慢运镜”覆盖整段。若近物与远景没有合理视差，只需要主体变大时，可以选择演员接近或明确的视野收窄方案，不能同时声称是推轨、变焦和人物冲近。

### 3. 光影与运镜联动

人物跨过窗光、门影、招牌或顶灯下方时，写清先受光的部位、亮区面积如何改变，以及何时回到阴影。摄影机绕到背光侧后，允许脸变暗，靠轮廓、少量反射与正确焦点保持信息；禁止为维持同一美颜亮度让光源跟着相机漂移。

夕阳侧逆光人物镜（L8）保持自然暖环境、柔和面部反射和真实暗面；人物转头时，鼻影、脸侧明暗、角膜倒影与发丝金边按角度连续变化。肩扛晃动只改变观看位置，不让光源反复换边、肤色忽冷忽暖或亮度随步伐抽动；轻微画幅运动中的毛孔、眼周与碎发不靠逐帧锐化闪烁来表现。

移焦只改变清晰面，不能顺便让背景换景、灯位变化或人物瞬移。近景遮挡打开时，后方主体应早已在对应位置；巨物接近时，尺度通过遮挡、天空留白和环境参照共同成立。快速动作后必须有一处稳定阅读点，使观众看清触点、表情或结果。

### 4. 材质、特效与表演连续性

软布先拉伸或卷折，硬壳先裂后断，碎片从受力处向外离开；纸片、陶片、尘土和火星各有不同大小、厚度、速度与衰减。前景碎片更大、更快、更可能失焦，远处碎片更小、移动更慢。效果光只影响能被照到的邻近面，遮挡后的区域仍暗。

跨镜保留汗、灰、散发、破损、道具残余摆动及失衡后的身体状态。没有重新整理动作，就不恢复完美服装和发型；没拍到松手，就继续保持抓握；没给脚步换位，就不改变支撑脚。反应可克制或夸张，但每个角色的身体节奏须有区别。

### 5. 密度与取舍

每镜优先保证一个主要信息动作和一个明确接收结果。若同时安排多次转身、两次移焦、跨房间移动和长对白，应拆为必要 CUT 或减少动作，不靠压缩到不可读速度解决。极近局部之后适时回到关系景，持续宽景中则用走位、遮挡和光区变化组织注意力。

优先保留三件事：光从哪里来、行动如何在空间中发生、镜头最终把信息交给谁。镜头没有新的关系要揭示时保持稳定；表演没有外部刺激时允许等待；动作结束后让结果留在画面中。所有选择服务当前剧本与规定 OUT，完成之后即收束。
