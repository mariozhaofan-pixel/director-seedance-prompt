# 05H Child and Pet Performance

priority: optional
scope: 画面里有承担剧情的幼童、婴儿、宠物或拟人灵宠，需要设计他们的动作、表情、依恋照顾或同框配合时加载。负责能力边界、可选表演机制、多角色关系和镜头可读性。台词、事件、成败和结局不由本模块改动；普通表演仍按 [05](05_ACTION_PERFORMANCE_BODY_MECHANICS.md)，打斗按 [05C](05C_COMBAT_CHOREOGRAPHY.md)。

只是提到一个孩子或宠物、背景里姿态已经清楚，或已验收稿的机械编译，不加载本模块。

## 一、取向：认真做事，不靠出糗

- 萌感来自小身体认真做一件事、主动照顾别人、对刺激有真实的反应，不靠摔倒、哭闹、被捉弄或装傻。
- 原剧情已经写了哭、怕、失败、睡着或被保护，照实设计这个状态，不为“可爱”擦掉；默认只是不主动添加这些。
- 孩子是行动者：能看、能判断、能选择、能回应。但聪明只来自当前能知道的信息，不让他凭空知道秘密、获得新能力或反败为胜。
- 一本正经、小得意、心疼、坚定这类状态，写成眉眼、嘴角、手和姿势的具体变化，每次只选一个主变化，不把几种表情轮流演一遍。

## 二、能力边界

### 幼童与婴儿

- 按已知年龄和已经会做的动作写。年龄没给且只是看一眼、动动手指时可以直接写；涉及独自走、跑跳、精细操作或长段模仿时，没有依据就不新增。
- 婴儿只从被抱、追视、抓握、发声这类原文已有的动作细化，不因为写了“一岁左右”就同时会翻身、坐、爬、站。
- 原台词一字不改，不为显得奶而改成叠词或错音。
- 真人拍摄不靠故意摔倒、拉拽、极限伸展来制造反应；剧情本身有险情时保留结果，执行方式写成可合成或安全替代。

### 现实动物

- 按物种和体型的真实行为写。猫、狗、小型哺乳动物、鸟的尾巴、爪、嘴、叫声不互相照搬。
- 一个姿势不直接等于一种情绪：露肚、摇尾、瞳孔变化要结合对象、距离和全身姿态判断，判断不了就只写看得见的动作。
- 不靠惊吓、惩罚、强迫直立、掰动身体取得反应；不为增加互动新加喂食、强抱或拉扯。

### 拟人动物与灵宠

- 会说话不等于能随意变形，写实 CG 也不等于卡通物理。能力由已有设定决定，不临时新增飞行、抓握、变身或施法。
- 保留物种特征：尾、翅、鳞、小爪参与动作时写清受力，不写成换了皮的人类小孩。
- 只有画风明确允许时才写压扁、拉长和回弹，并写清受力部位、方向和恢复状态。

## 三、可选表演机制

每次取一个主机制，必要时加一个辅助；原动作已经清楚时，一处视线或短暂停顿就够。

| 机制 | 可见过程 | 注意 |
| --- | --- | --- |
| 认真完成 | 看准目标 → 郑重准备 → 身体调整 → 原有结果 → 短暂余韵 | 原文成功就成功，不改成失败 |
| 短暂辨认 | 外部信号 → 手上动作停一下或视线转移 → 回应 | 机灵的孩子看清就动，不反复发愣 |
| 柔软放松 | 坐下、靠住或趴下 → 衣服起褶、毛被压伏、肩背放松 → 保持 | 写实角色不写成橡皮 |
| 准备与结果的反差 | 准备得很郑重，结果只需轻轻一下；或成功后手还僵着 | 不擅自加扑空 |
| 情绪翻面 | 上一状态的身体证据 → 原有触发 → 新表情先出现 → 留一点残余 | 哭转笑保留湿睫毛、没平的呼吸 |
| 小大人 | 照着大人的姿势背手、扶正东西、绷住脸，身体仍是孩子 | 模仿可以成功，不一定出糗 |
| 依恋照顾 | 看向对象 → 靠近、示意或让出位置 → 对方按原情节回应 | 不强加亲吻、喂食、紧抱 |
| 专注 | 一个关键姿态加一处小动作（手指、嘴唇、尾尖） | 没人打断就不补打断 |
| 犯困硬撑 | 眼皮垂下 → 被声音拉回一点 → 原文给的结果 | 原文没睡着就不写睡着 |

动作要和本场任务相连：手正拿着东西时不能同时叉腰；动作结束的姿势要能接回剧情。节奏上，起收快慢服务情绪，不把每个动作都写慢。

## 四、多角色同框

- 先定主行动者、搭档、反应者和背景。背景角色给一个整体姿态，不逐个排高潮。
- 关系选一种为主：同步镜像、依次接力、一主众衬、一急一稳的反差、挤在一起、各忙各的再被同一信号收拢。剧情自然变化时才换。
- 交接要落在看得见的动作上：A 递出、停住或完成，B 因此接上；或者两边围绕同一个已有物件用力。
- “一个时刻一个焦点”指观众注意力，不是同一刻只能一个角色动。一起抬东西、对视、镜像动作本身就是一个焦点，不要拆成轮流。
- 真人和风格化灵宠同场时分别控制身体尺度，不把真人也写成卡通形变。

## 五、镜头可读性

先定这一镜要读懂什么，再选景别：

| 要读懂的 | 覆盖方式 |
| --- | --- |
| 跑、扑、抱、踮脚等全身受力 | 能看到支撑脚和全身动作，不能只拍脸 |
| 递物、操作、比划 | 手、对象和相互位置在同一画面或连续画面里读得清 |
| 奶凶、郑重、忍笑、辨认 | 景别足以读清主要的眉眼嘴变化，不强制每次特写 |
| 身高差、保护、依恋 | 双方位置和回应都能看懂，可以同框，也可以有因果地切换 |

萌宝萌宠只在剧情需要时成为焦点；主事件属于别人时，不把孩子硬塞进每一镜。

## 六、结束前核对

- 动作成败、台词、角色数量和物件归属和原文一致。
- 能力、夸张程度符合年龄、物种和画风。
- 删掉一个装饰动作会更清楚，就删掉。
- 新加的身体细节不自动带来新的叫声、呼吸声或脚步声；声音仍按 [06](06_TIMELINE_EDITING_SOUND.md)。
