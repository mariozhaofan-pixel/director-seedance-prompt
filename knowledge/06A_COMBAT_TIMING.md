# 06A Combat Timing

priority: high
scope: 实际交锋的唯一时码细则、战斗时间轴编译、动作耗时与慢动作原子窗

## 使用边界

仅当当前独立段包含实际交锋时加载；普通对白、备战/对峙、未交锋追逐、救援、事故和无关微修改沿用 [06_TIMELINE_EDITING_SOUND.md](06_TIMELINE_EDITING_SOUND.md)。时长上限、时间粒度和用户覆盖沿用入口已解析的 `Resolved Policy`，本文件不重新选择版本或扩大修改范围。

战斗动作与摄影内容由 [05C_COMBAT_CHOREOGRAPHY.md](05C_COMBAT_CHOREOGRAPHY.md) 负责，特殊动作物理由 [05D_ACTION_SCENE_PHYSICS.md](05D_ACTION_SCENE_PHYSICS.md) 按需提供。05与06其他位置只作入口提示；战斗时序细则统一维护在本文件。

## 打戏时码覆盖

“实际打斗交锋”指画面中存在攻击与防守/闪避、兵器或枪弹接触、车辆/机甲/怪兽对抗性碰撞、能量攻击与反制。只有对峙、备战、追逐但未交锋、事故、救援或动作表演时不自动触发。

1. 先选择一个准确总时长 `T <= Tmax`。打戏段标题写 `建议T秒`，不写时长范围；用户指定时长时服从用户，但不能超过所选版本上限。 剧情足够时优先把兼容动作链打包到接近 `Tmax`；动作链较短时选择更短的准确时长，不拉长单个动作填满。
2. **Seedance 2.5**：每个可见CUT写成 `CUT N（起点-终点秒）`。第一镜从0开始，相邻首尾完全相接，区间单调、无重叠/倒序/留白，最终CUT精确结束在T。`integer-preferred`推荐整秒但允许小数并只给非致命提醒；`decimal-allowed`接受项目需要的小数边界；`integer-required`才把小数判错。用户或项目明确隐藏时码时，每个可见设置写无时码 `CUT N`，一镜到底或不间断 action master 内部用无时码 `BEAT A/B/C`；用 `开段、随后、接触前最后半拍、区间中段、CUT末端` 表达相位，不写 `0-3秒`、`第3秒`、`3秒后`、小数秒或 `Frame`；亚秒排演留在静默账本。
3. CUT时序是发生位置，不是孤立动作持续时间。禁止只写游离的“挥拳1秒/蓄力2秒”；决定性接触、开枪、爆点或反击需要更强约束时，在所属CUT内补与已解析粒度一致的绝对点、相对相位，或 `Frame T`。帧事件使用项目指定fps，未指定时按24fps解释，必须位于0-T范围内；不要为伪精确堆无意义小数位。
4. 时码不改变 CUT 语法：每个 CUT 仍只承担一个明确变化，可包含共同服务它的预载、路径、反应、环境与声音变化。不要因为获得时间格而增加无关连招。
5. 一镜到底打戏写 `CUT 1（0-T秒）`，内部BEAT按同一已解析粒度连续覆盖0-T。
6. 若段内先对白后交锋，整个独立段使用同一 `timestamp_policy`：全部CUT连续覆盖，台词占据对应区间；不要混用整秒强制与小数允许两套判定。
7. 七拍因果不按七拍机械拆成七镜，也不套3-6个CUT上限，可按明确变化扩展连续交换链；给预载、路径、接触、双方反作用、恢复与状态更新留下可读时间。
8. 台词、呼吸、枪声、金属声、撞击声和VFX触发跟随同一时序；声音桥可以跨CUT，不制造顺序倒置、区间重叠或未分配空档。关键接触的路径、接触点和第一拍双方反作用在所属窗口内依次可读。

## 动作耗时账本

逐 CUT 先做动作耗时账本，再写时码：

```text
T_combat_min = 预载 + 运动路径 + 接触可读 + 双方受力/反作用
             + 恢复 + 必要重定位 + camera travel/settle
             + 必须串行的VFX形成/传播/接触/消散读取
```

同时发生的攻击者反震与防守者受力取最长并行轨，不重复相加；必须先后发生的预载、路径、接触和恢复按串行相加。若总账超过 CUT 区间，先减少动作层、缩短装饰性运镜、迁移恢复或拆分交换链，不能只压缩时间戳或删除接触后的反作用。

短接触窗口：`<=2秒`的接触CUT只承载“已预载的单次攻击 -> 一次接触/格挡 -> 立即双方反作用”；超过一步的位移、取道具、完整蓄力、第二次接触或稳定settle必须前置、并行且有可见证据，或扩展窗口。

## 【运镜与时间轴】战斗语法

无论多 CUT 或一镜到底，先完成动作链和耗时账本，再用以下顺序编译可见文本；`CUT功能`、焦段和机位从剧情信息任务中选择，不按示例固定排序：

```text
CUT N（已解析粒度的起点-终点秒），地点/子空间 + camera起始世界位置/look direction
+ shot size/焦段倾向 + frustum roster/景深层
+ IN state与本CUT唯一明确变化
+ 主行动者的预载/路径/接触或落空
+ 响应者的防守/代价/反作用 + 双方恢复与战斗状态更新
+ camera路径/速度曲线/主体保持/接触前稳定/接触后反馈
+ 同步声音与VFX因果 + OUT state/下一CUT接力载体
```

运镜短语必须能在世界空间中画出：

```text
rig或运动方式 + 起始位置/高度/朝向 + 路径与方向 + 速度曲线
+ 主要主体及保持关系 + 景别/焦点结果 + 前中后景视差或真实遮挡
+ 制动/稳定/终点位置与构图 + 本镜叙事结果
```

- 建立空间、读取脚步/武器距离、跟踪进入、确认接触、读取后果、恢复方向、揭示尺度是可选摄影功能库，不是固定镜序。每个普通 CUT 只保一个主 camera move；短促冲击反馈附属于该 move，不算第二套无关运镜。
- 多CUT中允许某个较长CUT作为continuous action master；该CUT内可用 `BEAT A/B/C` 管理相位，但CUT前后仍是真实切镜。整段one continuous shot只能有一个 `CUT 1`：写 `CUT 1（0-T秒）` 与同一已解析粒度的连续BEAT；所有BEAT都在同一条连续camera path上。
- 相邻 CUT 继承 `双方世界锚点/距离/高度/支撑/握持 + 动作相位/速度 + screen direction + 接触/受力方向 + 焦点/声音/VFX残余`，并逐项证明OUT到下一IN的变化路径；camera同侧且人物未可见交叉时，screen-left/right相对顺序不得翻转。长镜头相邻 BEAT 额外继承 `camera终点/航向/高度 + 当前速度相位 + 焦段/主体画面尺度 + focus + 动作相位 + VFX残余`；任何转向、升降或变焦先有减速、绕行锚点或剧情触发。
- 先列本CUT必须看见的动作证据再选景别。需要同时看清双方支撑脚、手部握点、长兵器两端和接触点时使用MLS/WS或确实覆盖全身的等价构图；CU/MCU不能宣称裁切外脚步或全长兵器仍可见，MS也不能超出真实画框。紧景别只承担接触/表情/局部材料证据，完整支点与距离交给相邻宽景接力。
- 强打击感的摄影反馈链、各攻击向量的写法和motion blur范围只在05C“打击感摄影反馈编译器”维护。时间轴上只保证：停稳落在接触之前，唯一一次同向jolt/shake落在接触绝对点或接触窄窗口，轻微overshoot的回拉/制动、阻尼回稳和后果OUT都在当前CUT内完成；禁止无方向的全程震屏。
- 决定性慢动作是不可切断的原子窗：`实时进入 -> 接触前窄窗口降至35%-50% -> 实体/能量边界接触 -> 接触后VFX -> 第一拍双方反作用 -> 恢复实时 -> 恢复/OUT`。从降速起点到第一拍反作用必须留在同一CUT或同一个不间断BEAT内，期间禁止hard cut、隐藏切、另起slow-motion insert、动作悬停或重复预载；换角度只能发生在降速前，或第一拍反作用已经可读之后。除非用户明确要求多次，整段默认一次；慢动作期间重力、碎屑、毛发、衣料、液体和局部光继续按因果运动。
- VFX各阶段（链见05C“能量招式规则”）分配到真实 beat；不能让蓄势、接触和爆发结果同帧无因果堆叠。主VFX、接触声、动态局部光和环境响应在同一绝对时点/窄窗口触发，并以一致趋势衰减。
- 05C“打斗视觉覆盖与环境回收条件门”触发时，相邻主要CUT的覆盖差异、场景道具累计状态、重点命中确认和非对称尺度摄影都按05C执行；本文件只要求这些内容服务本CUT明确变化，并在时码内为camera travel/settle留出时间，不变成额外同级事件。

## 动作戏 CUT 编译顺序

动作戏、武打、枪战、载具、空战、机甲、怪兽或团队战的每个关键交换，先在静默层执行05C的七拍动作因果（载具、空战、机甲、怪兽和团队的特殊物理按05D），写入 `【运镜与时间轴】` 时按当前 CUT 的明确变化取必要阶段，不机械拆成七镜：

- 先确定准确总时长并执行本文件的打戏时码覆盖，把关键交换放入确定CUT/相位或区间。
- 起始先交代本 CUT 的摄影机任务和攻击/逃逸路线，复杂动作优先 MS/WS 保留双方支点、距离和接触点。
- 防守、闪避和反击按05C七拍下“主动防御必须改变力线”一段写；接触窗口内依次读清攻击路径、接触点与受力方向、第一拍双方反作用，随后才是材质/环境/声音确认和新的空间状态。
- 时间戳负责安排事件出现区间，不会自动结束已经读清的接触或对峙；关键证明点后必须在同一 CUT 写明退出条件并立即进入恢复、分离、失衡、抢入或继续运动。
- 轻击、中击、重击、终结级冲击按 `05C_COMBAT_CHOREOGRAPHY.md` 的“动作 CUT 摄影任务与冲击预算”选择层级；这些是内部反馈预算，不是角色等级或剧情价值。不让每次接触都同时使用震屏、慢动作、白闪和粒子。
- 中间 CUT 用动作相位、武器路线、焦点、飞散材质或声音接力；最终 CUT 只写本段可见 OUT，不把“下一开放动作”的未来名称写进提示词。
