# 05A Combat Exchange Variants

priority: medium
scope: 按需检索的打斗交换编排资料。补充 `05C_COMBAT_CHOREOGRAPHY.md` 的七拍动作因果、三主路由与武器拓扑；时码统一见 `06A_COMBAT_TIMING.md`，不改变宿主输出结构，不新增输出栏目或 QC。

## 使用边界

交换变体描述的是一段可拍摄的关系变化，不是固定招式表。按当前距离、支撑、握点和目标 OUT 读取相关条目；不要求每次换招，也不依次执行整份目录。每条沿 `IN -> 路线/接触 -> 对方处理 -> OUT` 组织；主接触所需预载可以来自上一动作，不重复蓄势。下列摄影写法提供证据覆盖选项，不强制切镜；一镜到底沿既有PATH交接画框和焦点，明确的固定机位继续保留。

所有条目是影视编排机制，不是经核验的流派招式或实操教学。破防、摔落和控制沿用05C状态规则；剧情要求继续才编排恢复/脱离，保持控制或倒地也可以是有效OUT，不擅自恢复已有伤势或添补攻击。使用现有角色、道具和场地；可选支点与出口只有已存在时才使用，不用示例创造关键道具或新出口。

先按动作意图找可见变化，再按距离、身体状态和空间筛选一两条：逼退/脱离选1，绕侧选2，诱追改线选3，拨开换位选4，护架恢复选5，短连触制造窗口选6，摔后接续选7，解除接触选8，长兵器缩距选9，失衡借力选10，封路持续压迫选11，多人配合选12，能力反制选13，环境改线选14，软兵器轨迹选15。意图只解释当前行为目的，不能替代动作本身。

**画面句例是局部CUT/BEAT素材，不是完整提示词或必选镜序。**按当前角色、身体左右、真实机位和场地重写；例中的门、桌、器械与能力必须在项目中已建立。时间由06按当前容量分配，不照搬统一秒数；一镜到底也要保留06规定的外层`CUT 1`，内部交换写BEAT，不能用一串BEAT取代CUT；2.5精确时码时外层CUT覆盖总时长。一条可写多次相互影响的动作，但共同推动一个明确的关系或状态变化；对方的判断、防守、失衡和恢复穿插在交换中，不等攻方整套结束才回应。只写镜头能证明的内容，条目名称和检索过程留在静默层。

## 交换变体

### 1. 直线逼退，侧向脱离

- **适用条件**：对手沿中线连续施压，场地一侧存在可见的横向空隙，双方仍保持站立交换。
- **IN / 支撑或握点**：被压方后脚承重、前脚可退；前臂或掌根与来力短接，另一手保持护架，不抓死对方。
- **路线与对方处理**：攻方直线推进；守方短退一到两步，最后一次接触把力线向外带，前脚斜切出中线。对方若追随，需转髋收步或减速找回轴线。
- **OUT / 后续可能**：双方错开半步，守方获得侧后角，可重新对峙、反向逼近或沿原出口脱离。
- **摄影必须可见证据**：中远景/全景同时容纳脚跟、接触点和最后的横移；换机位重算screen方向，在落脚相位接力，不能用隐藏跳位代替脱离。

- **画面句例**：侧面全身双人镜头，甲从画左向右连续压近；乙接住来臂短退，后脚落稳后沿斜线拨开，前脚踏进靠近摄影机的空隙，身体随落脚离开甲的正面。摄影机横移接住两人，甲收住前冲的步幅，转肩重新朝向乙；乙已从画右退路进入前景侧角，双方距离拉开。

### 2. 弧线绕位

- **适用条件**：空间有足够半径，双方距离尚未贴死，需要让轴线旋转而不是单纯后退。
- **IN / 支撑或握点**：主动方前脚和肩线指向目标；绕位方以外侧前臂、上臂或武器平面保持轻接，内侧脚先找空位。
- **路线与对方处理**：绕位方沿对手肩线外侧走半弧，身体和视线一起转，不做无目的旋身；对方以小步转髋追踪，若切断弧线，绕位方缩短弧长并退出。
- **OUT / 后续可能**：双方朝向改变但距离基本保留，可接侧向试探、短暂控制或重新拉开；若空间被封，OUT 改为停步护架。
- **摄影必须可见证据**：三分之四中远景保留地标、前后景和双方脚路，证明轴线由人物实际移动转过；camera可沿可达弧线跟随，不能只靠绕拍冒充人物绕位。

- **画面句例**：三分之四全身镜头，乙在画左近处，甲在画右稍远处。乙前臂轻贴甲的来臂，脚步沿甲外侧肩线绕向后景；甲连续小步转身追住乙。摄影机只横移让出身体遮挡，保留同一根后景柱作为参照；乙绕到柱前时收步，两人的肩线已实际转过，而非被绕拍制造换边。

### 3. 诱发追击后改线

- **适用条件**：一方主动权较弱但仍有稳定支撑，可用短暂退让诱使对手过度前压。
- **IN / 支撑或握点**：守方后脚踩实、肩线略露出退路；可用手腕或外侧前臂作短暂引导，保持可释放的接触。
- **路线与对方处理**：守方先退半步给出追击路径，攻方跨入后，守方绕支点改向，让其通过原站位；攻方以空手护身、收步或转身减速，避免直接撞入环境。
- **OUT / 后续可能**：攻守关系交换，守方取得侧面角度；可继续短接，也可借对手刹停的窗口脱离，不强制追加命中。
- **摄影必须可见证据**：先交代两人和退路，再连续展示诱导距离、交叉点、改线和对方刹停；禁止瞬间换边或无因果的反向飞移。

- **画面句例**：侧前方全景，乙先沿画面右方退半步，目光仍扣住甲的肩部；甲跨入这段空位时，乙以已落稳的脚转向后景，肩膀擦着甲的来臂外侧让开。甲的手臂从乙原站位掠过，前脚重落、后脚追上制动；乙趁他尚在转身，从其侧面脱出。摄影机连续保留原站位与两条分开的脚路。

### 4. 拨挡后借窗口换位

- **适用条件**：来力路线单一，守方只需改变接触面和角度即可，不需要以力量硬压回去。
- **IN / 支撑或握点**：前手或前臂接触来臂、衣袖或长兵器杆身；后脚预载，另一手守住中线或保持器械尾端。
- **路线与对方处理**：守方沿斜线拨开，接触面滑向外侧，来力擦过身体；守方借同一步进入新角度。攻方收回手臂并转身重建距离，或用另一侧封住出口。
- **OUT / 后续可能**：守方取得斜侧位，可接短暂试探、控制接触或安全分离；若对方及时转髋，双方回到中线而不重复同一接触。
- **摄影必须可见证据**：近景只证明手/器械接触和力线变化，中远景/全景接住脚步换位；以连续景别交接或动作相位切换，不能在近景里声称看见全身路线。

- **画面句例**：斜侧中远景，甲伸臂压向画右的乙，乙以前臂斜向外拨，来臂从乙胸前滑向画面后方；乙随这次接触斜跨一步，肩线来到甲侧面。甲立即屈肘回收并转髋追住乙，乙的下一步因此停在半侧位。摄影机侧移保留接触手臂和双方落脚，结束时两人相向，原来的直线进攻已变为斜向短距交换。

### 5. 护架被带开后的局部恢复

- **适用条件**：防守线被一次接触带偏但尚未失去平衡，剧情需要压力继续而不是立即终结。
- **IN / 支撑或握点**：双方有基本护架；一侧前臂或武器平面被拉向外，守方至少保留一只支撑脚和一条可回收的手臂。
- **路线与对方处理**：开口只出现在一侧，守方用肩髋遮住中线，碎步调整并让空出的手回到局部护架；攻方可前进半步，但必须处理回收中的手臂，不能把短暂窗口写成无阻碍命中。
- **OUT / 后续可能**：局部护架恢复，距离变近或变斜；下一拍可选撤步、拨挡或短接，不要求瞬间回到完整对称姿势。
- **摄影必须可见证据**：中近景读护架分开、躯干遮线和手臂回收；若脚步修正决定恢复，使用中远景/全景。接触与回收交替推进，状态读清即续接，不额外凑停顿。

- **画面句例**：腰部以上双人镜头，甲把乙靠近摄影机的一侧前臂带向外，乙立刻收下巴、转肩遮住胸前空隙，另一手从胸前回到护架。甲追入半步时碰上这条回收中的前臂，肩膀随碰触停住；乙呼气、松开咬紧的下颌，外侧手臂随后收回。焦点留在护架开口与回收路径，局部防线先恢复，双方仍贴近。

### 6. 短连触与主接触

- **适用条件**：近距离需要密度，但观众仍要辨认谁在改变路线，适合一小段连续攻防。
- **IN / 支撑或握点**：双方支撑稳定，手腕、前臂或肩线保持短接；每次短触都改变一条手臂、一步距离或一个角度。
- **路线与对方处理**：用少量轻短触逐次改变护架或距离，守方相应侧身、拍开或后撤；由已形成的窗口接一次主接触，把对方推离或带转，数量服从容量而非固定配额。
- **OUT / 后续可能**：主接触形成清楚的距离或角度差，可接重新逼近、换位或分离；若主接触落空，双方回到可读护架而非重演前段。
- **摄影必须可见证据**：需要近景时只放大手部和肩线短触，主接触与全身反应由中远景/全景承接，也可始终宽景连续覆盖；用运动方向或声音接力，不用抽象“高速连击”填时长。

- **画面句例**：侧面全身跟拍，甲一次短触把乙的前臂引向外侧，乙立刻拍回；甲借双方手臂回摆贴近，乙转肩缩小正面。甲的主接触落在乙肩部，乙上身随受力方向带转，后脚斜跨接住重心。摄影机跟到新落点即减速，衣料牵拉声接一声鞋底擦地，乙已经斜站在甲侧前方，而非原地吃完一串攻击。

### 7. 被摔后起身或脱离

- **适用条件**：受控摔投、失衡或滑倒已经发生，剧情允许解除控制且人物仍具备继续行动的身体条件。
- **IN / 支撑或握点**：沿上一拍已有落点、接触和朝向进入；若仍被抓握先交代限制解除，再按已建立支撑选侧滚、屈膝或空手撑起，不强制在翻转点松手。
- **路线与对方处理**：被摔方沿落地方向滚开，若压力跟进，用双脚或前臂建立距离并侧向起身；追击方看到空间被打开后改为封出口或重新站稳，不扑入盲区。
- **OUT / 后续可能**：被摔方可跪姿转站立、绕过障碍脱离或重新面对；控制方保留站立支点，下一拍可追随、停住或换路线。
- **摄影必须可见证据**：中远景/全景覆盖尚未完成的接地、滚动或起身及双方距离；不重演上一拍已完成的摔落，不以表情代替恢复证据。

- **画面句例**：低机位全景从乙已经侧身落地开始，甲在后景向前跟进；乙沿原落地方向滚出半个身位，屈膝收脚，空手撑地把上身抬起。甲看见乙朝出口一侧移动，脚步转向封线；乙借这一转向先退成半跪，再站起面对甲。摄影机向侧后方退让，持续看见撑手、落脚和缩短后的出口距离。

### 8. 控制接触转分离

- **适用条件**：短暂抓握或身体控制只用于改变关系、方向或距离，不承担终结功能。
- **IN / 支撑或握点**：以肩线、上臂、前臂或衣物作为可释放接触；控制方双脚可移动，被控方至少有一只脚能转向或后撤。
- **路线与对方处理**：控制方随对方转身带动身体，不把双方锁成静止雕像；被控方用转髋、支撑或轻推改变方向，接触在新角度明确松开。
- **OUT / 后续可能**：双方分开一个可行动距离，可接侧向逃离、重新护架或再次试探；若接触无法维持，直接以错身分离收束。
- **摄影必须可见证据**：中远景/全景显示双脚、接触点、转向和释放时刻；服装拉力、呼吸和脚步可作辅助，但不能遮住支撑变化。

- **画面句例**：斜侧全身双人镜头，甲握住乙上臂随他向画右转步，衣袖在两人之间拉紧；乙以仍着地的脚转髋，空手抵住甲肩侧，身体沿接触边缘转出。甲的抓握随新角度松开，袖口回弹；乙继续侧退，甲收回手臂重新面对他。摄影机轻移保留两脚与松手，分离由接触解除造成，而不是切镜后突然相隔数米。

### 9. 长兵器外圈转内圈，缩距换握

- **适用条件**：长兵器外圈占距遇到墙、柱或贴身突入，需要保持器械拓扑并安全缩短动作半径。
- **IN / 支撑或握点**：持有者保留前后双握和功能端方向，后手靠近尾部；对手在外圈边缘以手臂、短器械或身体侧面观察距离。
- **路线与对方处理**：外圈原本可用时，以既有弧线维持距离；对手靠近或即将进入窄处时先收肘，一只手稳持、另一只手沿杆身换握后再接力转杆。对手侧步或拨开杆身回应；若开段已在窄处，直接从可用短握IN开始，不先挥满再穿墙收杆。
- **OUT / 后续可能**：形成短握近距的控制接触，可转为分离或重新展开外圈；若走廊更窄，OUT 是贴墙停住并保留退路，而非强行挥满。
- **摄影必须可见证据**：三分之四全身明确功能端、两处握点、外圈弧线、缩距和墙面关系；换握必须连续可见，不能靠切镜隐藏。

- **画面句例**：三分之四全景，甲持长棍沿走廊退向画右，乙从画左逼近，后景墙面限制棍端摆幅。甲先收肘让棍身靠近躯干，一手稳住杆身，另一手沿杆滑近后重新握实；乙侧步拨开棍身时，甲用已缩短的握距接住偏转。摄影机沿走廊侧退，完整保留两只手与棍端，结束在窄幅短握，不让长棍穿过墙面。

### 10. 失去支点，借环境重新站稳

- **适用条件**：脚下打滑、后退受阻或接触反作用令一方暂时失去支点，附近有真实固定物可承重。
- **IN / 支撑或握点**：一只脚离开稳定面，空手寻找墙、栏杆、桌沿或门框；另一只脚和髋部仍控制下坠方向，不能把环境当凭空出现的支点。
- **路线与对方处理**：身体降低并沿失衡方向移动，手掌或前臂接触固定物后转移负荷，再推回到新站位；对方用一步封线或让出空间回应，不在恢复途中叠加不可见的强碰撞。
- **OUT / 后续可能**：回到站立护架、借固定物转身离开，或躲到实体遮挡后重建距离；环境只在确有接触和可见反馈时更新。
- **摄影必须可见证据**：全身镜头看见失足、环境接触、负荷转移、脚底重建和最终朝向；保留一个稳定地标，避免摇晃掩盖支点变化。

- **画面句例**：侧面全景，乙向画右退时鞋底滑开，髋部下沉，空手先抵住已在画右的固定栏杆。栏杆承住身体后，乙才把另一只脚踏回稳定地面，肩膀随呼气抬起。甲看见乙恢复，沿栏杆外侧跨步封住去路；摄影机侧移保留栏杆端点、掌根和双脚，乙最终扶栏站稳，出口已被甲占住。

### 11. 封路与持续压迫

- **适用条件**：意图是限制去向、迫使改线，而不是增加命中次数；出口或通道位置已建立。
- **IN / 支撑或握点**：交代双方与出口的相对距离，封路方仍有横移空间。
- **路线与对方处理**：脱离方先试探一条路线；封路方读到肩髋转向后斜跨占线，前压迫使对方收步；对方立即换向或护住空间，压力来自可选路线逐次减少。
- **OUT / 后续可能**：一条去向被封、双方形成新角度或脱离方被迫回到原区域；不擅自封死所有出口。
- **摄影必须可见证据**：画框保留双方与受影响出口，换向和拦截必须发生在各自可达距离内。
- **画面句例**：门洞在画右后景，乙在中景转肩准备冲向门，甲从门左侧斜跨一步占住路线。乙前脚刚起便收回，改沿画左绕行；甲转髋横移追住他的肩线。摄影机退成双人全景，让门洞始终留在两人身后；乙最终退回中央，第一次脱离被截断，但画左仍有可用空间。

### 12. 群体接力制造窗口

- **适用条件**：现有多人各有功能，一人的行动改变对手视线、护架或路径，为另一人创造机会。
- **IN / 支撑或握点**：先明确谁正接触、谁在可达侧翼、谁受遮挡或绕路；人数不等于同时接触人数。
- **路线与对方处理**：第一人试探引出回应，第二人趁真实窗口进入；对手也要转移防守、改向或利用遮挡。未接触者继续绕位、保护同伴或封线，不排队静候，也不同时无条件命中。
- **OUT / 后续可能**：注意力、空间或主动权发生一次清楚转移；人数、伤势和已有位置保持连续。
- **摄影必须可见证据**：宽景先交代接力关系；若收紧接触，下一画面接住仍在运动的其他人，不能让后景人物消失。
- **画面句例**：全景中甲在画左近处试探，乙守在中央，丙沿画右后景绕向侧翼。乙抬前臂拨开甲的来手，肩线刚转向甲，丙便从乙侧面逼近；乙看到丙进入余光，转步让甲短暂挡在两人之间。甲收手侧移重新找角度，丙因此收住前脚。摄影机侧移露出三人的错位，原本的夹击变成乙借人群关系打开的窄通道。

### 13. 利用能力条件反制

- **适用条件**：项目已建立能力的来源、传播介质、方向或阻断条件，反制可在画面中证明。
- **IN / 支撑或握点**：能力由谁、何处、何种状态触发；守方能观察什么，能改变哪一个既有条件。
- **路线与对方处理**：触发先出现可见征兆，守方据此改变路径、介质或遮挡；能力按已知规则被偏转、隔断或落空，攻方对新的线路作出回应。
- **OUT / 后续可能**：确定效果剩在哪里、谁得到移动窗口；不临时发明免疫、冷却、万能反弹或新能力。
- **摄影必须可见证据**：来源、传播线、干预点和结果在可读画面中相连，特效不盖掉脚路和身体反应。
- **画面句例**：已知电弧只沿连续水面传播，低位侧面全景中甲在画左触发电弧，亮线沿积水朝画右的乙逼近。乙看见水面亮起，立即踏上身旁已建立的干燥石阶；电弧沿下方积水掠过，映亮他的鞋底边缘，停在水迹尽头。甲目光抬向石阶并转身追踪，乙借这一落空窗口沿阶侧移，残光仍留在原水路上。

### 14. 环境改变下一条动作路线

- **适用条件**：当前场地有已建立、可移动或可破坏的物体，且改变物体状态能影响攻防；不同于10的固定物借力恢复。
- **IN / 支撑或握点**：交代物体原位置、可动性和作用接触，保留其原本重量与尺寸。
- **路线与对方处理**：身体或器械接触推动物体，物体沿受力路径移动并阻断/打开一条路线；对手看见变化后跨越、绕行、收步或转防。
- **OUT / 后续可能**：新的障碍、通道或遮挡持续存在，后续动作使用改变后的场地，不自动复原。
- **摄影必须可见证据**：同镜覆盖接触与物体启动，或在同一运动相位接力；保留物体落点与人物改线之间的关系。
- **画面句例**：侧面全景中乙退到画右的轻木桌旁，掌根推住桌沿，桌脚擦地斜移到甲的前进线上。甲原本向右追入的脚步立即缩短，转向桌子靠近摄影机的一端；乙趁他绕行沿桌后退开。摄影机横移保留桌沿两端，结束时桌子斜横在两人之间，刚才的直线路径已变成绕行路线。

### 15. 软兵器的展开、受阻与回收

- **适用条件**：项目已有绳、鞭、链等柔性器械；弧线、松紧与回收影响动作，不能按刚性长棍编排。
- **IN / 支撑或握点**：明确持握手、可辨识末端和当前垂落/拖行/绷紧状态；长度沿用素材或文本设定。
- **路线与对方处理**：持握端带动后，柔性段滞后展开，末端沿连续弧线经过；对方躲过或以已有障碍处理，接触后软段松弛或受拉，再恢复可控状态。
- **OUT / 后续可能**：末端落点、绕挂或回收进度可见；被障碍截住时先处理张力与解脱，不能下一拍瞬间重置到手边。
- **摄影必须可见证据**：宽景同时覆盖持握端、主要弧线和末端；衣物、尘土和声音辅助证明时序，不用残影代替真实器械路线。
- **画面句例**：侧面全景，甲在画左挥出已有长鞭，握柄先行，鞭梢延迟展开朝画右扫过。乙屈膝侧退到现有木柱后，鞭身碰柱弯折，末端下垂，甲的手臂随突然张力停住；甲退半步收回松下的鞭段，乙趁回收沿柱侧移。摄影机横移露出柱旁空间，鞭梢仍拖在地面，下一次展开尚需回收完成。

## 媒介差异（只在当前风格需要时使用）

同一动作意图保留路线、接触、回应和结果，只调整表现形式；媒介名称本身不是具体动作描述。

- **真人**：以脚底支撑、重心延迟、呼吸、衣料与道具惯性证明速度和重量，动作读清不等于放慢播放。
- **三维动画**：可用轮廓分离、短促预备姿态和接触后的越位回摆放大力度；仍需落脚承重、器械连续，幅度服从既定写实/夸张风格。
- **二维动画**：既定风格允许时，预备姿态短暂收紧，接触瞬间以冲击帧/运动拖影突出方向，随后迅速恢复稳定轮廓和反作用姿态。拖影是运动表现而非新增实体肢体；不把每个动作都写成定格、慢动作或连续闪白。

## 选择例（只选变体，不写完整提示词）

- **压迫但不受伤**：需要距离变化选1；已有护架被带开选5，再按出口条件接4。OUT 是侧角和新距离，不把三条串成必选连招。
- **摔后逃离**：按落地状态选7；只有途中确实失去支点且身旁已有可承重物时加10。恢复后接已建立出口，不追加固定追击。
- **狭窄走廊兵器**：`9 外圈转内圈缩距换握 -> 8 控制接触转分离`。墙面限制弧线，摄影优先保留双握、功能端、退路和释放时刻。
- **多人封住出口**：先用11确定哪条路线被限制，再用12让一个人的逼近触发另一人的进入窗口；不按人数平均分招。
- **能力很强但仍需博弈**：已有传播条件时选13；只有真实改变了场地才接14，不以更多粒子替代攻防关系。
