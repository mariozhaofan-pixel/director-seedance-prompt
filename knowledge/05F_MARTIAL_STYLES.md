# 05F Martial Styles

priority: on-demand
scope: 截拳道与咏春的写实近身打戏：站架、步法、手法、腿法、黐打截击、段落模板、人物与对手、摄影节奏、训练戏和声音

## 使用边界

用户点名截拳道、李小龙式打法、寸拳、截击、咏春、叶问式、黐手、木人桩，或要写实的中国功夫近身打法、这两派的训练戏时，由 [05C](05C_COMBAT_CHOREOGRAPHY.md) 的风格路由加载本文件。默认截拳道；用户说咏春时用第三节；两派可以同场对拆，各按各自的站架和节奏写。

本文件只决定动作内容。实际交锋的时码和 CUT/BEAT 句法按 [06A](06A_COMBAT_TIMING.md)，摄影任务、冲击反馈和覆盖按 05C，输出仍是主 Skill 的五栏。武侠飞檐走壁、能量招式和一般拳击不走本文件。

## 一、写法总则（两派通用）

1. **招式名不进正文。** 模型不认识“拍手”“拉手”“截踢”这类术语，看到只会生成泛泛的功夫片动作。正文只写身体几何：哪只手或脚、从哪里出发、走什么路线、打到哪里、对方怎样反应。术语只留在静默台账和用户要的动作拆解里。
2. **限制正面写。** 写了“不要高踢”“不蓄力”，模型反而会生成高踢和蓄力。改写成正面锁定：“每一脚都在腰带以下”“手臂第一个可见的动作就是已经在路上的拳”。
3. **主角出招写状态，不写准备。** 写拳已经在飞、打到之后的后果，不写“收拳蓄力”“准备出拳”。对手可以有明显的预兆动作，那正是主角截击的触发点。
4. **每一击都带反应，方向顺着来力。** 直拳让头向后仰，鞭拳让头向侧面甩，侧踹胸口让整个人向后飞，踩膝让腿向内折、身体向前栽。反应方向和来力不一致，模型会把它画回普通直拳。
5. **少见招式写三个锚点**：日常类比、先接触的面、顺着来力的反应（见 05C 空手格斗规则）。
6. **站架首镜写全，后面用同一句复述。** CUT 1 写完整身体几何，之后每个 CUT 只写“他回到窄侧身站架”这一句，措辞完全相同。
7. **每拍一个动作、一个画面事件。** 每一拍写清起始位置、动作（哪只手脚、什么路线、哪个目标）、对方的身体反应、新位置。把每一击拆成蓄力、启动、接触、余波、复位五段反而会冲掉关键事实。
8. **全段末尾写一句风格锁。** 写在【基础风格】末尾，措辞固定，见第七节。

## 二、截拳道

### 原则在画面上的样子

| 原则 | 画面上看到的 |
| --- | --- |
| 截击 | 对手刚开始出拳，主角已经先打中；对手的拳在半路熄火 |
| 经济 | 没有大弧线，只有短直线；两到四个动作结束战斗 |
| 不预兆 | 拳从护手原位直接射出，没有往回拉；出手前脸上没有任何变化 |
| 最长的武器打最近的目标 | 前手打脸，前脚踢膝和胫骨；不用后手绕过半个身体 |
| 攻防同拍 | 一只手拨开来拳，另一只手同时打中；不是先挡再打 |
| 断拍 | 一阵爆发 → 完全静止 → 又一阵爆发；对手在静止时落空 |
| 如水 | 不重复同一套组合，在远中近距离之间流动 |

### 站架

- **标准站架**（首镜写全）：他几乎侧身对着对手，右肩右脚在前，两脚比肩略宽，后脚跟离地一指宽，膝盖微屈，重心落在两脚前掌上，带着轻微不停的弹性。前手半伸、停在肩高，后拳靠在下巴前，两肘贴肋，下巴收紧，目光从前肩上方平稳看出去，脸上平静、读不出情绪。
- **示弱站架**：两手掌心朝外半举在胸前，像在劝对方冷静，但身体已经侧过去半边，右脚滑到前面，膝盖放软，重心在前掌。用于街头“我不想惹事”的开场。
- **断拍静止**：他回到窄侧身站架，完全静止，脚踩实，手停在护位，只有眼睛从前肩上方跟着对手。静止至少保持一秒。
- **早期传统站架**（年轻时期或传统学派）：七成重心坐在后腿，躯干接近正面，一只竖拳立在胸口正中，前臂沿身体中线。

前手不是死的：在原位细小地前后闪动，像随时要出手。后脚跟抬起是整套动作的扳机。

### 步法

| 步法 | 画面写法 |
| --- | --- |
| 推步 | 后脚蹬地，整个站架向前滑出一小步，前脚贴着地面擦过，两脚间距和侧身形状不变；每次约 30–60 厘米 |
| 爆发进身 | 从完全静止中一步滑出约一米，像击剑的弓步，躯干保持水平、不上下颠，一拍之内进入打击距离（李小龙本人可到约一米八） |
| 钟摆步 | 前腿迅速收到后脚旁，对手的低踢扫空，同一口气前腿再摆回去，直接带出反击；躯干几乎不动，两脚在身体下方互换 |
| 弧线绕步 | 小而快的击剑步沿弧线绕着对手走，始终面对他，绕向远离他强手的一侧 |
| 侧闪 | 最后一刻横跨半步离开来拳的线，拳从脸颊旁一掌宽处擦过，脚仍稳稳在身体下方；离线后立刻在新角度出手 |
| 收身闪踢 | 前腿迅速收到后腿后方，盆骨向后折，身体转成侧面，踢腿从腹前十几厘米处扫空；对方脚还没落地，主角的手已经出去 |
| 绕轴避抱 | 对方扑腿时，以前脚为轴转出一个角度，停在对方侧面、仍在打击距离内 |
| 悬浮 | 前掌着地轻轻弹动，头始终保持在同一高度滑行，像弹簧压紧却几乎不动 |

距离的升级顺序：推步（小）→ 推步跟进（中）→ 爆发进身配侧踹（最大）。一场戏可以沿这个顺序升级。

### 手法

| 手法 | 正文写法（几何 + 反应） |
| --- | --- |
| 前手直拳 | 前拳就从护位停着的地方射出，一条直线打到下巴，拳面竖立、拇指朝上，肘在拳后展开，一小步滑步把体重送进去；头猛地后仰，对方后退两步往下沉；他的手已经回到护位 |
| 插眼 | 前手张开，四指并拢绷直，像矛尖一样直刺对方眼睛，是全场最长最快的一击；对方往后一缩，双手捂脸，眼睛紧闭，有一两秒看不见 |
| 前手勾拳 | 直拳之后前臂弯起，短促地勾进下巴侧面，手肘压低，躯干只转几度；头向侧面甩，膝盖一软 |
| 鞭拳 | 手臂像反手扇耳光一样向外横甩，只是拳头握着，拳背指节（戴手表那一面）先打在太阳穴上，掌心朝下朝向自己；头顺着这一下向侧面甩，手臂沿原弧线弹回 |
| 弹鞭拳 | 从护位短促地反手一弹，像甩掉指尖上的水，拳背擦过鼻梁，同一拍内回到护位；头偏向一边，眼睛流泪 |
| 重鞭拳（终结） | 整个躯干拧过去，像握拳的网球反手，拳背砸在下巴上；对方头向侧面猛甩，身体转了四分之一圈倒下。这是唯一允许大幅度的一击，打完有一个收势停顿 |
| 连环冲拳 | 两只拳头沿对方胸口和脸正中的一条直线轮流冲出，拳面竖立，肘擦着自己的肋，像蹬自行车一样循环，每秒三到五拳，脚下小碎步往前压；对方手臂乱挥着倒退，仰面倒地 |
| 寸拳 | 拳头起手就贴在对方胸口，髋、肩、手腕同时一抖，对方整个人向后飞离地面撞进货架。只在用户要求时写 |
| 铲勾 | 从一掌宽的距离短促地向上铲进浮肋下方，指节半朝上；对方绕着这一点侧身折腰 |
| 后手直拳 | 后拳紧跟前手直拳直线穿出，髋部一甩，打在前手刚打开的那条线上 |
| 锤拳 | 拳头像锤钉子一样抬起再砸下，用小指一侧的拳底打在对方弯下的后颈 |
| 肘击 | 胸贴胸时手臂折起，肘尖沿一条短平弧线切过下巴；头向侧甩，对方踉跄撞墙 |

出拳的力量感：手先出、脚后到，后脚蹬地、身体跟上，脚在拳打到之后才落地；打中那一刻身体明显往下一沉；收手比出手更快。截拳道直拳躯干几乎不转，肩膀接近正对，和拳击大幅拧身的后手拳不同。

### 腿法（默认都在腰带以下）

| 腿法 | 正文写法 |
| --- | --- |
| 侧踹踩膝 | 躯干向反方向倾，前膝提起，腿向侧面直线蹬出，髋部翻过去，脚刀外缘和脚跟先到，脚趾横指画面，跺在对方前腿膝盖侧面，整个动作在膝盖以下完成，像踢上一扇矮门；膝关节一折，对方向前栽 |
| 截踢 | 对方前脚刚离地，主角前腿已经横着蹬出，脚跟领先、躯干后倾，脚底在半路迎上对方迈出的膝盖；进攻还没成形就塌了，对方自己的冲力撞在脚跟上。没有提膝蓄势，腿直接抬起、脚掌放平 |
| 侧踹胸口（终结） | 滑步进身，躯干后仰，前膝折向胸口，腿在腰高横向蹬出，脚跟领先，从肩到脚跟一条直线撑住，像跺开一扇沉重的门；对方双脚离地，向正后方飞出两三米撞进箱堆，身体绕着受力点折起来 |
| 斜踩胫骨 | 前脚向下向前斜跺过对方胫骨，刮过骨头、压住脚背；那条腿在他身下一软 |
| 低勾踢 | 前腿在腰带高度短促地划一道弧，脚背和小腿下段平拍在肋侧，腿沿同一弧线收回，髋只抬几度；对方抱着侧腹弯下去 |
| 切支撑腿 | 对方抬起扫踢，主角压低身体，小腿砍在对方支撑腿的小腿肚上；对方支撑一空，仰面摔平，那一脚在空中熄火 |
| 抱颈膝撞 | 双手扣住对方后颈往下拉，迎上提起的膝盖；膝盖撞进心窝，对方跪倒在地张嘴喘气 |
| 转身后踢 | 以前脚为轴转身，背对对手半拍，后脚跟像骡子尥蹶子一样沿直线向后蹬进腹部，转一圈干净利落，脚落地时已经重新面对对手。只在用户要求时写 |

### 黐打与截击

| 动作 | 正文写法 |
| --- | --- |
| 拍手打 | 后手掌把对方护在前面的手臂向下向内拍住，同一拍里前拳从打开的那条线射进下巴；两只手同时工作，头后仰，被拍的手臂还压在低处 |
| 拉手打 | 一只手扣住对方手腕，向下拽过自己髋旁，手肘砸回肋侧、髋跟着转进这一拉，对方脸朝前一头撞进反方向飞来的短拳；拉和打同时落下，像两列火车对撞。对方身体被拽得前倾下沉，从主角身边栽过去 |
| 绕手 | 出拳的手碰到格挡，贴着它往前绕一个小圈，沿新打开的线继续打到脸上，一条不断的路线 |
| 沉桥 | 手指勾住对方前臂上沿往下一拽一掌宽，脸露出半拍，另一只拳打进去 |
| 截击直拳 | 对方肩膀刚开始为摆拳蓄力，主角的前拳已经落在他下巴上，直线赢了弧线；摆拳死在半路，对方自己往前冲的体重让这一击加倍 |
| 拨打同拍 | 后手掌把来拳推偏一掌宽，前拳沿更短的直线先到；拨和打在同一拍里完成，拨的幅度不超出身体轮廓 |
| 黐手爆发 | 两人前臂在手腕处黏住，画着小圈滚动，重心来回交换；他突然从滚动里冲出一记竖拳打进胸口 |
| 连环破门 | 两拍之内三次手上争夺：拍下护手、另一只手抓腕一拽、腾出的拳横砸太阳穴；每一下为下一下开门 |

拍还是拉，看对方的手：对方的手越过自己中线就拉，留在中线里侧就拍。

### 擒摔与对武器

- **拉腕摔**：拽腕的力迎上对方自己的踉跄，主角一脚扫过对方前脚踝，对方从身边扑倒在地，手臂还被拽着停留一拍。
- **立式反关节**：把出拳的手臂送过自己前臂，撬直锁住肘关节，对方顺着跪倒，手臂僵直被锁。
- **解抓**：不跟对方抢手，脚跟直接跺在抓人的那只手上，手指弹开。
- **对刀**：一步斜出刀线，前脚低低戳进持刀者的前膝，突刺在半路塌掉；双手扣住持刀手腕，手肘压在被锁的前臂上，刀从弹开的手指里落下滑过湿地。主角推开对方，重新侧身静止。不先伸手去抓刀，先用距离和低踢。
- **对棍棒**：在棍子还没起速之前抢进摆幅内侧，前臂顶住对方上臂，拳同一动作打到；棍子的弧线死在主角肩后。

### 五种攻击方式在戏里的用法

| 方式 | 戏剧用途 |
| --- | --- |
| 单一直接攻击 | 一记毫无准备的直拳，从意想不到的角度打到；最显功力 |
| 组合攻击 | 两三拳的短组合，最后一拳回到第一拳的高度（打身—打头—打身） |
| 渐进间接攻击 | 先在一条线上佯攻，真打在另一条线；佯攻吃掉一半距离，对方的手还往反方向走时真攻已经出发 |
| 诱敌攻击 | 故意露出一个空当，对方扑过来，截击；宗师最常用、最有电影感的赢法 |
| 封手攻击 | 压住对方一只手，从打开的线打进去（拍手、拉手） |

**佯攻规则**：佯攻要做得像真的，对方必须有一个看得见的反应（手一抽去防），这本身是一个小拍。连续佯攻不超过两次；第一下深而长，真打短而狠。

### 段落模板

| 模板 | 时长 | 拍子 |
| --- | --- | --- |
| P1 截击单次进攻 | 4–6 秒 | 主角窄侧身站架静止，对手正面逼近 → 对手抡起大摆拳 → 截击：前手直拳在对手蓄力时打中下巴，配一步进身，摆拳死在半路 → 对手踉跄或倒地，主角回到站架静止 |
| P2 腿进拳（远到中） | 6–8 秒 | 弧线绕步 → 对手迈步上前，侧踹踩膝 → 膝盖一折、对手前栽 → 迎着下栽的身体前手直拳或勾拳打下巴 → 对手从身边倒下，主角静止 |
| P3 封手组合（中到近） | 6–8 秒 | 对手直拳，主角拍手打一拍完成 → 对手晃了一下再打，拉腕迎上鞭拳 → 对手被拽前栽倒过去，主角松手，静止 |
| P4 冲拳收尾 | 4–6 秒 | 被截击或打懵的对手失去架子 → 连环冲拳，主角小步前压、对手倒退 → 侧踹胸口把他送进障碍物（箱子、门、墙） |
| P5 一对二 | 8–12 秒，两个 CUT | 不同时打两个人，移动到让两人排成一线、前一个挡住后一个 → CUT 1：近的那个先上，用 P1 或 P2，倒下时挡住第二人 → CUT 2：第二人跨过或绕过倒地者，主角用截踢或 P3 迎上。两人用不同模板 |
| P6 对刀 | 6–10 秒 | 刀一入画，主角立刻拉开距离，手抬成窄架，身体侧过去 → 突刺，斜出刀线配低侧踹踩持刀侧膝盖 → 双手扣腕、肘压前臂，刀落 → 直拳或侧踹拉开距离，静止 |

**一场完整的截拳道打戏**：静止 → 挑衅或对手进攻 → 截击 → 一到三个动作的爆发 → 静止。主角在爆发前后都几乎不动，暴力只是两次静止之间的一道闪光，这是它和“绞肉机”式打戏的区别。

**街头自卫结构**：威胁或抓握成立 → 一个小防守动作（闪、蹲、侧步、截击）→ 低位反击（膝、胫骨、裆、眼、喉）→ 对手失去平衡 → 对倒下中的对手手脚收尾。三到五拍，两到四秒。被两个人包夹时先爆发，借蹲和转身逐个处理，不站在两人中间不动。

**距离流动**：踢击距离进场 → 黐打距离封手 → 拳击距离组合 → 摔投或锁技收尾。适合长段落的一镜或连续几镜。

## 三、咏春

### 和截拳道在画面上的区别

| | 截拳道 | 咏春 |
| --- | --- | --- |
| 站架 | 侧身，强侧在前 | 正面，窄，膝盖内扣 |
| 距离 | 进进出出，四个距离 | 贴上去就不离开 |
| 节奏 | 断拍，爆发和静止交替 | 持续压力，像缝纫机 |
| 出拳 | 带步伐的鞭甩和活塞 | 从胸口发出的短活塞，肘贴肋 |
| 腿 | 脚刀侧踹 | 脚跟或全脚掌向正前方蹬踩 |
| 赢法 | 两到四拍，靠截击 | 先缠住双手，再一串打到对方垮掉 |

### 站架

- **训练站架**：他正面对着对手，两脚很窄，只比髋略宽，脚尖微微内扣，两膝互相夹紧，重心沉在骨盆里。两手叠在胸前同一条竖线上：前手半伸、指尖向前，后手折在胸骨前。两肘沉重地贴着肋骨，脸平静，下巴放平。
- **入桩**：双脚并拢 → 以脚跟为轴脚尖外开 → 以前掌为轴脚跟外开 → 坐下，脚尖内扣、膝盖相夹。像“咔、咔”两下扣进一个平台，然后像雕像一样不动。适合训练戏和冥想式镜头；实战时从这里一步或一转身爆发出去。
- **实战站架**：两脚约与肩同宽，重心偏后腿，前腿几乎不受力，身体转 30–45 度。前手在中线上（问手），后手掌立在下巴前（护手），两手在胸骨前形成一个金字塔。
- **静手**：前手在胸口高度的中线上悬着不动，对佯攻毫不抽动，只对真正来的拳在最后一刻抬起十几厘米。全然静止 → 爆发。

### 步法

- **压步**：小而平的步子往前蹭，后脚推、前脚擦地，每步半只鞋长，一路走进对手身里，不让空当打开；配连环冲拳时对手被逼着直线后退。
- **转马**：两脚钉在原地，整个身体以脚跟为轴转四分之一圈，正面的架子像门绕着合页转开，来拳从胸前一掌宽处滑过。转身是离线加发力，不是后退。
- **之字步**：第一步斜着离开攻击线，第二步从侧面切进去，同时出手。
- **头始终在同一高度**，躯干不晃、不起伏，这是咏春步法在画面上的标志。

### 手形（都从肘部发动，肘离身体约一拳，像不动的轴）

| 手形 | 正文写法 |
| --- | --- |
| 摊手 | 前臂沿中线翻成掌心朝上，像托着一只盘子，楔进来拳、把它从胸前挤出去；后手同一拍从同一个窗口打出去 |
| 膀手 | 受压时手臂折成一只高翼，肘高过腕、前臂斜向下，来拳像雨水从屋檐滑落一样从上面滚过去；身体随之转动，腾出的手沿中线回击。肘几乎不动，是前臂绕着肘转，不是鸡翅膀那样扇 |
| 伏手 | 手腕勾着搭在对方前臂上面，肘下沉，从上方通过接触读出对方每一下抽动，掌控那条线 |
| 拍手 | 掌根带一点脆响把来拳横拍向自己对侧肩膀方向，不超过身体宽度，另一只手同时反击 |
| 拉手 | 手指扣住对方手腕往自己身前向下一拽，把他拉进自己的拳里 |
| 耕手 | 前臂从肘部向下沿身体落到髋旁，像把东西放进口袋，把上勾拳或踢来的小腿往下往外“落掉”，不是去接 |
| 按手 | 前臂外缘向下压住对方的手臂，压到心窝高度 |
| 标手 | 手指伸直并拢，从内向外拨开来拳，同时就是戳眼的一下 |
| 护手 | 掌心竖立在胸前中线上，手指并紧、拇指收好，随时准备抓 |
| 圈手 | 手腕绕着对方手臂画一个小圈，从外门转到内门，接着一掌推出去 |

两手配合：一只手在高位工作，另一只手就护着低位；空着的手永远在身前中线上。

### 打法

| 打法 | 正文写法 |
| --- | --- |
| 连环冲拳 | 两只拳头从胸口正中轮流沿一条直轨冲出，拳面竖立、肘擦着肋骨，一拳收回胸骨时另一拳已经出去，每秒三到五拳，平小的步子吃掉距离；对方的头和胸在这阵鼓点下不断后仰，直到后背撞上墙。节奏均匀，没有重音 |
| 正蹬 | 膝盖沿中线提起，脚掌平着向正前方蹬进对方大腿，像用脚底关上一只沉重的抽屉，蹬穿过去；对方髋部向后弹，身体在腰部折起来。只踢腰以下 |
| 掌底 | 掌根从胸骨前笔直撞向下巴，手指朝上，整条手臂是一根活塞；头猛地后仰，像撞上门框 |
| 标指 | 手臂像布一样软软飘出，在最后一指宽里突然绷紧，像鞭子抽响，指尖刺向喉咙；对方捂着脖子呛咳着后退 |
| 肘 | 胸贴胸时，折起的手臂沿斜线向下劈过锁骨，从架子本身发出的短而重的一劈，身后没有挥动，整个身体随这一下往下沉 |
| 合速 | 左手扣住对方手腕猛地往自己身前一扯，右手掌底同时向前打出；对方被扯得踉跄，自己的冲力加进这一击，两股速度在下巴上相撞 |

打法的共同点：没有任何后拉；力量从脚到髋到腰到肩，最后从手上放出；手臂一直放松，只在最后一刹那绷紧；打点放在目标后面几厘米，打穿过去。

### 黐手与拉手循环

- **黐手**：两人面对面，前臂黏在一起，手按摊、膀、伏一圈圈滚动，躯干几乎不动，像用手说话。一方压过来就顺着滚，一方撤回去手就跟进打进空当。
- **单黐手循环**：甲摊手 → 低掌推出 → 膀手；乙按手 → 直拳 → 伏手；伏手落在摊手上，循环滚动。可直接用作训练戏的循环底子。
- **拉手循环**：抓腕一拽同时直拳 → 对方膀手化解 → 对方反过来抓腕一拽、出拳 → 再膀手……一架不停转动的风车，适合动态中景。
- **节奏**：均匀、催眠似的滚动（约每秒一圈到三圈）→ 在任意一拍上突然断开：一拉加一拳 → 回到循环。拍摄用严格侧面的腰上中景，手臂在剪影里看得清。
- **结构对比**：结构对的人被推时纹丝不动；结构错的人（肘外翻、身体前后倾）被一推整个人移开、躯干塌掉。用来写输的一方，比“被打飞”更可信。

### 段落模板（咏春）

| 模板 | 拍子 |
| --- | --- |
| 搭桥破门 | 对手绕圈蓄力，宗师正面站着几乎不动、手在架子里 → 前臂接触 → 两三拍黏着重组（摊、膀、伏，拍、拉）→ 通道打开 → 连环冲拳直到对手垮掉 → 宗师把手放回架子，像开打前一样站着 |
| 之字切入 | 之字步离线 → 第二步摊手和直拳同一拍 → 低位正蹬踩膝 |
| 下拉收尾 | 对手刺拳 → 膀手配护手 → 拉手把手臂向下拽 → 掌缘切喉 → 直拳打心窝 |
| 双层次 | 插眼佯攻 → 直拳打喉 → 脚跟正蹬打裆 → 上步横肘打太阳穴 |
| 截腿 | 对手低踢 → 提膝用小腿挡 → 脚落地同时膀手接拳 → 拉手下拽 → 向上的冲拳打下巴 |
| 静手截击（街头） | 前手静悬中线 → 对手真出拳时短促抬手偏开十几厘米，同一拍从对方手臂上方回击 → 小步贴进去 → 控颈控肩，近身短打 |
| 截刺拳（对拳手） | 戴拳套的对手从远处刺拳 → 迎着他进身：平行拍挡加同拍直拳 → 拳击距离塌成近身距离，拳套没用了 → 黏住手腕、连环冲拳 |

### 反应的两种写法

- **写实**：结构被破坏，躯干塌掉，脚步乱，被推开半步，手指张开被抓住。适合真实街头。
- **夸张电影式**：被打的人向后飞出两三步、弯腰对折、头猛甩后仰。用户要好看、要读得出力度时用。

一场戏里选一种，别混。

## 四、人物与对手

- **宗师**：打到生死关头也像平常一样，脸上没有表情变化，眼睛不瞪、不怒，目光散开看整个人而不是盯手；两次爆发之间几乎不动，身体紧凑放松，像弓起背却放松的猫。愤怒和恐惧会让人变慢，所以发怒的一方更容易被截击。
- **学生**：同一套武器，节奏更均匀，组合更多，截击更少；动作略紧，偶尔失误。
- **对手（非截拳道）**：大摆拳、正面方站、预兆明显（拳往回拉、肩膀先动、脸先狰狞）、出拳只用手臂、打完手臂挂在外面。站姿用“错误站姿”：拳收在腰间、双手举太高、胸口正对、两脚交叉、身体压在前腿上、站得又高又直、嘴张着。主角的轮廓窄而侧，对手的轮廓宽而开，一眼分出高下。
- **传统学派对截拳道**：传统一方马步宽、拳收腰间、靠格挡后再打；截拳道一方侧身弹动、一记长直拳爆发。咏春一方则贴身不离、手一直搭在对方臂上、点对点短打。
- **体型差**：瘦小的人靠结构、角度和时机打倒大个子；年长宗师对壮汉，一次有效动作胜过一串花哨动作。

## 五、摄影与节奏

- **角度**：侧身站架和直拳在侧面或四分之三侧面最清楚。踢腿要让腿脚全在画内，不用胸部以上的近景；黐手和拉手用严格侧面的腰上中景；倒地后的锁技用能看见两人全身的低机位。
- **决胜交换用固定远景长镜头**：李小龙自己的拍法，让速度和准确度完整可读，不靠快剪制造混乱的错觉。其他段落按 05C 的观看证明方式选。
- **切点**：一次交换一个 CUT；多镜时切在断拍的静止处，那是天然的剪辑点。
- **节奏公式**：稳定的循环或静止 → 突然断开 → 0.5–1 秒的爆发 → 复位。截拳道是“静—爆—静”；咏春是长时间的柔慢黏着加 0.3–1 秒的爆发，没有中速。
- **一击之内**：收手比出手快；打中那一帧身体下沉；连环冲拳每次进身后打三到五拳再回站架。
- **截击偷拍子**：反击在对方动作完成前就开始，截踢在对方踢腿的前三分之一，反击的手在对方脚落地前出发，进身在扫踢弧线过半前完成。
- **长对话里的爆发**：长时间平静的对话或对峙，中间插一两秒的动作闪光，再回到平静。

## 六、训练戏

| 训练 | 画面与声音 |
| --- | --- |
| 手靶 | 持靶人像对手一样用靶“回应”，把来拳拍向一侧；竖拳成对地啪啪打响、立刻弹回，脚在组合之间滑动。三分钟一轮：第一分钟慢，第二分钟快，第三分钟全速 |
| 木人桩 | 硬木桩约一米五高、二十多厘米粗，上面两只斜伸的手、中间一只低手、下面一条弯曲的腿，架在两根横木上、会弹会晃。练的人几乎不离开桩，小步绕着转，双手始终贴着木头，肘低、背直。三种声音：掌拍木手的干脆“啪”、前臂磕木手的闷“哒”、掌或脚打进桩身的低沉“咚”，被拉“颈”时桩在框里晃、木架吱响。节奏三到五个动作一组，转身换边，像鼓手换花样 |
| 等长拉带 | 对着固定皮带用力，拳停在半伸，手臂发抖、前臂筋络突起，十到二十秒后一松、长长吐气，再一下爆发 |
| 拍掌反应 | 站得松松的，眼神放软，画外一声拍掌，他瞬间向前爆发一拳，回声还没散就又静止了 |
| 纸靶 | 吊在胸高的一张纸，拳或手指打穿纸面，纸啪地破开 |
| 墙靶 | 拳和掌打进墙上的沙包，练穿透感 |
| 地上胶带 | 白色胶带在木地板上画出站架轴线，教练绕着学生走，手动调整脚和躯干的角度 |
| 小念头 | 正面站在训练站架里，脚从头到尾不动，只有手动，一只手一只手地做，极慢、像冥想，只在动作末端一瞬间绷紧，每一击鼻子呼气 |
| 寻桥 | 带步法和转身：180 度转身配膀手，转身后侧踹配短促呼气 |
| 标指 | 原地一扇快速的插指，90 到 180 度猛转方向，转过去就是一记斜劈肘 |
| 三桩踢 | 正蹬前桩，不放腿接侧踹右桩，重心一换再侧踹左桩，像被三人包围 |

剪辑模板：先单人慢做一个动作（套路），再和搭档快打同一个动作（应用）。

## 七、声音与风格锁

- 每一下接触都要在【声音设计】里列出来并对准接触帧，不列就是无声的。连环冲拳是均匀的机枪点射；掌拍前臂是短促的脆响；拉手带一声风啸；木人桩三种质地见上表。
- **截拳道风格锁**（写在【基础风格】末尾，措辞固定）：每一脚都在腰带以下；每一拳都从双手护位停着的地方沿短直线射出，手臂第一个可见的动作就是正在飞行的那一击；两次交换之间他在窄侧身站架里完全静止；整场是短直线和长静止。
- **咏春风格锁**：每一脚都在腰带以下；每一拳都是从胸口正中射出的短直线活塞，肘贴着肋；他始终正面窄站，小步向前压；整场是一条竖直中线和不停的向前压力。

## 八、交付前检查

**截拳道**：首镜写了完整站架几何；至少一次截击；腿都在腰带以下；出手没有后拉；有断拍静止；两到四拍解决；每一击写了哪只手脚、路线、目标和顺着来力的反应；正文没有术语和禁止句；末尾有风格锁。

**咏春**：首镜是正面窄站；至少一拍前臂黏着、看得出通过接触重组；连环冲拳配压步作为主要收尾；腿是腰以下的正蹬或踩；肘始终贴肋；末尾有咏春风格锁。

## 九、常见问题修复

| 症状 | 原因 | 修复 |
| --- | --- | --- |
| 打成大开大合的普通功夫片 | 写了招式名或“功夫”“武术动作” | 换成身体几何，首镜写全站架，末尾加风格锁 |
| 鞭拳、侧踹被画成直拳、正踢 | 缺日常类比、接触面和反应方向 | 按总则第 5 条补三个锚点 |
| 出现高踢、转身踢 | 写了“不要高踢” | 删掉否定句，写“每一脚都在腰带以下” |
| 主角先挡再打，像两拍 | 防守和反击写成两句 | 写成“同一拍里一手拨开、一手打中” |
| 拳像推人，没有力量 | 只写了伸手 | 写手先出脚后到、打中时身体下沉、收手比出手快、打穿目标 |
| 主角咬牙怒吼 | 写了情绪词 | 写平静的脸和散开的目光 |
| 黐手看不清谁在干什么 | 正面或近景拍 | 改严格侧面腰上中景，写清哪只手控制哪条线 |
| 每拍细节太多，关键动作反而丢了 | 每一击拆成很多阶段 | 回到每拍：位置 → 动作 → 反应 → 新位置 |
| 连环冲拳像乱拍 | 没写中线和节奏 | 写两拳沿同一直轨轮流、均匀、配小步前压 |

## 十、示例

小巷截击（截拳道，P1，约 6 秒）。只示范打斗栏目的写法，时码按 06A 落到实际项目：

```text
【基础风格】
……每一脚都在腰带以下；每一拳都从双手护位停着的地方沿短直线射出，手臂第一个可见的动作就是正在飞行的那一击；两次交换之间他在窄侧身站架里完全静止；整场是短直线和长静止。

【运镜与时间轴】
CUT 1（0-6秒），侧面全景，固定机位，两人全身和脚都在画内。阿森几乎侧身对着画右的壮汉，右肩右脚在前，两脚比肩略宽，后脚跟离地一指宽，膝盖微屈，重心在前掌上轻轻弹动；前手半伸停在肩高，后拳靠在下巴前，两肘贴肋，下巴收紧，脸上平静。壮汉正面方站，向阿森逼近一步，右肩向后一拉，抡起一记大摆拳。就在他肩膀刚开始蓄力的那一刻，阿森的前拳已经从护位停着的地方沿一条直线落在他下巴上，拳面竖立，一小步滑步把体重送进去；摆拳死在半路，壮汉的头猛地后仰，踉跄退两步撞上身后的垃圾箱。阿森回到窄侧身站架，完全静止，只有眼睛跟着他。

【声音设计】
拳头打中下巴一声短促的闷响，对准接触那一帧；壮汉后背撞上铁皮垃圾箱的哐当声；之后只剩远处车声和两人的呼吸。
```
