# 04 Camera Light Color Style

priority: high
scope: 基础风格、camera、lens/focal length、shot size、camera movement、光线、色彩、画家/流派语义编译

## 使用边界

本文件是静默参考库，不是最终输出模板。最终回答必须按 `01_CORE_EXECUTION_CONTRACT.md` 的中文输出格式写，不要把本文件里的英文表头、英文示例或表格结构直接复制给用户。英文只保留必要技术短语，例如 `slow dolly in`、`rack focus`、`IMAX 65mm language`。

## 基础风格写法

`【基础风格】` 是 Seedance 提示词的高优先级模块，每个独立段落都要出现。它紧随置顶的 `【角色/场景/素材锁定】`，并位于 `【运镜与时间轴】` 之前；它不是一次性总说明。

写法规则：

- 每段明确写出摄影机系统与感光/画幅基准。真人/写实画面点名具体 cinema camera 或胶片画幅；动画、动漫、游戏和纯CG写 `virtual cinema camera` 与等效 Super 35/large-format 等画幅，不伪装实拍元数据。
- 每段重复项目级统一基调：摄影机、画幅、lens rendering、焦段/景深倾向、扩散/高光、色彩关系、黑位、颗粒与材质基线。
- 每段补充本场景变化：动机光源、方向、主光与环境/practical色温、光比、阴影/negative fill、天气/空气介质、空间材质和情绪反差。
- 不允许后续段落只写“同上”“沿用上一段风格”。如果要保持统一，就写“延续 [项目级基调]，本段改为 [具体场景变化]”。
- 风格参考、画家/流派参考也写进这里，转换成线条、色彩、构图、质感和光线，不单独开素材说明栏目。
- `真人电影风格`、`电影级调色`、`暖光`、`冷光`、`高级质感`只能作为完整技术描述后的摘要，不能单独成段。8K、杰作、大师级、超写实、电影感、高级感、氛围感这类空泛质量词不写，换成看得见的光源、材质、颜色和动作。

### 基础风格最小技术包

1. **Capture**：camera body/film or virtual camera + sensor/film format + aspect ratio。
2. **Optics**：lens family/rendering + focal tendency + depth of field + diffusion/halation/highlight rolloff；flare/畸变只在有用途时写。
3. **Lighting/exposure**：motivated key/fill/practical + direction + key/ambient color temperature + intensity + shadow hardness + negative fill + contrast ratio。
4. **Atmosphere/depth**：空气清晰度、haze/烟尘/湿气、空气透视或体积光，以及前中后景的实际结果。
5. **Surface/texture**：skin/material microtexture + grain + roughness/specular；按材质条件加入 anisotropy、caustics、湿润反光或尘土吸光。
6. **Color finish**：palette relation + saturation + warm/cool separation + black point/toe + highlight behavior + LUT/stock-like visible result。

每项可以压缩成短语，但不能缺项。CUT 内仍负责具体景别、焦段与光线事件；它们不能反向替代 `【基础风格】` 的项目采集与成像基线。

推荐句式：

```text
摄影机/画幅：[camera body or virtual camera] + [sensor/film format] + [aspect ratio]。
镜头/成像：[lens family] + [focal tendency] + [depth of field] + [diffusion/highlight/flare/distortion]。
画幅呼吸感：[默认克制、不规则的自然呼吸漂移与细小修正，强弱按剧情与对标；明确固定或极稳时写固定]（见下方“自然呼吸感”）。
受光/曝光：[motivated sources] + [direction] + [key/ambient color temperature] + [shadow/negative fill] + [contrast ratio]。
空气/纵深：[air clarity or medium] + [aerial perspective/volumetric result]。
材质/质感：[skin and material microtexture] + [roughness/specular/anisotropy/caustics when supported] + [grain]。
色彩/收尾：[palette relation] + [saturation/warm-cool] + [black toe/highlights] + [LUT/grade result]。
```

## 默认特写与浅景深覆盖

新编默认多用CU/MCU和有叙事用途的ECU，以大光圈、合适焦段、主体距离与前后景间距建立浅景深，把注意力留给眼神、嘴部表演、手与关键道具，降低无关背景细节漂移。写清对焦对象、焦平面及需要辨认的范围；不能只写“大光圈电影感”，也不规定每镜都用同一焦段、固定T值或特写比例。

先按03证明摄影机位置、朝向、视锥和真实后景，再决定裁切与虚化。浅景深不能修复错误的门/座位/人物方向、互相穿越或错误功能面。必须看清出入路线、握持/接触、支撑、多人反应、道具功能面或屏幕文字时，保留同框证据、调整焦平面/光圈，或安排短MS/WS建立与明确接力；全景与适度深焦可以承担空间信息和跨段衔接。无关背景可化为稳定色块和轮廓，剧情证据不能被遮挡、裁掉或虚焦。用户指定的深焦、群像、大全景或一镜到底意图优先，不把本偏好变成每CUT硬门。

### 200mm 及以上：超大光圈、极浅景深（默认强制）

焦段按全画幅等效：200–300mm 记长焦，300–500mm 记超长焦；300mm 是两档交界，用户当次有称谓就沿用，未指定时按超长焦标注。这是本 Skill 的命名与成像约定，不是“长焦必然浅景深”的光学定律，所以要用光圈、拍摄距离与焦平面写出结果，不能只报一个数字。

- 凡 CUT 用到 200mm 及以上（含 200mm 端点和更长焦段），都写“超大光圈、极浅景深”，并写出结果：主体所在的薄焦平面清楚，后方环境完全在焦外，只剩认不出细节和轮廓的柔和大色块。远处建筑、地形、装置和人物不能同时清楚，不为交代参考环境收小光圈、扩大景深或做成前后全清。
- 场景参考图在这类 CUT 里只提供世界位置和光色依据：背景继承该处的光源方向、色温和大块明暗、色彩关系，不列出图里有哪些建筑和道具，不写“完整还原环境”“背景清晰可见”“透过间隙看清远处装置”。远物是什么，交给其他合适焦段的镜头交代；已由别的镜头建立的空间关系，不必在长焦特写里再证明。
- 长焦压缩体现在后方层次被拉近、相互叠合，但仍是强虚化，不用清晰的背景结构证明压缩。约定持续覆盖运动、甩镜落幅和失焦再合焦之后：合焦只找回指定主体，不把整个环境变清楚；普通长焦镜头不主动转焦去拍清远背景，用户明确指定焦点揭示时，只让当前目标所在的焦平面清楚。
- 特写要眼清耳虚时再补耳部与远侧眼睛柔化；全身远距离长焦不强求面部的景深分离。
- 可复用短句：“250mm 长焦，超大光圈、极浅景深。焦点落在主体近侧眼睛，后方空间被压缩成完全认不出结构的焦外色块，只延续场景的光向、色温与明暗关系。”
- 只有用户针对该镜明确要求深景深或背景可辨时才覆盖本条；对标和一般空间说明都不构成破例。需要读清出入路线、多人反应或屏幕文字等空间证据时，按上一节另选焦段或补宽景接力，不把长焦背景改清楚。

### 高速与稳定运动不按机身写（补充）

有两类器材的“风格”其实是时间和运动，不是成像，写成机身名会把器材画进画面或让整段变慢：

- **高速摄影机（Phantom 一类）**：写成 speed ramp 或 slow motion 插镜，只用在一个具体动作区间：轮胎压水、碎石飞溅、悬挂压缩、布料或液体受力。写明进入前是实时、放慢到多少、持续多久、何时回到实时，并写出放慢后才看得清的细节（水花分成一颗颗水珠、碎石沿受力方向散开）。不把整段写成高速摄影。
- **四轴稳定或手持稳定系统（Ronin、Steadicam 一类）**：写成运动路径：`stabilized low-slung glide`、贴地低机位平稳跟随、从车外经由车窗进入车内的连续推进。`Steadicam glide` 这类运动方式的英文技术短语可以写；云台、吸盘、拍摄车等器材实体不写，按下文运镜语法中术语对照后的说明，只写观察高度、路线和画面结果。

车拍里的拍摄车、吸盘、摇臂车同理，见 [05G](05G_VEHICLE_CINEMA.md)。

### 变形宽银幕的画面证据（补充）

只写“变形宽银幕镜头”时，模型常给出一张普通照片：它认的是画面里的证据，不是镜头名。用到变形宽银幕时，在【基础风格】或对应 CUT 写出这些结果：

- **焦外光斑**：竖向拉长的椭圆，写明落在哪些亮点上（积水反光、路灯灯泡、窗口光），不只写“椭圆焦外”。
- **横向拉丝光斑**：写明从画内哪个最亮的光源拉出，颜色跟光源走，冷光源可偏蓝，钨丝灯、火光写暖橙色。画内没有亮光源就不写拉丝；需要时先在画面里安排一个（灯、天际亮带、湿地反光）。
- **广角虚化要有物理依据**：24mm 或 35mm 只写“强烈虚化”不会生效。写一个具体焦点物、摄影机离它约 1–3 米、光圈全开，再写前景和远处哪几层化成焦外；不写焦点物时模型会让全画面清晰。
- **人脸焦段**：人脸不用 24mm，会被拉宽；单人近景用 50mm 或 85mm，全身 50mm，群像 35mm。
- **畸变与画幅**：出现鱼眼或桶形弯曲时写“直线保持笔直”，并降到 35mm。画幅默认 2.39:1，正文写明，界面里也要设置。
- **机位**：广角大景写清摄影机在空间哪一侧、斜对角看向纵深、镜头在膝/腰/胸哪个高度，纵深层次才立得住。

### 焦段 + FOV 补充锁定

FOV 不代替焦段。默认仍按“焦段/光学特征 + 摄影机物理距离 + 景别 + 可见透视结果”编译；只有画面边缘覆盖、超广角直线保持、远距离压缩或平台对角度语言响应更明确时，才补充 `diagonal field of view`。

全画幅等效下可使用以下近似对照，数字只用于避免自相矛盾，不作为每个 CUT 的必填项：

| 焦段近似 | 对角 FOV 近似 | 可见结果 |
| --- | --- | --- |
| 310mm | 8° | 极强长焦压缩、远距离观察、前景遮挡明显；超大光圈、极浅景深 |
| 200mm | 12° | 长焦压缩、局部观察；超大光圈、极浅景深，背景只剩焦外色块 |
| 135mm | 18° | 长焦隔离、背景明显压缩、浅景深倾向 |
| 85mm | 29° | 短长焦人像、面部比例稳定、背景靠近 |
| 50mm | 47° | 自然标准透视、空间比例中性 |
| 24mm | 84° | 广角空间扩张、摄影机靠近、环境边缘可读 |
| 16mm | 107° | 超广角 rectilinear、近大远小显著、直线仍保持直线 |

若同时写焦段和 FOV：

- 明确这是同一画幅/裁切下的近似关系；换成大画幅、Super 35、竖屏裁切或后期 crop 时重新核算，不机械照抄。
- 摄影机距离必须支持目标景别；不能一面写“20米外观察”，一面要求16mm贴脸透视。
- 最终提示词仍要写可见结果，例如背景压缩、环境覆盖、边缘直线、前景放大、主体大小和景深，不让数字独自承担控制。
- 一个 CUT 内保持同一焦段/FOV，除非明确执行 `zoom`；换焦段发生在新 CUT，或写成可见、连续且有叙事理由的变焦动作。

### 景别覆盖可行性门

先列出本CUT必须由画面证明的最远证据边界，再选择能容纳它们的最紧景别。若同一动作必须同时读清双方支撑脚、髋肩发力、双手握点、长兵器功能端与接触点，使用MLS/WS或能明确覆盖全身的等价构图；MS只能承诺真实入框的躯干、手和局部道具，MCU/CU/ECU不能同时声称脚步、全长兵器或全身距离可见。坚持紧景别时，删除画外可见要求，或在接触前/后用有动机宽景接力补足，不用文字假装裁切外证据仍在画面内。

画幅改变时沿整个动作路径重选覆盖：9:16优先检查横扫、兵器端点、横向出入和落点，21:9等宽屏优先检查头脚、跳跃顶点与垂直落差。先改可达机位、距离或覆盖镜头；导演可补空白调度，但不能为塞进画框擅改已锁动作、把幅度缩小或把速度放慢。涉及后期裁切时按最终可见画框而非原始画幅判断；只有明确存在播放界面遮挡时才避开对应区域。宽屏可用横向关系依次转移注意力，竖屏可用纵深或上下层次组织，画幅本身不决定切镜频率。

画幅短例仅供当前任务选用，不是固定构图或镜序：

- **9:16双人对话/递物**：两人已隔桌相对时，先选斜侧机位，让近侧人的肩与递物手落前景、远侧人的脸与接物手落中景，桌沿连接动作路径；camera随手部交接小幅重构图，接触读清后把焦点交给接收者。双方表情必须同时读清而该机位做不到时再补覆盖，不靠搬动已锁座位硬塞进窄框。
- **21:9三人反应**：剧情已有一人发问、一人隐瞒、一人旁观时，用不等距组团与纵深同时保留三人，按台词落点、隐瞒者手中任务变化、旁观者视线接收顺序激活注意力；其他人的任务持续可见。原剧本没有的泄密或认知反转不由构图示例新增。
- **横扫与高处落下**：竖屏横扫先选可保留支撑点、兵器端点和目标的斜侧覆盖；宽屏坠落先后退或俯仰跟随，使离开支撑、下落路径与落点可读。单一机位不能兼顾时按真实动作相位接镜；不把横扫改成直刺、把坠落改成平移，也不自动慢放。

真实摄影路线还要容纳摄影机本身：按目标画框、焦段和摄影距离确认后退余地、净高、门洞及绕行通道，沿 PATH 检查而不只检查 IN/OUT。空间不足时先缩短位移、改用可达方向或调整光学/景别，不为放下摄影机移动已锁墙体。按实际几何选镜，不以“室内”标签一律禁用俯拍、长焦或升降；明确的虚拟穿越镜头另按用户风格执行。

## 运镜语法

完整运镜指令按下式编译：

```text
[承载装置/运动类型] + [相对主体的路线和方向] + [速度与加减速轮廓] + [主体在画面中的保持方式] + [起点画面] + [终点画面] + [剧情作用]
```

在 `【运镜与时间轴】` 中把该式落成动态几何：IN写camera高度/距离/看向与主体起始depth/screen位置；PATH分别写camera和主体的三维横向、纵深、高度、弧线/圆心与速度曲线；运动中写主体跨前中后景、遮挡峰值/解除、screen滑移或可见缩放，以及近层快/远层慢的真实后景视差；OUT写减速/稳定点或保留明确速度向量的运动切点。`locked-off camera` 是零长度camera path且无camera parallax，不等于主体投影、焦点或环境静止。

只写“推进、拉远、平滑、渐进、快速”都不完整。`smooth` 描述稳定性或加减速曲线，不等于慢；`gradual` 描述变化过程，不说明方向和终点；`fast` 必须同时给目标、可读主体和制动终点。

同一个中文词可能对应不同摄影机操作，必须在可见提示词中补英文消歧：

- `推近/拉远`：在 `camera dollies forward/back` 与 `zoom in/out with camera position fixed` 中二选一。
- `摇镜`：写 `pan`、`tilt` 或 `roll`，不能让模型自行选择旋转轴。
- `升降`：写 `pedestal/boom`、`crane` 或仅摄影机光轴俯仰变化的 `tilt`。
- `跟拍`：写 `follow tracking`、`lead tracking` 或 `lateral tracking`，并说明摄影机在主体前、后或侧面。
- `环绕`：写 `camera orbits [命名圆心]`，说明顺/逆时针、角度、半径/高度和终点。
- `固定镜头`：写 `locked-off camera`；只固定摄影机，不冻结演员、焦点、光影、环境或声音。
- `聚焦到`：如果改变焦平面写 `rack focus`；如果只是把对象作为画面主体，改写构图或切镜，不能冒充光学对焦。
- `慢动作`：写明是动作时间重映射 `action plays in slow motion`；摄影机速度另写。

中文术语有歧义时，同句补对应英文；中文仍是主体，不整句改成英文，也不混入日语：

| 中文 | 英文 | 区分 |
| --- | --- | --- |
| 横移 | `truck left/right` | 机身平移，不是 `pan` 原地转动 |
| 甩镜 | `whip pan` | 快速转向一个明确落点 |
| 推焦、转焦 | `rack focus` / `zoom in` / `dolly in` | 清楚的对象变了写 rack focus；主体迅速放大写 zoom 并给起止焦段；观察位置走近写 dolly 与视差 |
| 冲击变焦 | `crash zoom` | 只改取景角，不产生穿过空间的视差 |
| 希区柯克变焦 | `dolly zoom` | 机身与变焦反向，主体大小保持 |
| 升格 | `slow motion` | 只指动作放慢，写明哪一段、多长 |
| 定格 | `freeze frame` | 画面整体停住；人物“停住不动”另写持续过程 |
| 一镜到底 | `continuous single take, no cuts` | 同一观察视点经历全程 |
| 正反打 | `shot/reverse shot` | 留在轴线同一侧 |
| 过肩、越肩 | `over-the-shoulder (OTS)` | 前景肩背属于谁要写明 |
| 主观镜头 | `POV` + 归属 | 写谁的视点、高度和方向 |
| 俯拍、仰拍、垂直俯拍 | `high angle` / `low angle` / `top-down` | 只改俯仰；高度变化另写 `pedestal/crane` |
| 航拍 | `aerial viewpoint` | 不写无人机实体 |
| 手持、肩扛 | `handheld` | 同时写幅度、频率和随谁颠动 |
| 浅景深、焦外 | `shallow depth of field, out-of-focus background` | 写清焦点落在哪 |
| 长焦压缩 | `telephoto compression` | 后方层次被拉近叠合，仍按焦段规则虚化 |
| 逆光、轮廓光 | `backlight` / `rim light` | 亮线只在外轮廓 |
| 剪影 | `silhouette` | 主体只剩暗形，没有边缘光 |
| 叠化 | `dissolve` | 同一 setup 内写成 BEAT，不伪增 CUT |

拍摄者和器材不写进正文：“摄影师扛着跑、蹲下”“无人机飞过”“三脚架”“稳定器”，以及“无摄影师、无摄影机”这类否定清单，都可能把人、器材或它们的影子画进画面。只写观察高度、取景、前推后撤、横移、摇摄、画幅颠动和焦点结果。【基础风格】的摄影机型号和 `camera dollies` 这类运镜术语不受影响；用户要幕后人员或器材作为剧情主体入画时照写。

| 运镜 | 情绪 / 剧情 | 错误用法 | 稳定写法 |
| --- | --- | --- | --- |
| locked-off camera | 观察、权力僵持、证据、喜剧延迟 | 把演员也冻结 | `locked-off camera；由演员的任务、焦点或声音承载这一拍` |
| pan left/right | 横向寻找、交接信息、接住入画 | 不写起止对象 | `pan right：从空门洞摇到走进来的医生，结束时两人都读得清` |
| tilt up/down | 垂直揭示、从后果回到人物 | 只写上摇/下摇 | `tilt up：从掉在地上的报告摇到听者的脸` |
| pedestal / boom up-down | 保持摄影机光轴方向的垂直位移 | 与 tilt 混淆 | `camera pedestal down：从眼睛高度降到桌面高度，镜头保持水平` |
| slow dolly in | 压力逼近、情绪收紧 | 只写“推进” | `slow dolly in，推向固定的危险点` |
| fast dolly back | 惊吓、尺度突然变大 | 画面主体丢失 | `fast dolly back，主体保持居中，危险占满后景` |
| lateral truck | 追踪、横向路径 | 方向不清 | `camera trucks left，与工人的移动平行` |
| follow / lead tracking | 跟随路线、引导逃亡或进入 | 不写摄像机在前还是在后 | `lead tracking：camera 在奔跑者前方倒退，保持全身可读` |
| camera orbit | 展示关系、困局 | 未说明是摄影机绕行还是人物旋转 | `camera orbit：绕两人顺时针慢走 120 度，结束在肩高；轴线保持可读` |
| descending spiral orbit | 坠落、命运压迫 | 空间漂移 | `descending spiral orbit：从高机位盘旋下降到肩高` |
| crane rise | 尺度揭示 | 无信息变化 | `crane rise，露出人群后面被堵住的出口` |
| crane descend | 压力落到人物、从地图进入困局 | 下降但无落点 | `crane descend：从办公室全貌降到被困员工的桌前` |
| tilt up reveal | 从物到威胁 | 只写“上摇” | `tilt up：从泥里的车辙摇到高耸的机器尾部` |
| dolly-in tension | 心理压迫 | “推进”未说明摄影机位移还是变焦 | `camera 缓慢 dolly forward，推向后视镜里驾驶员的眼睛，75mm 焦段固定` |
| dolly-back scale reveal | 人与巨物关系 | “拉远”未说明摄影机位移还是变焦 | `camera dollies backward，焦段固定，露出站在收割机盲区三角里的老人` |
| handheld panic | 逃亡、混乱 | 随机晃动 | `handheld：主体中心可读，脚步带动画面晃动` |
| stabilized tracking / Steadicam-like glide | 优雅、潜入、仪式 | 把品牌名当成完整路径 | `stabilized tracking（Steadicam glide）：camera 沿窄走廊向前滑行，主体保持在画左三分之一，no visible cut` |
| whip pan | 快速转移注意 | 乱切无目标 | `whip pan：从喊出警告的人甩到机器尾部的撞击区` |
| zoom / crash zoom | 改变取景角而不改变透视位置；突发线索 | 与 dolly 混写 | `短促 crash zoom，推到固定报告图像上的红色数值` |
| rack focus | 信息转移 | 焦点对象不清 | `rack focus：从前景稻秆转到后面藏着的人` |
| bullet time | 超现实冲击 | 只写名称，不区分时间与摄影机 | `动作放慢到几乎冻结，虚拟 camera 绕指定接触点走 90 度弧；碎屑的空间位置保持一致` |
| dolly zoom / Hitchcock effect | 恐惧认知崩塌 | 只写人名或把 dolly 与 zoom 同向 | `camera dollies backward 同时 zoom in，保持驾驶员脸的大小；背景透视向外扩张` |

每个 time beat 只用一个主运镜；只有机械耦合且共同完成同一剧情变化的复合运动可计为一个主运镜，否则分到不同 time beat。

### 运镜速度与组合

速度词必须落到可见运动曲线：

| 速度轮廓 | 适合 | 可执行写法 |
| --- | --- | --- |
| subtle micro-movement | 纪实呼吸感、轻微不安 | `低幅、不规则的 handheld 漂移，脸保持可读` |
| very slow / slow | 倾听、压迫、发现 | `匀速 very slow dolly in，停在桌沿之前` |
| moderate / walking pace | 走位、带领、空间浏览 | `lateral track，与演员步行同速` |
| brisk / fast | 追逐、惊吓、信息突变 | `camera 快速 dolly backward，焦段固定，出口入画时刹停` |
| snap / whip | 单一注意力跳转 | `snap pan：从示警的手甩到转动的车轮` |
| gradual acceleration | 威胁累积、追逐升级 | `tracking 随奔跑者逐渐加速` |
| gradual deceleration | 抵达、认知、后果 | `camera 减速，落成稳定的 close-up 并保持` |
| ease-in / ease-out | 稳定商业、抒情、产品展示 | `平顺 ease-in，中段匀速，在主体物上柔和 ease-out` |
| speed ramp | 接触前蓄势、撞击、后果 | `进入时保持实时，跨越接触和第一拍受力时 ramp 到 40%，恢复阶段回到实时；camera 路径另行写明` |

- 分开描述演员速度、camera速度和情绪强度。摄影机可跟随、领先或有动机地滞后演员，速度变化由追踪距离、信息显现和观众关系决定；紧张或悲伤升级不自动要求加速、推近或增大晃动，具体取舍由 `06` 的镜头叙事任务决定。
- 手持必须同时写晃动幅度、频率、身体/步伐来源和可读主体（来源写成画幅随谁的移动或什么事件颠动，不写拍摄者或器材，见上方术语对照后的说明）：低幅低频呼吸式漂移适合纪实与轻微不安，高频微震适合紧张，剧烈晃动只服务逃生或灾难冲击；产品细节展示和已有复杂复合运镜默认不再叠加手持。
- POV 必须点名视角来源、视线高度和运动逻辑，例如“郭大江眼睛 POV”“低于人眼的动物 POV”“车辆前挡风玻璃 POV”；航拍写 `aerial viewpoint`，不写无人机实体，也不写成角色主观 POV。除非用户要求持续沉浸式主观视角，人物/生物 POV 只作为短暂信息或情绪视角，避免长时间失去客观空间。
- 角色POV揭示未知画外事件时，先确定人物确实能接收的声音、触碰、震动、影子或反光，再写身体反应、头部/眼位转向、遮挡解除与目标入画；触发与转向可紧密重叠，不规定额外停顿。主动搜索按目标驱动转向，已在视野内的对象直接读取，不凭空补声源或重复发现。分开胸口、头部和眼位朝向，转向后保留实际支撑与道具握持；不要用自由摄影机绕到背后来代替角色看见。每镜明确POV归属；严格全程POV不插客观镜头，用户允许切出或更换视点时明确CUT及新归属，不默认全片只能有一个视点人物。
- 组合运镜只保一个复合主句：`dolly zoom` 写清摄影机和变焦的相反方向及主体大小保持；`orbit + zoom` 写圆心、旋转角度、远近变化和终点；`lateral truck + counter-pan` 写轨道方向、反向摇摄和主体居中。
- 运镜方向的读不反证据（补充，不替换方向词）：写完 `dolly out/pull back`、`crane up`、`push in` 等方向后，再补一句画面里看得见、读不反的结果——后拉时画面里出现过的东西只会越变越小，并不断有新东西从四边进入；上升时画面里的东西往下沉、从下缘退出，更高处的东西从上缘降进来；推近时只会越变越大；近处变化比远处快说明是机身在移动而不是变焦。谁在动就让谁当主语：机身平移把地面移进画面，而不是“腿从下缘冒出来”。
- 复杂复合运镜优先调用 `@视频`，但参考视频只控制已指派的运镜路径、速度和节奏，不控制当前角色、地点、服装、剧情或声音。

### 自然呼吸感（默认开启）

默认保留带自然呼吸感的实拍触感：没有明确固定或极稳要求的镜头，画幅有克制、不规则的微幅漂移、自然起伏和细小构图修正，不写成机械锁死。这是本 Skill 的默认审美，不据此推断所有电影都用肩扛。

- **写在哪**：`【基础风格】` 写一条基线，例如“画幅保留克制、不规则的自然呼吸漂移与细小修正，关键表演始终可读”；只有强弱变化或例外的 CUT 再在该 CUT 写。
- **强弱**：由剧情和对标校准。常规与安静场面用细微、非匀速的漂移和修正；行走、追拍和紧张场面逐渐加强颠动、侧倾和跟随滞后。剧烈晃动、失焦、甩镜和自然裁切各有依据才用，不捆成每镜套餐；用户明确要剧烈时要达到可见幅度，但在关键眼神、接触或因果那一瞬留出辨认机会。不要所有镜头都用同一句“轻微晃动”，也不每镜都丢焦再找回。
- **关闭的情况**：用户或项目层写了固定、绝对平稳或 `locked-off camera` 的镜头；对标的创作资料、实际片段或用户要求表明本场以极度稳定为核心；站位记录镜（[02C](02C_CONTINUATION_REFERENCES.md)，必须静止）；`content_purpose=product` 的产品细节镜（[05G](05G_VEHICLE_CINEMA.md)）。固定位置但允许摇跟的镜头，只在允许的摇摄范围里工作。资料没提肩扛不等于本场要极稳。项目层 `项目规则.md` 写“画幅呼吸感：关”时整体关闭。
- **只写画面怎么变**：呼吸感是可见的画幅变化，不是声音要求，不因此加喘息、脚步或操机声；来源写成画幅随谁的移动或什么事件颠动，不写拍摄者或器材。
- **手机拍摄**：选中[手机 Vlog 风格包](styles/phone-vlog/phone-vlog.md)，或个别镜头明确是剧中手机录的画面时，晃动来自剧中持机的人：自拍随持机角色的手臂和步伐，同伴拍随画外同伴的步伐，手机放着录时静止。持机的人是剧中角色，可以写他的手臂和步伐，仍不写拍摄者或器材。
- **高度与俯仰分开写**：“成年人肩高，取景向下摇，高度不变”和“观察高度连续降到孩子眼高”是两种动作；原地摇跟写“观察位置固定，只横摇跟随”，不写成向前位移；高度降低只写高度变化，不写谁蹲下。

| 剧情与观察状态 | 可直接采用的画幅表现 |
| --- | --- |
| 站立观察、等待 | 取景保持成年人肩高，画幅不规则漂移、轻微侧倾、小幅修正，保留观察时间 |
| 正常行走、倒退跟随 | 画幅随移动不均匀上下颠动和侧摆，主体距离变化，构图修正略迟 |
| 远距离长焦观察 | 小幅取景变化被放大，主体偏离、边缘裁切，偶有短促跟焦偏差；背景持续强虚化 |
| 奔跑、紧迫追拍 | 剧烈上下颠动和侧倾、前景掠过，主体短暂出画，随即急促摇回 |
| 突发痛苦、跌倒、意外受伤 | 事件发生后画幅突然加重晃动，急摇或下摇过冲、焦点短暂丢失，再修正 |
| 剧情已明确的近前求助或拉扯 | 角色逼近至画外近处，画幅突然后撤、主体猛然变大，接触节奏带出有方向的摇晃；对方保持画外 |
| 事件结束、死寂或凝视 | 位移停下，画幅退回余颤与不规则漂移；安静仍有生命感 |

表格用于已经选定相应观察方式的镜头，不要求每镜都用肩高机位；对标校准强弱与节奏，不机械照抄整行。动画与虚拟摄影项目同样默认开启，强弱按风格包或项目规则收放。

## 对白场景的摄影调度

对白 CUT 先看关系和语义归属，再选 shot size、camera setup 与 camera movement，不默认使用平视正反打：

| 戏剧关系 | 演员与摄影调度 | 适合的可见机制 |
| --- | --- | --- |
| 权力不平等 | 强者少动或占据高位，弱者在前景/纵深暴露手、呼吸和重心变化 | 深景双人构图、高低差、前景压迫、有明确戏剧理由的 `locked-off camera`，或写明起止距离的极慢 `camera dolly-in` |
| 亲密靠近 | 两人共享构图，用递物、接物、坐下、靠近或距离缩短承载台词 | 紧双人构图、低速 `lateral truck`、以两人中点为圆心的小弧度 `camera orbit`、焦点在手与脸之间 `rack focus` |
| 回避与隐瞒 | 角色不正面相对，用负空间、遮挡、错开的 eyeline 和道具任务暴露真实意图 | 斜构图、frame-within-frame、前景遮挡、从道具 rack focus 到反应 |
| 喜剧延迟 | 动作按严肃逻辑继续，让错误细节和晚半拍的反应形成笑点 | 保持双人/全景关系、短暂停留、reaction cut；不靠夸张晃镜制造笑点 |
| 威胁与逼问 | 施压者侵入对方空间或封住出口，构图同时读清距离变化和反应者 | 纵深调度、侧向重构图、低角度前景、`slow camera dolly-in` 或压力型 `locked-off camera` |
| 告白与反转 | 先让说话者维持表面控制，再把画面交给听者的理解或关系变化 | 共享双人构图转 reaction cut、L-cut/J-cut、由脸转手或由物件转眼神 |

规则：

- 台词的摄影机不必始终拍说话者；信息属于谁，就让焦点、构图或切镜落到谁身上，但说话来源必须清楚。
- 摄影机运动必须跟随距离、权力、信息或反应的变化，不能用“camera持续移动”掩盖人物缺少调度。
- `locked-off camera` 只在证据、权力、等待、尴尬延迟、震惊或情绪压迫需要时使用；它只固定摄影机，画内仍要有呼吸、握力、视线、焦点、光影、环境或声音变化。
- 用户或项目已锁定“破水平”、特定斜构图或其他 camera lexicon 时，按其明确定义执行；不要把 Dutch angle 当作所有对白的通用美化。

## 光线库

写光线必须包含：光源、方向、强度、主光与环境/practical色温、阴影、光比或negative fill、材质反应。色温是来源属性，不给整幅画面随意贴一个数字。

光比按可读性选择：`2:1` 适合高调商业、温和人物和明亮科普；`4:1` 适合多数剧情片，在立体塑形与面部可读之间平衡；`8:1` 适合低调悬疑、恐惧、权力压迫和局部隐藏。需要识别人脸、危险点、武器路线或群众时，阴影侧仍保留最低必要细节；不能一面写8:1压黑，一面要求暗部全部清晰如高调广告。

| 光线 | 适合场景 | 提示词写法 |
| --- | --- | --- |
| Dune daylight harsh sun | 沙漠、灾难、史诗 | `高处硬烈的直射阳光，短而黑的影子，尘土被照成金色，皮肤高光干燥、不留情面` |
| Dune firelit interior | 宗教、密室、古老权力 | `画左一处大火源，摇曳的琥珀色光，深的 negative fill` |
| golden hour | 温情、回忆、收获 | `低角度金色阳光从右后方来，长而柔的影子，稻秆上有 rim light` |
| blue hour | 孤独、悬疑、转场 | `blue hour 的天光环境，微弱的 practical 光，冷色阴影` |
| moonlight | 夜逃、恐惧 | `冷月光从后上方来，肩头一道银色 rim，前景沉在柔和的暗里` |
| oil lamp / candlelight | 古代、亲密、危险 | `一小点暖色 practical 火苗，衰减很快，影子在脸上移动` |
| torchlight | 洞穴、追逐、仪式 | `手持火把，不稳定的橙色高光，墙面随影子起伏` |
| neon | 城市、科幻、诱惑 | `青与品红的 neon 从两侧对打，湿表面反射颜色` |
| fluorescent | 医院、工厂、办公室 | `头顶平而偏绿的 fluorescent，眼下阴影硬，质感冷而无菌` |
| overcast natural light | 纪录、现实、事故 | `阴天的天空像一块大柔光箱，低对比，泥地反射暗灰` |
| skip-bleach contrast | 罪案、战争、冷硬现实 | `skip-bleach 反差，中间调去饱和，黑位压实` |
| low-key horror | 恐惧、未知 | `low-key 布光，只有一处有动机的 practical，黑色 negative fill，威胁半隐` |
| high-key commercial | 产品、科普、广告 | `high-key 柔光箱布光，阴影极少，表面干净可读` |

### 光影物理补充

与上表并用，不替换已选光线方案：

- 挂了场景参考图、用户又没指定主光方向时，【基础风格】里的光源方向、色温和曝光按场景图里实际看到的写，不另起一套和场景图相反的光。
- 光本身不带颜色。透过树叶的光，是被照透的叶子在亮（半透明黄绿、看得见叶脉），不写“绿色光柱”；写成有色光柱容易变成染色滤镜。
- 遮挡物决定光斑软硬：又厚又近（窗棂、栅栏、墙缝）出硬边光柱；又细又远（树叶、藤蔓）只剩边缘化开的不规则光斑。大而低的遮挡（宽树冠、雨棚）底下是整片柔和的暗加零星光斑。
- 逆光：亮线只长在外轮廓上（逐段写它沿哪条轮廓走），轮廓以内整片压暗；配件只在朝光一侧亮出几个小点。描述里每一处“亮”都要能指出它在哪条外轮廓上，指不出来就是凭空多了一盏灯。
- 主体压在极亮的天空或圆盘上时只剩一块剪影，没有边缘光；形状靠负形读。
- 逆光脸太暗时，提高背景亮度拉开亮度差，不给正面补光。
- 光在镜头里变化时，挂在别的东西的运动上：风推树冠让地上光斑移过去、脚踩碎水洼的反光、人往前进入亮斑又退回暗部。是否每镜都写光的变化，由项目或风格决定；真人质感项目见 [04A](04A_LIVE_ACTION_TEXTURE.md)。
- 往事、回忆段全程只写暖色光源：段里出现任何冷色光源，整镜容易变回冷色。

### 天气接触与光源依据（补充）

持续天气写进 `【基础风格】`，并在最容易丢失的近景补关键接触证据：

- **雨**：近景有失焦雨线，中景雨滴持续打到头发、眉骨、脸颊和肩部，远处是雨幕；发丝湿贴，衣料吸水变重、贴在身上，水从发梢与下巴滴落，积水被雨和脚步不断打破。第二、第三个面部特写也要写直接击打和流滴，不能只剩干脸配背景雨丝。
- **风**：同一阵风同时影响草叶、头发、衣摆、松散布料和烟尘，强弱自然起伏；系牢的部分稳定，松散的部分抖动回落；头发在头盔或帽子里时不凭空飘出。区分环境运动和画幅运动，大风不等于画幅猛烈抖动。
- **雪**：近、中、远的雪粒大小、虚化和速度不同；扬雪由风、落地或冲击带起；画面被雪尘填满必须是实际遮挡，不是无因白闪。
- **转变后保留结果**：雨停转晴，头发、衣服和地面仍湿；跨段的湿身登记到项目层 `状态事件链.md`（[02K](02K_PROJECT_SLOT.md)）。
- **光源有依据**：空旷场地不为照明凭空加人、车灯或火堆；纪实场面默认按现场光源照人物，不自动加无来源的主光、补光、轮廓光或眼神光，用户另要电影布光、梦幻或柔光时再按该组调整。

## 质感、空气与光学响应

纵深不等于背景虚化。按现有场景选择主要线索：动机光的明暗分层、已有结构的遮挡与尺度递退，或符合距离和介质的空气透视；相容的辅助线索可以并用。清洁小室内可用窗侧亮面、暗墙和门框重叠分层，不为“电影感”新增烟雾或前景道具。大气透视写远景对比、色彩随距离与介质变化；景深另写焦平面与离焦程度，不能要求强虚化背景同时精确读清远处表情或文字。

雾、烟与可见光束分开判断：场景有合理介质即可呈现雾感，只有光源方向和介质共同支持时才写可见光束。光源保持世界位置，换机位后重算画面受光侧；人物穿过明暗区或具名光源移动时，在当前 CUT 写出变化。没有这些事件时，不为迎合情绪自动换光向、改天气或让白天骤暗。

柔化按叙事细节调强弱，不按术语数量定配额。diffusion、halation、bloom、雾和强离焦若共同抹去眼神、接触边缘或空间地标，保留本场主要质感效果，降低竞争效果；用“高光边缘轻晕、焦内眼睛与手部接触清楚、后景保留门框轮廓”等可见结果表达。颗粒不等于柔焦，数字锐化也不能恢复被遮掉的信息；用户指定的粗颗粒或梦幻效果仍按风格目的保留。

| 技术描述 | 适用条件 | 稳定写法与边界 |
| --- | --- | --- |
| 强空气透视 | 大空间、长距离、山谷、城市、沙尘/湿气中有明确前中后景 | 写介质来源、密度梯度和远景降对比/偏色；近景不能同时被同等雾化 |
| 轻度柔光扩散 | 人物文戏、回忆、柔和广告、需要收敛高光 | 写 `light diffusion, restrained halation, softened highlight edges`；不把皮肤磨成塑料 |
| 压黑黑位 | 罪案、夜景、悬疑、低调权力 | 写 `compressed black toe, rich blacks with retained narrative detail`；剧情信息所在阴影不死黑 |
| 各向异性高光 | 拉丝金属、缎面、头发、唱片纹路、方向性湿表面 | 写明材料纹理方向和高光沿哪个方向拉伸；皮肤、石墙和漫反射布料不机械使用 |
| 焦散 | 水面、玻璃、晶体、弧形反射金属把光投到另一表面 | 写明光源、折射/反射介质、接收表面和随介质运动的图样；没有传播路径不生成装饰光纹 |
| 电影级调色 | 所有需要统一成片基调的项目 | 必须继续写 palette relation、饱和度、black toe、高光、肤色保护和 LUT/stock-like 可见结果，不能单独使用该词 |
| 同类色 | 温和统一、衰败单调、品牌或场景综合色 | 点名相邻色相、明度/饱和度层级和10%强调色，避免主体与背景融成一块 |

## 色彩系统

当前已触发07A名画致敬时，配色按其“原画配色转译为电影光影”执行：继承原画实际主辅色、冷暖与明暗层级，通用面积配额、强调色和角色分色建议不覆盖原画关系。其余任务沿用本节。

- 60/30/10：60% 环境主色，30% 人物/道具辅色，10% 危险或情绪强调色。
- 色彩关系必须点名：同类色、互补色、分裂互补或冷暖分离中选择当前剧情需要的一种；同类色仍用明度、饱和度或10%强调色分离主体。
- 角色色彩：主角、反派、受害者、机器、超自然元素不能混成同一色块。
- 危险色：红、橙、黑黄警示、冷白机械光，用于突出风险点。
- 超自然例外色：只给异常能量、预兆、梦境、神迹，避免污染现实场景。
- HEX 锁定：产品、UI、装备、品牌色需要稳定时才写 HEX。
- LUT 语言：`warm Kodak-like highlights with cool cyan shadows`、`bleach bypass contrast`、`muted documentary LUT`；同时写 black toe、高光滚降、肤色保护或饱和度结果，不只写“电影级调色”。

## 画家 / 流派风格语义编译

本节只处理画家/流派的视觉风格，不自动联网或加载具体作品致敬。当前明确要求“世界名画”或致敬某幅绘画时转07A，按文字保留其可辨认的动作关系和构图；该路由不绑定名画图片，不能套用下方一般风格示例中的“不要复制具体作品”来抹去用户要求的场面辨识度。

如果用户提到画家、流派、插画风格或风格图，不要只复述名称。必须翻译为：

- 线条：硬边、软边、墨线、厚涂、速写。
- 色彩：饱和度、冷暖、主辅色、强调色。
- 构图：平面装饰、纵深透视、对称、负空间。
- 材质：油画、胶片颗粒、水彩扩散、PBR、黏土、赛璐璐。
- 光线：自然光、戏剧性明暗、图形化阴影。
- 情绪：童话、荒诞、史诗、压抑、温柔、冷峻。

写法：

```text
风格参考被编译为：柔和的水彩边缘，低饱和苔绿配暖赭石的色板，简洁的图形化剪影，柔和环境光和手绘纸纹；do not copy any signature or exact artwork。
```
